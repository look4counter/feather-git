<h1 align="center">Feather Git</h1>

<p align="center">
  <strong>깃털처럼 가볍게, 작업의 흐름은 한눈에.</strong><br />
  변경사항 확인부터 커밋과 푸시까지, 하나의 화면에서 이어가는 Windows용 Git 클라이언트.
</p>

## 코드에 집중할 수 있도록

어떤 파일을 바꿨는지, 어느 브랜치에서 작업 중인지, 이전 커밋에는 무엇이 담겼는지.
Feather Git은 브랜치와 커밋 이력, 변경 파일과 코드 차이를 한 화면에 모아 보여줍니다.

프로젝트를 탭으로 열고, 변경을 살펴보고, 필요한 내용을 커밋하세요.
편집기에서 작업한 내용도 자동으로 반영되어 흐름을 이어갈 수 있습니다.

## 한눈에 살펴보는 작업의 흐름

- **분기와 병합을 따라가는 커밋 그래프** — 브랜치가 갈라지고 합쳐지는 흐름을 보고, 커밋 메시지와 작성자, 변경 내역을 함께 확인하세요.
- **변경사항을 명확하게** — 스테이징한 파일과 작업 중인 파일을 구분하고, 추가·삭제된 코드를 살펴보세요.
- **커밋부터 원격 반영까지** — 스테이징, 커밋, 마지막 커밋 수정과 Fetch·Pull·Push를 화면에서 이어가세요. 푸시는 실행 전 확인창을 거칩니다.
- **여러 프로젝트를 하나의 창에서** — 저장소마다 탭을 열어 오가세요. 탭을 전환해도 각 저장소의 선택 상태가 유지됩니다.
- **외부 변경도 자동으로** — 편집기나 터미널에서 바꾼 파일과 저장소 상태를 감지해 화면에 반영합니다.
- **손에 맞는 작업 공간** — 패널 크기와 목록 열 너비를 조절하고, 자주 쓰는 작업의 단축키를 설정하세요.

## 열고, 살펴보고, 커밋하세요

1. **저장소 열기** — 상단의 **+**로 새 탭을 열고 기존 저장소 열기, 새 저장소 만들기, Clone 중에서 선택하세요.
2. **변경사항 확인** — 파일을 선택해 코드 차이를 살펴보고 커밋할 내용을 스테이징하세요.
3. **커밋과 공유** — 메시지를 작성해 커밋하고, 준비가 되면 원격 저장소에 푸시하세요.

## 이런 작업에 잘 어울립니다

- 여러 저장소를 오가며 개발할 때
- 커밋 그래프로 프로젝트의 변경 흐름을 파악할 때
- 커밋 전에 파일별 변경사항을 꼼꼼히 검토할 때
- 편집기와 Git 클라이언트를 함께 열어두고 작업할 때
