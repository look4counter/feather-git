# 화면 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

프로젝트 탭 → 7개 작업 툴바 → 본문 → 상태 표시줄 순서를 유지한다.
본문 왼쪽은 브랜치/변경 파일, 오른쪽은 커밋 기록/상세이다.
탭 클릭은 현재 프로젝트 표시를 바꾼다. 커밋 클릭은 상세를 바꾼다.
툴바 클릭은 해당 작업의 연결 예정 안내만 표시한다. Git 명령, 파일 쓰기, 네트워크 호출은 하지 않는다.

프로젝트 바에는 로고 없이 이름과 ×가 있는 탭을 표시한다. 선택 강조선은 위쪽이다.
열린 탭 목록은 가로 스크롤되며 + 버튼은 오른쪽 끝에 남는다.
닫기는 해당 탭만 제거한다. 선택 탭을 닫으면 오른쪽 이웃, 없으면 왼쪽 이웃을 선택한다.
마지막 탭을 닫으면 빈 상태를 표시한다. +는 프로젝트 열기 연결 예정 안내를 표시한다.

Windows에서는 탭바 위에 같은 BASE 배경의 32px 커스텀 제목 표시줄을 둔다.
왼쪽 앱 이름 영역은 창 이동 및 더블클릭 최대화 영역이고 오른쪽에는 최소화, 최대화/복원, 닫기를 둔다.
각 영역은 GPUI의 Windows 네이티브 창 제어 영역으로 지정한다. 다른 플랫폼은 기본 제목 표시줄을 유지한다.

창 제어 아이콘은 Windows 전용 글꼴에서 10px로 표시한다. 버튼 크기는 46×32px이다.
프로젝트 바 높이는 36px, 탭 닫기 영역은 20px, 오른쪽 + 영역 너비는 40px이다.

최신 탭바 높이는 42px이다(기존 36px 대체). 강조선은 선택 탭 위에 겹쳐 그리며 레이아웃 공간을 차지하지 않는다.
오른쪽 + 기호는 12px 정사각 영역 중심의 교차선으로 그리고 버튼 중앙에 정렬한다.
