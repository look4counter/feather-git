# 닫기 버튼 표시 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

활성 탭의 닫기는 상시 표시하고 비활성 탭은 해당 프로젝트 탭 전체의 호버 때만 표시한다. 숨겨진 버튼 공간을 유지한다. 모든 탭 오른쪽에 1px LINE 경계를 표시하고 닫기 이벤트의 부모 선택 전파 방지와 이웃 선택 정책을 유지한다.

현재 src/ui.rs와 FR-022·SC-013 및 T032 설명에 따라 손상된 문구를 복원했다. 활성 탭도 숨기던 이전 호버 전용 계약은 대체되었다. 과거 실제 실행 결과의 복원을 의미하지 않는다.
