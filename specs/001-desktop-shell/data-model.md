# 데이터 모델

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

- 프로젝트: 정적 이름 배열, 선택 인덱스. 모든 프로젝트는 데모 화면임을 명시한다.
- 커밋: 정적 메시지, 해시, 날짜, 참조 라벨. 선택 인덱스로 상세를 조회한다.
- 변경 파일: 상태 문자와 정적 경로.
- 화면 상태: 프로젝트 인덱스, 커밋 인덱스, 작업 안내 문자열. 상태는 메모리에만 유지한다.
