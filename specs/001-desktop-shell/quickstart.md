# 실행 및 검증

현재 기준은 [전체 명세 색인](../README.md)과 [이 기능의 명세](spec.md)를 따른다. 초기의 샘플 테스트·미연결 툴바 확인 절차는 샘플 제거 및 실제 Git 작업 연동으로 폐기되었다.

1. Cargo.toml의 로컬 vendor 의존성이 존재하는지 확인한다. 현재 소스에는 두 패치 디렉터리가 있다.
2. 현재 실행 중인 사용자 앱을 종료하지 않는다. 기본 실행 파일이 잠겨 있으면 별도 출력 빌드를 사용한다.
3. 격리된 테스트 저장소에서 현재 툴바·네 패널·선택·상세·상태 표시줄을 확인한다. 실제 Git 작업은 해당 기능의 확인창과 검증 절차를 따른다.
4. 활성 탭의 ×는 상시, 비활성 탭은 호버 때만 표시되며 모든 탭의 오른쪽 1px 경계가 유지되어야 한다. 숨김 전후 공간·닫기 전파 방지·고정 + 동작을 확인한다.
5. 프로젝트 탭바 42px·패널 제목 36px와 제목·배지 중앙 정렬을 확인한다. 마지막 프로젝트 닫기는 현재 시작 화면 정책을 따른다.
6. 코드 변경 검증 시 관련 자동 테스트·정적 검사·빌드를 실행하고 결과를 실행 일자와 함께 기록한다. 이번 문서 정리에서는 이를 재실행하지 않았다.

기존 미완료 작업 T007·T013·T017·T022·T026·T029·T032·T035는 실제 창 검증이 남아 있다. 이전 36px 탭바 및 활성 닫기 호버 전용 조건은 현재 기준으로 대체하여 검증한다.
