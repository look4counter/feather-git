# 조사 결과

- 결정: 기존 GPUI로 구현한다. 근거: Cargo.toml의 명시적 선택이며 로컬 캐시의 공식 hello_world 예제를 확인했다. 대안: 웹 UI는 네이티브 프로젝트와 맞지 않아 배제했다.
- 결정: 화면은 다크 네이비와 청록 포인트를 사용한다. 근거: 흰색 위주 화면 개선 요구와 작업 집중도. 대안: 밝은 회색은 참조 화면과 변화가 작다.
- 결정: 샘플 데이터만 사용한다. 근거: 기본 골격 범위이며 저장소 서비스가 없다.
- 알려진 제약: 로컬 패치 의존성 폴더가 없다. 패키지를 임의로 대체하지 않고 빌드 제한을 보고한다.

## 닫기 버튼 호버 표시 조사

GPUI 0.2.2의 InteractiveElement::group/group_hover는 부모 그룹의 호버 스타일을 자식에 적용한다. visibility 숨김은 공간을 유지하므로 별도 호버 상태나 탭 레이아웃 재계산 없이 요구사항을 구현한다. 데이터 모델과 외부 계약 변경은 없다.

## 탭 경계와 활성 닫기 표시 조사 복원

현재 tabs()는 각 행에 border_r_1·LINE 경계를 적용하고 닫기 버튼에 when(!active) 조건으로만 숨김을 적용한다. 그룹 호버는 비활성 탭 닫기를 표시하며 활성 탭은 항상 표시된다. 현재 소스와 T032로 확인한 내용이며 손상된 과거 조사 원문의 정확한 문장을 재현하지 않는다.

초기 샘플 전용·vendor 부재 판단은 당시 조사 기록이다. 현재 샘플 런타임은 020에서 제거되었고 vendor 소스는 존재한다.
