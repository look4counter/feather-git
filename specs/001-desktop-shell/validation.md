# 검증 결과

## 구현 결과

- src/main.rs: GPUI 진입점, 기본 1440×900, 최소 1100×700.
- src/ui.rs: 네이비/청록 테마, 프로젝트 탭, 7개 작업, 4분할 패널, 상태 표시줄.
- src/sample.rs: UI와 분리된 샘플 데이터.
- design/desktop-shell.png: 구현 방향을 설명하는 정적 디자인 미리보기. 실제 앱 캡처가 아니며 렌더링 검증을 대신하지 않는다. 이미지의 배치와 가독성을 직접 확인했다.

## 실행한 검사

- cargo fmt --check: 통과.
- rustc --edition 2024 --test src/sample.rs -o target/sample-tests.exe 및 실행: 1개 테스트 통과.
- cargo check --offline: vendor/gpui/Cargo.toml 부재로 의존성 로드 단계 실패.
- cargo test --offline: 동일한 의존성 로드 오류로 실행 불가.
- 소스 검토: 커밋 선택 인덱스를 상세가 직접 참조하며, 작업 버튼은 안내 문자열만 변경한다. Git 호출 없음.

## 일관성 및 수렴 검토

명세 6개 요구사항과 3개 성공 기준, 2개 사용자 이야기, 계획의 4개 구현 단계를 검토했다.
소스상 각 요구사항에 대응하는 구현은 있으나 SC-001~003의 실제 창 크기, 클릭, 스크롤 검증은 미완료이다.
헌장은 미작성 템플릿으로 헌장 검사는 생략했다. 기존 Cargo.toml은 변경하지 않았다.
의존성 복원 후 전체 컴파일 및 실행 검증이 필요하므로 완전 수렴으로 판정하지 않는다.

## 실행 오류 수정 검증 (2026-11-11)

- 사용자 변경: Cargo.toml의 로컬 패치 설정이 제거되어 공식 gpui 0.2.2를 사용한다. 이 변경을 유지했다.
- 재현: E0599(items_stretch 메서드 부재), E0599(AppContext 가져오기 누락).
- 수정: src/main.rs의 AppContext 가져오기와 src/ui.rs 본문 컨테이너의 기본 flex 정렬.
- cargo fmt --check: 통과.
- cargo check --offline: 통과.
- cargo test --offline: 1개 통과.
- cargo run --offline: 빌드 성공, 실행 파일 시작 및 프로세스 유지 확인. 실행 로그에 오류 없음.
- 창 확인: 프로세스의 창 핸들은 생성되었으나 computer-use 목록에서 해당 새 창을 찾을 수 없었다. 실제 렌더링/클릭은 확인하지 못했다. 테스트 실행 세션은 종료했다.
- 의존성 경고: proc-macro-error2 2.0.1에 향후 Rust 호환성 경고가 있으나 현재 검사와 테스트는 통과한다.
- 수렴 검토: FR-007의 컴파일 오류는 해결되었다. 실제 화면 검증은 기존 T007에 남겨 두며 SC-004의 창 표시도 해당 검증에 포함한다. 기능 추가나 의존성 변경은 없다.

## 프로젝트 바 개선 검증

- src/ui.rs에서 로고 제거, 탭별 ×, 위쪽 선택선, 오른쪽 고정 +를 구현했다. +는 프로젝트 열기 준비 중 안내를 표시한다.
- 열린 탭 목록을 원본 프로젝트 인덱스로 관리해 닫기 후 상세 참조를 유지한다. 마지막 탭을 닫으면 빈 상태를 표시한다.
- 닫기 버튼은 이벤트 전파를 중단하여 부모 탭 선택을 막는다.
- cargo fmt --check: 통과.
- cargo check --offline: 통과.
- cargo test --offline: 4개 통과. 비선택 탭 닫기, 선택 탭 닫기와 이웃 선택, 모두 닫기 및 없는 탭 닫기를 검증했다.
- cargo build --offline: 실행 중인 target/debug/feather-git.exe 파일 잠금으로 교체 실패(os error 5). 현재 사용자 앱은 종료하지 않았다.
- 수렴 검토: FR-008~011과 SC-005~006의 구현 및 상태 테스트는 대응한다. 시각적 위치, 버튼 실제 클릭, 좁은 창 가로 스크롤은 실행 검증이 남았다. 이를 후속 검증 작업으로 기록한다.
- design/desktop-shell.png는 이전 정적 시안이며 이번 변경을 반영한 실행 화면이 아니다.

## Windows 커스텀 제목 표시줄 검증 (2026-11-12)

- src/main.rs: Windows에서만 TitlebarOptions.appears_transparent를 켜서 기본 제목 표시줄을 숨긴다.
- src/ui.rs: 프로젝트 탭바의 BASE(0x10151f)를 공유하는 32px 제목 표시줄을 추가했다. 앱 이름과 최소화/최대화·복원/닫기 버튼을 배치한다.
- WindowControlArea의 Drag/Min/Max/Close를 사용한다. 공식 GPUI Windows 소스에서 HTCAPTION/HTMINBUTTON/HTMAXBUTTON/HTCLOSE 매핑과 비클라이언트 버튼 처리를 확인했다. 중복 클릭 핸들러는 추가하지 않았다.
- cargo fmt --check, cargo check --offline: 통과.
- cargo test --offline: 기존 테스트 4개 통과.
- cargo build --offline: 기존 실행 파일 잠금으로 교체 실패.
- target/titlebar-preview의 임시 매니페스트로 동일 src/main.rs를 별도 이름으로 빌드: 성공. 원본 Cargo.toml과 의존성은 변경하지 않았다.
- 검증용 실행 파일은 오류 로그 없이 실행되고 창 핸들을 생성했다. computer-use 목록에는 해당 창이 노출되지 않아 화면과 드래그/더블클릭/버튼 실제 조작을 확인하지 못했다. 검증용 실행 세션은 종료했다.
- 수렴 검토: FR-012~013 소스 구현은 명세 및 계획과 일치한다. SC-007~008 실제 화면 및 창 동작 검증은 남아 있으므로 후속 작업으로 기록한다.

## 제목 버튼 및 프로젝트 바 밀도 개선 검증 (2026-11-12)

- src/ui.rs: 일반 문자를 Segoe MDL2 Assets의 창 제어 아이콘으로 바꾸었다. 최소화 E921, 최대화 E922, 복원 E923, 닫기 E8BB를 10px 및 줄 높이 1로 중앙 정렬한다. 기존 46×32px 영역과 네이티브 제어 동작을 유지한다.
- 프로젝트 바 높이를 51px에서 36px로 줄이고 닫기 영역은 20px, + 영역 너비는 40px로 변경했다.
- 프로젝트 바 위쪽에 LINE 색상 1px 구분선을 추가했다. 탭 위쪽 선택 강조선은 유지했다.
- cargo fmt --check, cargo check --offline: 통과.
- cargo test --offline: 기존 테스트 4개 통과.
- 기본 cargo build --offline는 실행 중인 파일 잠금으로 교체 실패했다. 동일 소스를 기존 임시 검증 매니페스트로 별도 파일명 빌드하여 성공했다.
- 수렴 검토: FR-014~016 및 SC-009~010의 소스 구현이 명세와 계획에 대응한다. 새 상태 로직이나 의존성 변경은 없다. 실제 DPI별 아이콘 표현과 호버, 36px 바의 시각 검증은 아직 수행하지 않았다.

## 프로젝트 탭바 정렬 보정 검증 (2026-11-12)

- src/ui.rs의 tabs() 높이를 42px로 변경했다. 타이틀바 구분선은 유지했다.
- 모든 탭의 2px 상단 테두리를 제거하고 선택 탭에만 absolute 강조선을 겹쳐 그렸다. 비선택 탭은 배경이 위쪽까지 채워지고 선택에 따라 내용의 세로 위치가 변하지 않는다.
- +는 12×12px 영역의 중심 5.5px에 두께 1px의 가로/세로 선을 배치해 기하학적 중앙을 맞췄다. 버튼은 기존 flex 양축 중앙 정렬을 유지한다.
- cargo fmt --check, cargo check --offline: 통과.
- cargo test --offline: 기존 4개 테스트 통과.
- 기존 임시 검증 매니페스트로 동일 소스 별도 파일명 빌드: 통과.
- 수렴 검토: FR-017~019 및 SC-011의 소스 구현이 계획 및 계약과 일치한다. 기존 선택/닫기 상태 로직은 변경하지 않았다. 실제 창의 DPI별 선/정렬 검증은 수행하지 않았다.

## 프로젝트 탭 닫기 버튼 호버 표시 검증

- src/ui.rs의 프로젝트 탭에 그룹을 지정하고 닫기 버튼은 기본 숨김, 해당 부모 그룹 호버에서만 표시하도록 변경했다. 숨김은 공간을 유지하며 기존 클릭 전파 방지와 닫기 상태 처리를 보존했다.
- cargo fmt --check: 통과.
- cargo check --offline: 통과.
- cargo test --offline: 4개 통과. 선택/비선택/마지막 탭 닫기 회귀 검사 포함.
- cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-hover.exe: 통과. 출력 경로 조정 안내 및 기존 proc-macro-error2 미래 호환성 경고가 있다.
- 실제 창의 선택/비선택 탭 호버, 탭 간 이동, 닫기 영역 진입 및 레이아웃 유지는 미검증이다. 자동화 테스트로 시각적 동작이 검증됐다고 간주하지 않는다.

## 프로젝트 탭 경계와 활성 닫기 표시 기록 복원

현재 소스에서 모든 탭의 1px 오른쪽 경계와 활성 닫기 상시·비활성 닫기 호버 표시를 확인했다. 이 부분의 과거 문구가 손상되어 당시 테스트 수·종료코드·빌드 결과는 재확인할 수 없다. 기존 T030·T031 완료 표시는 이력으로 보존하며 현재 버전의 검증으로 해석하지 않는다. 실제 시각·입력 검증 T032는 미완료다.

## 패널 헤더 높이 축소 검증

- 공통 heading()의 높이만 48px에서 36px로 변경했다. 네 패널 호출부와 제목·배지·중앙 정렬·구분선을 유지하여 FR-023과 코드가 일치한다.
- cargo fmt --check, cargo check --offline, cargo test --offline 통과. 기존 테스트 4개 모두 통과했다.
- cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-headers.exe 통과. 기존 의존성 미래 호환성 경고와 출력 경로 조정 안내가 있다.
- 실제 창의 제목·배지 잘림과 본문 배치는 미검증이다. SC-014의 시각 검증은 남은 작업으로 유지한다.
