## 비고

상단 탭 바 변경은 FR-015~FR-017 및 SC-006으로 반영했다. 기존 폴더 선택·새로고침 버튼 요구를 제거하고 빈 탭·마지막 탭 닫기·실행 인자 동작을 확정했다. 품질 항목 6개를 재검토했으며 모두 통과했다.

사용자가 A를 선택하여 실제 저장소 조회 범위로 확정했다. 저장소 변경 기능은 포함하지 않는다. 명확화 후 품질 항목 6개가 모두 통과했다.

추가 요청인 여백 없는 배치와 공통 경계선 크기 조절을 FR-012~FR-014 및 SC-005로 명세했다. 최소 크기·드래그 종료·프로젝트 전환 동작을 정의하여 기존 품질 항목 6개를 다시 검토했고 모두 통과했다.
