# 사용자 인터페이스 계약

- 실행: `cargo run -- [저장소 경로]...`. 인자가 없으면 빈 페이지 탭을 표시한다.
- 상단: 44px 높이의 탭 바. 전체 높이 사각 탭과 중앙 24px 닫기 버튼, 맨 오른쪽에 고정된 +만 제공한다. 로고·앱 이름·새로고침·저장소 열기 버튼은 없다.
- +를 클릭할 때마다 새 빈 탭을 추가하고 활성화한다. 빈 본문에는 패널·상태줄·안내·대화상자를 표시하지 않는다. 마지막 탭을 닫으면 빈 탭을 하나 만든다.
- 좌상: 브랜치 목록 및 Local/Remote/Stash/Tag 탭. 선택은 탐색만 수행한다.
- 우상: 커밋 제목, 해시, 작성자와 시각. 모든 참조에서 도달 가능한 전체 커밋 수를 표시한다.
- 좌하: Stage/History. Stage는 스테이징과 작업 디렉터리 변경을 별도 표시한다.
- 우하: 행 번호가 있는 통합 Diff. 추가 녹색, 삭제 붉은색, 헤더 청록색.
- 하단: 저장소 탭에만 경로, 읽기 전용 상태, 로딩 또는 오류 안내.
- 최소 창 크기: 1000×680. 각 내용 영역은 독립적으로 스크롤한다.
- 오류가 발생해도 탭 닫기 및 새 빈 탭 추가가 가능하다.
- 본문 외곽과 네 패널 사이에 여백과 둥근 모서리가 없다. 콘텐츠 내부 여백은 유지한다.
- 공통 세로·가로 경계선은 1px이며 포인터 판정 영역은 각각 7px다. 방향별 크기 조절 커서를 제공한다.
- 세로 경계선 드래그는 좌우 열 너비를, 가로 경계선 드래그는 상하 행 높이를 바꾼다. 마우스를 놓으면 종료한다.
- 최소 크기는 좌측 260px, 우측 360px, 위·아래 180px이다. 작은 창에서는 가용 공간에 맞춰 축소한다. 비율은 프로젝트 전환 중 유지한다.

## 새 탭 시작 계약

세 선택지에서 새 경로·기존 폴더·URL과 새 경로를 각각 받는다. 취소는 상태를 유지하고 실패는 해당 탭에 표시한다. 진행 중 중복 요청은 무시한다. 성공은 동일 탭에 적용하며 닫힌 탭은 복원하지 않는다.

## 커밋 그리드와 상세 계약

Graph·Description·Author·Date·Hash 헤더와 24px 행을 정렬한다. 그래프 클릭도 커밋 행 선택이다. History 상단 커밋상세는 파일 스크롤에 관계없이 보이며 Stage에서는 숨긴다. 커밋 선택 시 상세를 기본 표시하고 파일 선택 시 Diff로 전환한다. 상세에는 줄 번호나 Diff 색상을 붙이지 않으며 조회 중·빈 커밋·실패를 구분한다.

## 전체 이력 그리드 계약

브랜치 선택은 필터링 대신 해당 브랜치 끝 커밋을 선택한다. Description은 브랜치명 다음에 제목을 표시한다. Date는 커밋 시간대 기준 날짜와 시분이다. 그리드는 패널 폭 100%를 사용하고 이웃 열 경계를 드래그하여 전체 폭을 유지한다. 고정 헤더와 가상 행은 동일 열 배열을 사용하며 가시 행만 생성한다. 커밋 선택은 상세와 파일만 갱신한다.

## 공통 스크롤 계약

히스토리·브랜치·파일·Diff는 같은 스크롤바를 쓰며 Diff에는 가로 바도 제공한다. 히스토리 아래 끝에서 200개를 추가하고 더 이상 없으면 멈춘다. 개수/첫 부모 라벨은 없고 체크아웃 표식은 ●다. 커밋상세는 파일 스크롤 위 고정 항목이며 메시지 자체는 Diff의 가상 목록에 표시한다.

## 콘텐츠 중심 표시 계약

네 영역의 제목 헤더는 없고 탭·그리드 컬럼과 파일 경로만 유지한다. 스크롤이 필요할 때만 같은 공통 바를 표시한다. 목록과 상세 고정 행은 폭 100%·높이 24px이다. 추가 로딩 진행 표시는 그리드 안의 오버레이다. 상세 상위 해시는 라벨과 한 줄이고 시간대 및 메시지 라벨은 표시하지 않는다.

## 복구와 모달 계약

새 탭에는 최근 저장소 이름·일반 경로와 열기·목록에서 제거·저장소 삭제를 제공한다. 삭제는 앱 내 확인을 거쳐 휴지통 이동하며 실패 시 목록과 탭을 유지한다. 도움말과 진행은 같은 창 안의 중앙 오버레이이다. 진행 중 배경과 전역 단축키를 차단하며 실패 시 종료하고 오류를 보여준다. 입력 중 f와 ?는 입력 문자로 처리한다. fetch는 작업 트리를 변경하지 않는다.

## 목록 포커스·읽기 전용 선택 계약

클릭한 브랜치·파일·커밋 목록의 ↑/↓는 클릭과 동일한 선택 조회를 수행하며 파일 그룹 라벨은 건너뛴다. 커밋상세와 Diff 본문은 클릭 커서·드래그·Shift 방향키·Ctrl+A·Ctrl+C를 지원한다. 복사는 줄번호/변경 표식 없이 원문 텍스트·탭·빈 줄을 보존한다. 입력/삭제/붙여넣기는 내용을 바꾸지 않는다. 데이터 선택 변경은 텍스트 범위를 초기화한다.

## 히스토리 진행과 최소 도움말 계약

Progress는 히스토리 최초/재조회·추가 페이지·브랜치 탐색에만 나타난다. 상세/Diff 선택은 전역 입력을 막지 않는다. 도움말에는 `[단축키]`와 `f - 패치`만 보이고 Esc/바깥 클릭으로 닫는다. 브랜치는 미로딩 대상까지 200개 페이지를 누적하고 발견한 행으로 이동한다.


## Stage 상태·원격 HEAD·새로고침 계약

origin/HEAD와 origin/main은 같은 커밋을 가리켜도 다른 배지이다. Stage에서는 작업 디렉터리 헤더가 없고 unstaged 상태는 빨강 `??`/` M`/` D`, staged 상태는 초록 `A `/`M `/`D `이다. staged 파일명도 초록이다. Space는 선택한 unstaged 파일을 실제 스테이징하며 History/텍스트/입력 필드에서는 실행하지 않는다. F5는 로컬 새로고침이고 도움말에 `F5 - 새로고침`을 표시한다. f는 원격 fetch이다.


## Stage 양방향 전환 계약

Stage 목록에는 그룹 헤더가 없다. Space로 선택 경로를 stage/unstage하고 기존 두 칸 표기와 색상을 갱신한다. unstage는 작업 파일 내용을 유지하며 다른 파일의 인덱스에 영향을 주지 않는다. 반대 상태 행이 남으면 선택을 유지하고 변경 자체가 사라지면 Diff를 비운다.


## 지연 탭과 커밋 오버레이 계약

시작 시 활성 탭만 조회하고 나머지는 처음 클릭할 때 읽는다. stage 전환은 경로 정렬을 바꾸지 않는다. History의 커밋상세 행은 파일 행과 같은 글자 크기이다. 도움말에 `c - 커밋`을 표시한다. c로 열린 메시지 오버레이는 Ctrl+Enter/Ctrl+S로 제출하며 하단에 `Ctrl+Enter 또는 Ctrl+S`를 표시한다. 빈 메시지/실패는 오버레이 안에서 알리고 메시지를 보존한다. 실행 중 편집·중복·취소는 막고 성공 시 닫아 갱신한다.


## 작은 제목과 커밋 입력 스크롤 계약

커밋과 `[단축키]` 제목은 본문 크기이다. staged가 없으면 c는 팝업을 열지 않는다. 커밋은 Ctrl+S 또는 하단 우측 커밋 버튼, 취소는 Esc 또는 닫기 버튼이며 Ctrl+Enter로 제출하지 않는다. 하단 안내는 `커밋 : ctrl + s, 취소 : esc`이다. 긴 메시지는 입력 영역 안에서만 스크롤하고 제목과 하단은 고정한다.


## 작성자 표시와 Stage 다중 선택 계약

Author는 `이름 <메일주소>`이다. Stage에서 Shift는 범위, Ctrl은 개별 선택 추가/해제, Ctrl+Shift는 범위 추가이다. Space는 선택 전체를 반전하고 같은 경로 양쪽 행 선택은 stage 우선이다. 선택 행을 모두 강조하고 대표 행의 Diff를 보여준다. 상태 변경 후 실제 남은 행으로 선택을 복원한다.

## 선택 파일 폐기 계약

d는 Stage의 선택을 대상으로 전체 변경 폐기 확인창을 연다. 대상 목록과 신규 파일 삭제를 알리고 확인 후에만 HEAD 복원 또는 신규 파일 삭제를 수행한다. Esc/취소/바깥 클릭은 실행 전에 취소하며 실행 중에는 막는다. 다른 경로를 변경하거나 디렉터리를 재귀 삭제하지 않는다.

도움말의 p는 fast-forward 풀, shift+p는 일반 푸시이다. 입력/모달에서는 실행하지 않고 중복 요청은 무시한다. 하단에 진행 상태를 표시하고 성공 후 해당 저장소를 재조회한다.

커밋 팝업은 버튼 없이 `커밋 : ctrl + s, 커밋 후 푸시 : ctrl + p, 취소 : esc`를 표시한다. Ctrl+P의 push 실패는 이미 만들어진 로컬 커밋을 실패로 되돌리거나 재생성하지 않고 별도 오류로 알린다.


## Ctrl+A와 폐기 확인 키 계약

Stage 목록의 Ctrl+A는 모든 행을 선택하고 기존 대표 Diff를 유지한다. 폐기 창에는 개별 파일/버튼이 없고 `폐기 : ctrl + s, 취소 : esc`를 표시한다. Ctrl+S는 그 확인창 안에서만 폐기하고 Esc는 실행 전에 취소한다.

하단 오류는 약 3초 뒤 일반 상태로 돌아가며 새 오류가 오면 시간을 다시 센다. 확인창 내부 오류는 수정/재시도까지 유지한다.

## 포커스와 도움말 표시 계약

목록 선택은 활성 청록색/비활성 회색으로 구분하고 호버로 덮지 않는다. 도움말은 공통·목록·Stage 파일·텍스트·확인창 조건을 구분하며 키 표기를 소문자로 쓴다. 새로고침은 f5와 ctrl+r가 동일하다.

## 새 탭 최근 저장소 계약

왼쪽 신규 저장소 작업과 오른쪽 최근 목록은 좌우로 표시한다. 최근 목록은 높이 40px의 한 줄 가상 행과 독립 수직 스크롤이다. 휴지통 아이콘은 열기를 전파하지 않고 목록 제거/저장소 삭제 선택창을 연다. 제거는 기록만 지우고 삭제는 추가 확인을 거친다. esc/취소는 변경 없이 닫는다.

History 커밋상세 행은 일반 파일 행과 같은 활성/비활성 선택색 및 호버 계약을 따른다. 선택 상태는 포커스 이동으로 해제하지 않는다.

최근 저장소와 생성·폴더 열기·복제 성공은 작업을 시작한 빈 탭만 소비한다. 실패/취소는 빈 탭을 유지한다. 비동기 완료는 다른 현재 선택을 빼앗지 않으며 닫힌 시작 탭을 다시 만들지 않는다.

도움말 표시 계약은 공통→브랜치→커밋히스토리→파일목록→텍스트뷰어 순서다. 각 키는 한 줄이고 확인창 전용·기존 diff/커밋상세 제목·이전/다음 행 선택 안내는 제외한다. 새 요구는 이전 도움말 그룹 계약을 대체하며 실제 단축키 동작은 보존한다.

## 설정 오버레이 계약

두 화면의 우측 하단 도움말 옆 `f12 - 세팅`과 f12로 연다. 사용자/원격 탭과 닫기를 제공하며 esc는 IME 조합 중이 아니면 닫고 ctrl+s는 사용자 설정 저장이다. 사용자 탭에서 전역 선택·이름·이메일을 명시적으로 저장한다. 전역 사용 시 현재 저장소의 개별 사용자 키는 제거한다. 새 탭에서는 전역만 가능하다. 인증은 HTTPS 주소와 GCM 상태 확인·브라우저 로그인·로그아웃·Git 연결 버튼으로 관리하며 토큰을 표시하지 않는다. 원격 탭은 이름·fetch/push 주소·브랜치/추적을 읽기 전용으로 표시한다. 빈 상태·진행·실패를 구분하고 오버레이가 열리면 기존 섹션 키는 실행하지 않는다.

## 브랜치 조작과 태그 표시 계약

커밋히스토리 포커스의 b는 선택 커밋 기준 이름 입력창을 연다. 이름 확인 후 생성만 하고 HEAD는 유지한다. Local 더블클릭은 그 브랜치를 체크아웃하며 Remote는 같은 이름 Local 재사용 또는 추적 생성/체크아웃 확인창을 연다. 명시적 확인 전에는 원격 대응 로컬을 생성하지 않는다. 확인창은 enter/ctrl+s/버튼 확인과 esc/취소를 지원하며 실행 중 중복/닫기를 차단한다. 실패는 현재 상태를 재조회하고 작업 변경을 강제로 삭제하지 않는다. Description은 청록 브랜치 배지와 보라 태그 배지 및 기존 제목을 표시한다.
