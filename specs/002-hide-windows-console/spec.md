# 기능 명세: Windows 실행 시 콘솔 창 숨기기

**작성일**: 2026-10-31  
**상태**: 확정  
**입력**: Windows 빌드 실행 파일을 열 때 cmd 창이 뜨지 않도록 한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 그래픽 앱 실행 (우선순위: P1)

Windows 사용자가 빌드된 실행 파일을 열면 Feather Git 창만 나타난다.

**독립 검증**: Windows 빌드 결과를 실행하여 별도 콘솔 창이 나타나지 않는지 확인한다.

**인수 조건**:

1. Windows에서 실행 파일을 직접 열면 Feather Git 창이 열리고 별도 cmd 창은 나타나지 않는다.
2. Windows 이외 운영체제의 빌드 설정은 기존대로 동작한다.

### 경계 사례

- 터미널에서 실행한 경우 이미 열린 터미널은 닫지 않는다.
- 앱 내부에서 별도 프로세스를 실행할 때의 창 관리는 기존 기능의 책임으로 둔다.

## 요구사항

### 기능 요구사항

- **FR-001**: Windows용 주 실행 파일은 그래픽 앱으로 시작되어 별도 콘솔 창을 만들지 않아야 한다.
- **FR-002**: 다른 플랫폼의 실행 시작 방식은 유지해야 한다.

## 성공 기준

- **SC-001**: Windows용 실행 파일을 직접 열 때 별도 콘솔 창이 0개 표시된다.
- **SC-002**: 앱의 기본 창은 정상적으로 표시된다.

## 가정

- 사용자가 말한 cmd 창은 앱 시작과 동시에 뜨는 주 실행 파일의 콘솔 창을 뜻한다.
