# 커밋 그래프 표시 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

커밋 한 행의 입력 간선은 위쪽 경계에서 중앙까지, 출력 간선은 중앙에서 아래쪽 경계까지 그린다. 전체 이력에서 같은 레인 간격을 사용하며 인접 행의 도착·출발 지점과 색상이 이어져야 한다. 노드는 선 위에 그린다. 체크아웃 링은 첫 샘플 행에 유지되며 클릭 선택과 별개이다. 그래프 클릭도 기존 행 선택과 상세 갱신으로 이어진다.

## 행 밀도 및 노드 표시 보완

행 높이는 24px로 줄인다. 노드는 선용 좌표 스냅 대신 별도 물리 경계 정렬을 사용하고, 체크아웃 링은 하나의 둥근 도형 테두리로 동심을 유지한다. 선의 색상·경로와 커밋 선택 계약은 유지한다.
