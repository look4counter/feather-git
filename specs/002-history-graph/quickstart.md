# 실행 및 검증

1. cargo fmt --check, cargo check --offline, cargo test --offline을 실행한다.
2. cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-graph.exe로 빌드한다.
3. 빌드된 앱에서 첫 행의 병합 두 레인과 공통 조상에서 합류하는 곡선, 마지막 루트의 선 종료를 확인한다.
4. 커밋 행을 바꾸어 클릭하고 상세 메시지·해시 갱신 및 첫 행 체크아웃 링 유지를 확인한다.
5. 스크롤과 창 크기 변경, Windows 125%/150% 배율에서 끊김과 잘림을 확인한다. 실제 조작을 하지 않은 항목은 미검증으로 기록한다.

## 조밀한 목록과 노드 확인

커밋 행은 24px이며 선분은 0/12/24px에 이어진다. 원은 배율별 물리 경계에 맞춘 둥근 도형이고 체크아웃 링은 동일 도형의 테두리이다. 100/125/150/175/200% 화면에서 원의 선명도, 제목·배지 잘림과 행 선택을 확인한다.
