# 검증 결과: 기존 프로젝트 방식의 커밋 그래프

## 구현 및 원본 일치

- GraphBuilder::append와 RowGraph 렌더링 본문은 원본에서 모듈·타입명만 조정했다. 공백을 제거한 소스 비교로 두 본문이 원본과 일치함을 확인했다.
- 레인 계산, 곡선 제어점, 팔레트, 체크아웃 링, DPI 보정과 경로 캐시를 유지한다. 현재 앱의 38px 행과 45px 그래프 열을 유지한다.
- 샘플 부모 관계는 분기·병합 및 루트를 포함한다. 기존 메시지·해시·순서와 선택/상세 처리 코드는 유지했다.
- FR-001~005의 구현을 확인했다. 새 외부 의존성이나 저장소 접근, 원본 프로젝트 변경은 없다.

## 자동화 검증

- cargo fmt --check: 통과.
- cargo check --offline: 통과.
- cargo test --offline: 11개 통과. 선형·병합·다중 루트·여러 부모·빈 입력·외부 부모·페이지 연속성, DPI/좁은 열, 샘플 부모 순서 및 기존 탭 테스트 포함.
- cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-graph.exe: 통과.
- 기존 proc-macro-error2의 미래 Rust 호환성 경고 및 별도 출력 경로 관련 안내가 있다.

## 실제 화면 검증 제한

화면 확인 도구가 feather-git-graph.exe 사용을 승인하지 않아 실행/화면 캡처·클릭 검증을 진행하지 못했다. SC-004의 실제 곡선·행 경계·체크아웃 링·선택 상세 동기화와 실제 DPI별 표시를 검증했다고 간주하지 않는다. 자동화로 수학적 좌표 보정만 확인했다.

## 커밋 행 밀도와 노드 선명도 검증

- 수정 전 재현: 기존 원 경계 계산과 ROW_HEIGHT=38에서 신규 픽셀 경계/24px 연결 테스트 2개가 실패했다.
- 수정: 공통 ROW_HEIGHT=24, 커밋 메시지 12px, 원은 GPUI 둥근 quad로 그리고 물리 픽셀 경계·지름에 정렬한다. 체크아웃 링은 같은 도형의 테두리이므로 내부와 외부 원이 동심이다.
- cargo fmt --check, cargo check --offline, cargo test --offline 통과. 테스트 총 13개 통과.
- cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-compact-graph.exe 통과. 기존 의존성 미래 호환성 경고와 출력 경로 안내는 유지된다.
- 100/125/150/175/200% 배율의 원 경계·지름·링 두께 물리 정렬과 선분의 0/12/24px 연결을 검증했다. FR-006~007 및 SC-006은 코드/자동화 검증상 일치한다.
- 앞선 원본 렌더링 본문 동일성 기록은 최초 이식 당시 결과이다. 이번 요구사항에 따라 원 렌더링과 행 높이는 의도적으로 변경했다. 레인 알고리즘과 연결 곡선 계산은 유지한다.
- 기존 화면 도구 미승인으로 실제 픽셀의 시각적 선명도, 제목·배지 잘림 및 클릭 조작은 미검증이다. SC-005의 실제 표시 확인을 완료로 간주하지 않는다.

## 체크아웃 바깥 원 확대 검증

- node_geometry()에서 체크아웃일 때만 외곽 Bounds를 사방 1px에 해당하는 정수 물리 픽셀만큼 확장하고 테두리도 같은 두께만큼 늘렸다. 일반 원과 내부 흰 원 지름, 중심은 유지된다.
- 100%에서 외곽 지름 13px, 내부 지름 7px을 확인했다. 지원 배율별 내부 지름 보존과 물리 픽셀 경계 테스트가 통과했다. FR-008 및 SC-007과 코드가 일치한다.
- cargo fmt --check, cargo check --offline, cargo test --offline 통과. 전체 13개 테스트 통과.
- cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-checkout-ring.exe 통과. 기존 의존성 및 출력 경로 안내만 있다.
- 실제 창 시각 검증은 이전 화면 도구 승인 제한으로 미완료이며 T006/T010에서 확인한다.

## 체크아웃 메시지 강조 검증

- 기록 테스트 11개와 그래프 테스트 10개가 통과했다. 수동 성능 테스트 1개는 제외했다. 캐시된 두 행 사이에서 HEAD를 바꾸면 강조 대상만 이동하고 제목 캐시는 재사용되는 것을 확인했다.
- 전체 대상 검사와 디버그 빌드가 통과했다. 명세와 메시지 요소의 조건부 굵기, 기존 그래프 표시 및 파일 기록 범위를 대조했다. 실제 화면의 글꼴은 검증하지 않았다.
