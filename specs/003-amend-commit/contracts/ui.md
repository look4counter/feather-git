# 화면 계약

커밋 메시지 아래에 마지막 커밋 수정 체크박스를 배치한다. 기본 해제이며 기존 커밋 후 푸시와 독립적으로 동작한다. 탭과 스페이스로 조작 가능하고 처리 중 잠긴다. 오류는 기존 커밋창에 표시한다.

커밋 메시지 입력창은 기존 입력창과 일관된 테두리로 전체 둘레를 표시한다. 빈 상태·입력 상태·처리 중에도 테두리를 유지한다. 여러 줄 입력과 스크롤 동작을 유지한다.

커밋 메시지 래퍼의 내부 여백, 모서리 둥글기 및 배경은 한 줄 입력창과 같아야 한다. 여러 줄 높이는 유지한다.

커밋창에서 입력창 위의 커밋메시지 라벨을 표시하지 않는다.
