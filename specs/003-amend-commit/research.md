# 조사

- 결정: 기존 gix 생성·서명 경로를 재사용한다.
- 근거: 현재 라이브러리와 인덱스 해석을 유지하며 수정 커밋에서도 서명 설정을 적용한다.
- 비교 대안: Git 프로세스 또는 git2 별도 경로는 동작 중복 때문에 선택하지 않는다.
- 결정: 새 부모와 참조 갱신의 예상 이전 HEAD를 분리한다.
- 근거: 수정 커밋의 부모는 교체 대상 자신이 아니라 그 부모다.

## 입력창 테두리 조사

결정: 커밋창에서 편집기 바깥을 기존 LINE 색상의 1픽셀 테두리로 감싼다. 근거: 다른 입력창의 border_1 및 border_color 패턴과 일치하며 공유 편집기의 다른 사용처에 영향을 주지 않는다. 공유 편집기 전체 변경 대안은 요청 범위를 넘으므로 채택하지 않는다.

한 줄 입력창 스타일 기준은 src/settings.rs의 field 함수로 확정했다. 같은 테두리·rounded_sm·p_1·편집기 배경 및 넘침 처리를 재사용하고 여러 줄 입력에 필요한 높이는 유지한다. 고정 높이까지 복사하는 대안은 여러 줄 입력을 제한하므로 제외한다.
