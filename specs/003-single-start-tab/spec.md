# 기능 명세: 단일 임시 새 탭

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.
> 후속 변경 참고: [005](../005-repository-dialogs/spec.md) · [020](../020-remove-sample-projects/spec.md) · [021](../021-persist-workspace/spec.md).
> 현재 기준: 현재 Create/Open/Clone은 실제 작업을 수행하고 시작 탭·최근 저장소·열린 프로젝트 상태를 저장·복원한다. 미연결 데모 및 메모리 전용 설명은 초기 이력이다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1 — 시작 화면 열기 (P1)

사용자가 +를 누르면 프로젝트 탭 뒤에 새 탭이 생기고 활성화된다. 새 탭 본문은 old의 시작 화면처럼 왼쪽 신규 저장소·저장소 열기·Clone 작업과 오른쪽 최근 저장소 영역으로 구성한다. 이미 새 탭이 있으면 새로 만들지 않고 해당 탭을 활성화한다.

### 사용자 이야기 2 — 닫기와 종료 (P1)

새 탭과 프로젝트 탭 사이를 전환하고 새 탭을 닫을 수 있다. 새 탭을 닫은 뒤 +로 다시 열 수 있다. 프로그램을 종료하고 재시작하면 새 탭은 없다.

## 요구사항

- FR-001: + 클릭은 최대 한 개의 새 탭을 만들고 활성화한다. 반복 클릭 및 프로젝트 탭으로 전환 후 클릭도 동일한 탭을 활성화한다.
- FR-002: 시작 화면은 old/src/ui.rs의 start_page처럼 왼쪽 너비 300px/최대 40%의 세 작업과 오른쪽 최근 저장소, 세로 구분선, 20px 여백과 간격을 갖는다. 최근 저장소 데이터가 없으므로 빈 상태를 표시한다.
- FR-003: 새 탭에는 기존 프로젝트 탭과 동일한 오른쪽 구분선, 선택 강조와 닫기 버튼 정책을 적용한다. 새 탭이 활성화되면 프로젝트 툴바와 네 패널 대신 시작 화면을 표시한다.
- FR-004: 새 탭 상태는 메모리에만 두고 저장·복원하지 않는다. 기본 앱 상태에 새 탭은 없다.
- FR-005: 새 탭 닫기 시 열려 있는 기존 프로젝트로 돌아가고, 프로젝트가 없으면 빈 화면을 표시한다. 마지막 프로젝트를 닫아도 새 탭이 열려 있으면 새 탭을 표시한다. 기존 프로젝트 선택·닫기·커밋 상세는 유지한다.
- FR-006: 현재 미연결 데모 범위를 유지한다. 세 작업 버튼은 연결 예정 안내를 표시하며 실제 저장소 생성·열기·Clone을 수행한 것처럼 보이지 않는다. 새 저장소 연동과 최근 목록 영속화는 범위 밖이다.

## 성공 기준

- SC-001: +를 여러 번 누르거나 프로젝트로 전환했다가 눌러도 새 탭 수는 1이다.
- SC-002: 새 탭 열기·전환·닫기·다시 열기와 프로젝트가 0개인 경계 조건에서 유효한 화면을 표시하고 오류가 없다.
- SC-003: 앱 기본 상태를 다시 생성하면 새 탭 상태가 없으며 저장 파일이나 설정 쓰기를 추가하지 않는다.
- SC-004: 포맷·컴파일·자동화 테스트 및 빌드가 통과한다. 실제 화면의 시작 레이아웃과 클릭 검증 여부를 별도 기록한다.

## 가정 및 명확화

화면 구성 요청을 기준으로 old의 시작 화면을 재현한다. old의 여러 빈 탭 및 세션 저장 동작은 사용자 지시대로 단일·비영속 탭으로 대체한다. 기존 프로젝트 탭 데이터와 테마는 유지한다. 범위와 종료 동작을 검토했으며 추가 질문이 필요한 모호성은 없다.

## 시작 버튼 문구와 아이콘

- FR-007: 새 탭 왼쪽의 상단 신규 저장소 라벨을 제거하고 세 버튼 문구를 Create, Open, Clone으로 표시한다. FR-002의 기존 라벨 및 버튼 문구를 대체한다.
- FR-008: 각 버튼 문구 앞에 생성(더하기), 열기(폴더), 복제(겹친 사각형) 아이콘을 표시한다. 아이콘과 문구는 같은 행에서 중앙 정렬하며 버튼 크기·클릭 안내·단일 탭 수명은 유지한다.
- SC-005: 왼쪽에 별도 제목 없이 아이콘과 Create/Open/Clone 세 버튼이 순서대로 표시되며 클릭 안내에도 변경된 문구를 사용한다.
- 명확화: 삭제할 라벨은 왼쪽 상단 제목이며 최근 저장소 제목은 유지한다. 아이콘은 현재 테마를 따르는 16px 선 도형으로 그린다. 추가 모호성은 없다.
