# 검증 결과: 단일 임시 새 탭

## 구현 결과와 명세 일치

- +는 open_start_tab()을 호출해 메모리 상태 두 개만 설정한다. 반복 클릭과 프로젝트 전환 후 재클릭에도 동일한 단일 새 탭만 표시한다.
- 기존 탭 렌더링 순회에 새 탭 항목을 연결하여 오른쪽 구분선, 활성 강조와 닫기 표시 정책을 재사용한다. 새 탭 항목은 PROJECTS 배열로 접근하지 않는다.
- 새 탭 활성 시 old와 같은 왼쪽 300px/최대40% 작업 열과 오른쪽 최근 저장소, 20px 간격/여백 및 구분선을 표시한다. 최근 데이터는 없으므로 빈 상태이다.
- 세 작업은 연결 예정 안내를 표시한다. 저장소 작업이나 세션/파일 저장 코드를 추가하지 않았다.
- 새 탭을 닫으면 이전 프로젝트로 복귀하고 프로젝트가 없으면 빈 화면을 표시한다. 마지막 프로젝트 닫기 시 열려 있는 새 탭을 유지한다.
- 기본 Workspace의 새 탭 상태는 false이며 파일 쓰기나 직렬화를 추가하지 않아 재시작 시 복원되지 않는다. FR-001~006과 코드가 일치한다.

## 자동화 검증

- 신규 상태 테스트를 먼저 추가했을 때 인터페이스 부재로 컴파일 실패를 확인한 후 구현했다.
- cargo fmt --check: 통과.
- cargo check --offline: 통과.
- cargo test --offline: 18개 통과. 신규 5개 상태 테스트와 기존 그래프/탭 테스트 포함.
- cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-start-tab.exe: 통과.
- 기존 proc-macro-error2 미래 호환성 경고와 별도 출력 파일 경로 안내가 있다.

## 미검증 범위

이전 화면 도구의 실행 파일 사용 승인 제한으로 실제 창의 시작 화면 배치, +/닫기/버튼 클릭 및 프로세스 종료·재실행은 직접 확인하지 못했다. 단일 탭/닫기/재시작에 해당하는 상태 전이는 자동화 테스트로 확인했다. 실제 화면 확인을 완료로 간주하지 않는다.

## 시작 버튼 문구와 아이콘 검증

- 왼쪽 신규 저장소 제목을 제거하고 버튼 문구를 Create/Open/Clone으로 변경했다. 각 버튼 앞에 16px 더하기/폴더/겹친 사각형 아이콘과 8px 간격을 적용했다. 클릭 안내도 같은 문구를 사용한다.
- 아이콘은 GPUI 캔버스 경로로 그리며 현재 글자 색상을 상속한다. 플랫폼 글꼴이나 외부 이미지 의존성은 추가하지 않았다.
- cargo fmt --check, cargo check --offline, cargo test --offline 통과. 기존 18개 테스트 모두 통과했다.
- cargo rustc --offline --bin feather-git -- -o target/debug/feather-git-start-icons.exe로 별도 실행 파일을 빌드했다.
- 코드 검토상 FR-007~008과 SC-005의 표시 조건에 일치한다. 기존 단일 탭·닫기·비영속 상태는 유지된다.
- 실제 창의 아이콘 배치와 호버 색상은 기존 화면 도구 승인 제한으로 미검증이다.
