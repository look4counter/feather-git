# 구현 계획: 푸시 확인창

날짜: 2026-11-01
명세: [기능 명세](spec.md)

## 요약과 기술 문맥
Rust 2024, GPUI 0.2.2, gix 0.87.1, git2 0.21을 사용한다. 기존 BranchDialog 공통 모달에 푸시 액션을 추가하여 키보드·취소·오류·실행 잠금을 재사용한다. src/setup.rs에서 추적 설정과 원격 추적 객체를 읽는 PushPlan을 만들고, 기존 네이티브 명시적 lease 푸시 경로를 이용한다.

## 규칙 확인
헌법은 미작성 템플릿으로 확정 원칙이 없다. 한글 문서와 전체 speckit 단계를 준수한다. 설계 전후 위반 없음.

## 구조와 단계
- src/setup.rs: PushPlan에 로컬 참조, 원격, 목적지, 예상 원격 객체를 고정하고 실행 시 로컬 브랜치와 추적 설정이 같은지 확인한다.
- src/ui.rs: BranchAction::Push와 옵션 화면, 포커스, 일반 푸시 진입 연결을 추가한다.
- src/ui.rs: 커밋 작업에서는 커밋만 수행하고 성공 후 요청한 저장소의 PushPlan을 가진 확인창을 표시한다.
- src/native_remote.rs: 기존 명시적 lease 협상과 강제 refspec을 재사용한다.

## 검증
cargo test --bin feather-git push 및 cargo check --all-targets를 실행한다. 로컬 bare 저장소를 이용해 일반 푸시 거절, 예상과 일치하는 수정 커밋 강제 푸시 성공, 다른 원격 변경의 거절을 검증한다. 확인 전 실행은 UI의 제출 경로를 검토한다.

## 푸시창 문구와 버튼 간소화

명확화 점검 결과 설명 삭제 범위는 대상 안내·확인 질문·옵션 도움말이며 오류 문구는 유지한다. 추가 질문이 필요한 모호함은 없다. src/ui.rs 렌더링의 세 문구를 삭제하고 Push를 기존 minimal 조건에 추가해 취소 버튼을 숨긴다. Escape 및 창 바깥 클릭으로 닫는 동작은 재사용한다. 데이터와 네이티브 푸시 계약은 변경하지 않는다. 검증은 컴파일·서식 검사 및 렌더링 경로 검토로 수행한다. 규칙 위반 없음.
