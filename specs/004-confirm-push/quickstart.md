# 검증 안내

1. cargo test --bin feather-git push 실행으로 로컬 원격의 일반·조건부 강제 푸시를 확인한다.
2. cargo check --all-targets로 화면과 네이티브 연결을 검증한다.
3. 앱에서 푸시 요청 시 확인창이 열리고 취소하면 원격이 그대로인지 확인한다.
4. 마지막 커밋 수정과 커밋 후 푸시를 함께 선택하면 수정 커밋 완료 후 푸시 확인창이 나타나야 한다.
5. 탭·스페이스로 옵션을 선택하고 확인 단축키로 제출한다. 실행 중 중복 입력을 차단해야 한다.

## 제한된 환경에서의 임시 폴더

시스템 임시 폴더 접근이 제한되면 다음과 같이 작업공간 내부 임시 폴더를 지정한 뒤 검증한다.

```powershell
New-Item -ItemType Directory -Force .build/test-temp | Out-Null
$env:TEMP = (Resolve-Path .build/test-temp).Path
$env:TMP = $env:TEMP
cargo test --bin feather-git setup::tests
```
