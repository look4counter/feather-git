# 설정 팝업과 서비스 계약

각 버튼은 동일 모달의 해당 모드를 연다. Clone만 소스 경로를 먼저 표시한다. 탐색은 실제 대상 폴더를 선택한다. 경로 수정은 이름을 마지막 폴더명으로 덮어쓰고 이름 직접 수정은 경로를 바꾸지 않는다.
확인 중 중복 제출을 막고 검증 실패는 입력을 유지한 Alert로 알린다. 성공 시 새 탭을 닫고 Project를 활성화한다. Open 성공도 Create/Clone과 동일하게 Alert 없이 바로 프로젝트를 표시한다. 이미 열린 canonical 경로는 기존 프로젝트를 선택한다. Git 실패 후 사용자 파일 삭제를 수행하지 않는다.
