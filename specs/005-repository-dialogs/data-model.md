# 데이터 모델

- Operation: Create/Open/Clone. 타이틀과 필드 구성을 결정한다.
- Request: 모드, 소스, 실제 경로, 표시 이름. 확인 시 입력을 스냅샷으로 고정한다.
- Project: 표시 이름, 선택적 실제 경로, 현재 브랜치/HEAD, 브랜치/원격 목록, 커밋과 변경 파일, 추가 이력 여부. 실제 경로 없음은 기존 데모이다.
- Commit: 전체 ID, 부모 ID, 메시지·요약, 작성자, 날짜, 참조. 그래프 입력으로 변환한다.
- RepositoryDialog: 3개 텍스트 입력 Entity, 모드, busy, 변경 구독과 포커스. 경로 변경만 이름 자동 갱신 이벤트를 만든다.
- Workspace: 동적 프로젝트와 폼/Alert, 현재 선택 및 렌더링 그래프. 성공 후 폼·새 탭을 닫고 실제 프로젝트를 활성화한다.
