# 조사

- 결정: 기존 windows 라이브러리의 비동기 ReadDirectoryChangesW를 사용한다.
- 근거: 파일 트리 정기 스캔 없이 운영체제 알림을 수신하고 취소·완료 대기로 버퍼 수명을 보장한다.
- 대안: 전체 파일 폴링은 빌드·대형 저장소 부하가 크며 외부 감시 라이브러리 추가는 기존 플랫폼 의존성으로 대체 가능하다.
- 결정: git2 인덱스와 ignore 판정을 백그라운드에서 사용한다.
- 근거: 추적 파일은 ignore 규칙과 무관하게 반영하고 미추적 빌드 결과는 제외한다. ignore 파일 이벤트는 자체적으로 갱신을 유발한다.
- 결정: 자동 반영은 기존 수동 reload와 분리한다.
- 근거: 기존 reload는 선택과 Diff를 초기화하므로 자동 반영에서 재사용하면 사용자 탐색을 방해한다.
