# 구현 계획: 깃털 아이콘

## 요약

단일 SVG 실루엣과 투명한 중심 여백으로 간결한 브랜드 상징을 제공한다.

## 기술 맥락

64×64 viewBox, 단일 복합 경로, 짝홀 채움 규칙과 currentColor를 사용한다.
의존성과 앱 연결은 없다. 결과는 assets/branding/feather-git-icon.svg에 저장한다.
검증용 비교 이미지는 시각 확인 후 사용자 요청에 따라 정리했다.

## 헌장 확인

헌장은 미작성 템플릿으로 규칙 검사를 생략한다. 한글 문서와 speckit 순서를 준수한다.

## 단계

1. 조사: 굵은 외곽과 중심 여백으로 작은 크기 식별성을 확보한다.
2. 설계: 정적 자산의 크기, 색상, 독립 사용 계약을 정의한다.
3. 구현: SVG를 작성하고 밝고 어두운 배경의 축소 렌더링을 확인한다.

## 구조

- assets/branding/feather-git-icon.svg: 최종 아이콘
- specs/006-feather-icon/: 명세, 계획, 작업과 사용 안내
- 비교용 미리보기는 검증 완료 후 삭제했다.

## 검증

XML 파싱과 경로 수, 외부 참조 부재를 확인한다.
24, 32, 128픽셀 렌더링을 육안으로 확인한다.
