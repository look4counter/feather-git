# 입력 계약

1. `쿼` 확정 → `리` 조합 → 종료 → 일반 `I`, `D`: `쿼리ID`.
2. `리` 조합 → 확정 `리` → 종료와 종료 → 확정 `리` 순서 모두 글자가 중복되지 않는다.
3. 이전 조합 결과와 다음 조합 문자열이 함께 오면 결과 뒤에 다음 조합이 붙는다.
4. 취소는 미확정 조합만 제거한다.
5. 종료 후 방향키·삭제·선택·일반 입력에 이전 조합 표시가 영향을 주지 않는다.
6. 문자열 위치는 기존 UTF-16/UTF-8 변환 계약을 유지한다.

## 추가 검증 계약

네이티브 조합이 남은 상태에서 일반 문자가 도착하면 입력기의 조합 확정을 먼저 수행한다. 조합 결과를 현재 조합 영역에 적용한 다음 일반 문자를 삽입한다. 네이티브 조합이 없으면 확정을 요청하지 않는다. 뒤늦은 한글이 영문 뒤에 중복 삽입되지 않아야 한다.
