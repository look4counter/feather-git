# 입력 상태 모델

- 창별 조합 상태: 종료 알림을 받았으나 후속 입력 여부가 아직 결정되지 않은지 나타낸다.
- 편집 버퍼: 기존 문자열·UTF-8 커서·선택 영역·조합 영역을 유지한다.
- 종료 이벤트: 버퍼 내용을 바꾸지 않고 종료 상태를 기록한다.
- 후속 일반 입력·새 조합·마우스 조작: 종료 상태가 있으면 기존 조합 표시를 해제한다.
- 확정 결과: 기존 조합을 교체하고 종료 대기 상태를 제거한다.
- 확정과 새 조합 동시 전달: 확정 후 새 조합을 적용한다.
- 취소: 기존 조합을 빈 문자열로 교체하고 종료 대기 상태를 제거한다.
