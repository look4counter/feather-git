# 데이터 모델

- ProgressOverlay: 표시 메시지. 작업/저장소 상태는 보관하지 않는다.
- DialogActivity: Idle(입력 가능/진행 숨김), Browsing(입력 잠금/진행 숨김), Working(입력 잠금/진행 표시).
- 작업 결과: 현재 폼이 여전히 유효할 때 기존대로 상태를 해제하거나 폼을 닫는다.

## Dialog 표시 모델

Dialog는 ID, 제목, 너비, 본문/버튼/선택적 overlay 요소와 포커스/키 콜백을 받는다. 업무 상태는 담지 않는다. 본문 호스트는 타이틀바 다음 flex 영역이며 모든 모달은 이 영역에 상대 배치된다.

## 깃털/물결 장면 모델

FeatherWaterScene의 phase는 0~1이고 GPUI 프레임 스케줄러가 약 2.8초마다 반복한다. 접촉 phase 0.52에서 깃털 줄기 끝이 수면 높이에 도달하며 이후 3개 물결이 시간차로 확산/투명화된다. ProgressOverlay의 기존 문자열 인수는 작업별 애니메이션 식별자로 유지하고 화면 텍스트로 출력하지 않는다.
