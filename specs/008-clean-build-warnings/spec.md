# 기능 명세: 빌드 경고 정리

**기능 식별자**: `008-clean-build-warnings`
**작성일**: 2026-11-03
**상태**: 검토 완료
**요청**: 빌드 때 반복 출력되는 경고를 정리한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 경고 없는 빌드 (우선순위: P1)

개발자는 현재 지원하는 Windows 환경에서 빌드하고 실제 조치가 필요한 진단을 구분할 수 있다.
**우선순위 이유**: 반복되는 경고가 실제 결함을 가린다.
**독립 검증**: 개발용·배포용 빌드와 기존 입력 회귀 검증을 실행해 성공 여부와 경고 수를 확인한다.

1. 현재 빌드를 실행하면 알려진 타입 추론 경고와 향후 호환성 경고가 나오지 않는다.
2. 배포용 빌드도 성공하고 동일한 경고가 없다.
3. 기존 입력 편집 기능과 실행 파일의 기존 네이티브 내보내기 정보가 보존된다.

### 경계 조건

- 다시 빌드해도 경고가 되살아나지 않는다.
- Windows 전용 빌드 설정이 다른 플랫폼에 적용되지 않는다.
- 기존 의존성 라이선스와 앞선 한글 입력 수정은 보존한다.
- 실제 컴파일·링크 오류를 전역으로 숨기지 않는다.

## 요구사항

- **FR-001**: 현재 빌드에서 관측된 수치 타입 추론 경고의 원인을 제거한다.
- **FR-002**: 의존성의 향후 컴파일 오류로 이어질 비공개 항목 재공개 문제를 해결한다.
- **FR-003**: 실행 파일의 불필요한 링크 산출물 생성 안내가 경고로 반복 출력되지 않도록 정리한다.
- **FR-004**: 기존 입력 회귀 검증과 실행 파일의 네이티브 내보내기 정보를 보존한다.
- **FR-005**: 수정 의존성은 저장소에서 재현 가능하며 출처와 라이선스를 유지한다.

## 성공 기준

- **SC-001**: 개발용·배포용 빌드가 성공하고 알려진 경고 및 향후 호환성 경고가 0건이다.
- **SC-002**: 기존 입력 회귀 검증 15개가 모두 통과한다.
- **SC-003**: 수정 후 실행 파일의 기존 네이티브 내보내기 항목이 유지된다.

## 가정과 명확성 검토

현재 도구 체인과 의존성 버전을 유지한 최소 수정으로 처리한다. 경고 전역 차단은 하지 않는다. 범위·동작·성공 기준이 명확하여 추가 질문은 필요하지 않다. 화면과 저장 데이터 형식 변경은 범위 밖이다.
