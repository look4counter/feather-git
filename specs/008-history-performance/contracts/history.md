# 이력 표시 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

행 높이 24px, 원/링·색상·부모 관계는 유지한다. 가상 목록이 요청한 범위만 행을 준비하고 헤더/본문은 동일 그래프 너비를 공유한다. 레인 간격은 압축하지 않으며 부족한 가로 공간은 표 전체 스크롤로 제공한다. 프로젝트의 새 데이터가 들어오면 해당 캐시/스크롤만 초기화하고 다른 프로젝트는 유지한다.
