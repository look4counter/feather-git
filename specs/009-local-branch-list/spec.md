# 기능 명세: 로컬 탭의 브랜치 표시

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.
> 후속 변경 참고: [010](../010-panel-tab-buttons/spec.md) · [028](../028-independent-repository-tabs/spec.md) · [080](../080-history-revert-reset/spec.md).

## 사용자 시나리오

저장소 패널의 로컬 표시가 활성화된 화면에서 로컬 브랜치만 확인한다. 로컬과 원격이 모두 존재하더라도 원격 저장소 제목과 원격 항목은 표시되지 않는다.

## 요구사항

- FR-001: 현재 로컬이 활성 표시된 저장소 패널은 Project.branches만 렌더링하고 Project.remotes 및 원격 저장소 섹션을 표시하지 않는다.
- FR-002: 현재 브랜치 강조, 현재 배지 및 로컬 브랜치가 없는 경우의 안내를 유지한다. 원격 데이터 자체와 저장소 로딩은 변경하지 않는다.
- SC-001: 로컬 패널 렌더링 코드에 원격 목록/제목 생성이 없고 로컬 목록과 빈 상태가 유지되어야 한다.
- SC-002: 포맷, 컴파일, 기존 테스트가 통과해야 한다.

## 명확화

현재 탭 행은 클릭 동작 없이 로컬만 활성 표시하는 UI다. 이번 요청은 이 화면의 로컬/원격 혼합 표시 수정으로 한정한다. 원격·태그·스태시 탭의 새 동작은 추가하지 않는다. 추가 구현 모호성 없음.
