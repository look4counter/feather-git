# 인증 입력 및 요청 계약

주소 입력 안내는 HTTP/HTTPS 지원을 표시한다. 등록과 로그인은 HTTP 또는 HTTPS의 호스트가 있는 URL만 허용하며 기존 사용자 정보·쿼리·프래그먼트·제어문자 검증을 유지한다.

Git 자격 증명 요청의 protocol 값은 입력 URL의 스킴이다. host는 포트를 포함하며 path와 선택적 username을 유지한다. 줄바꿈 주입은 거부한다. 기존 HTTP 자격 증명은 HTTPS와 동일한 가져오기·삭제 경로를 사용하되 프로토콜별로 분리한다.

원격 URL에 포함된 ID는 계정 선택 조건이며 주소 범위 비교에서는 사용자 정보를 분리한다. 콜백에서 받은 계정과 URL 계정이 충돌하면 등록 인증을 반환하지 않는다. 등록 URL 입력의 사용자 정보 금지는 유지한다. 프로토콜·포트·경로 경계도 유지한다.
