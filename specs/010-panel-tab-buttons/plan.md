# 구현 계획: 패널 탭

## 기술 배경 및 기존 구조 분석
Rust 2024와 GPUI 0.2.2를 사용한다. src/ui.rs의 Workspace가 선택과 렌더링을 담당하고 src/repository.rs가 git2 데이터 접근을 담당한다. branches와 files의 탭은 현재 고정 텍스트이며 클릭이 없다. Project에는 로컬·원격·작업 파일만 있고 태그·스태시·커밋 파일은 없다. 기존 메타데이터를 재사용하고 추가 조회는 repository 계층의 읽기 함수로 제공한다.

## 설계 및 영향 범위
src/ui.rs에 두 선택 상태와 조회 결과를 추가한다. 공통 버튼 렌더러로 스타일과 클릭 처리를 통일한다. 탭 클릭, 프로젝트 선택 및 활성화, 커밋 선택 시에만 추가 데이터를 갱신하여 렌더 루프의 디스크 접근을 피한다. prepare_history에서 프로젝트 전환에 맞춰 갱신한다. src/repository.rs에 태그·스태시와 선택 커밋의 첫 부모 대비 파일 차이를 읽는 함수를 추가한다. 최초 커밋은 빈 트리 대비 변경을 사용한다. 네트워크·쓰기·새 의존성은 없다.

## 헌법 점검
현재 헌법은 미작성 템플릿으로 규범 검사는 생략한다. 기존 UI→저장소 의존 방향과 공개 Project 형식을 유지한다. 설계 전후 아키텍처 충돌 없음.

## 검증 계획
실제 임시 저장소에서 태그·스태시 및 최초/후속 커밋 파일 차이와 오류를 검증한다. 전체 cargo test, cargo check, cargo fmt --check를 실행한다. 실제 화면 검증 여부는 별도로 보고한다.
