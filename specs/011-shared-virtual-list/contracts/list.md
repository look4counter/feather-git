# 목록 표시 계약

세 목록의 행 순서·높이·강조·내용은 기존과 같다. 파일 경로 말줄임과 상태 색상을 유지한다.
제목·탭·빈 상태·오류는 가상화된 행 밖에서 표시한다. 저장소와 파일의 목록 부모는 남은 높이에 맞추며 이중 세로 스크롤을 만들지 않는다.
커밋 기록은 기존 선택, 가로 스크롤, 그래프 캐시와 프로젝트별 스크롤을 유지한다.
공통 함수는 요청된 범위만 렌더러에 전달하고 전체 데이터를 순회하지 않는다.

## 행 선택 계약

공통 목록이 행 클릭·선택 배경·호버를 제공한다. 콜백에는 절대 인덱스를 전달하며 행 생성은 여전히 가시 범위에 한정한다. 선택은 단일 선택이다. 저장소의 현재 브랜치 글자색과 배지는 선택 여부와 독립적이다. 파일·저장소 클릭은 Git 작업을 실행하지 않는다.

선택 배경은 호버보다 우선한다. 왼쪽 버튼을 누를 때 선택 콜백을 호출하고 오른쪽·가운데 버튼과 버튼 해제에서는 선택하지 않는다.

모든 행은 공통 ROW_HEIGHT=24픽셀을 사용하며 개별 높이 인자는 없다. 내용과 선택 배경·입력 영역은 같은 높이를 사용한다. 커밋 그래프도 같은 정의를 공유한다.
