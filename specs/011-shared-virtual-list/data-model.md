# 데이터 모델

기존 Project, ChangedFile, HistoryState를 변경하지 않는다.
공통 목록은 ElementId, usize 항목 수, Range<usize> 렌더러로 구성된다. 목록이 행 데이터를 소유하지 않는다.
목록 식별자는 종류·프로젝트·패널 탭으로 구분한다. 커밋 기록의 기존 프로젝트별 스크롤 핸들을 그대로 전달한다.
범위는 현재 개수 이하로 제한하며 빈 범위에서는 행 생성 함수를 호출하지 않는다.

## 선택 상태

SingleSelection은 선택 인덱스 Option<usize>를 소유하고 현재 개수로 검증한다. 저장소와 파일은 서로 다른 상태이며 데이터 갱신에서 해제된다. 커밋은 기존 Workspace.commit을 제어형 선택값으로 사용한다.

목록 외곽이 공통 ROW_HEIGHT=24픽셀을 적용하고 내용은 부모 높이를 따른다. 호출자별 높이 속성은 없다.
