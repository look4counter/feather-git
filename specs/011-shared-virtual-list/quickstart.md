# 검증 안내

프로젝트 루트에서 cargo test, cargo check, cargo fmt --check, cargo clippy --all-targets를 실행한다.
범위 테스트는 10만 항목, 빈 항목, 단일 항목, 마지막 범위, 데이터 감소와 범위 초과를 포함한다.
수동 확인은 cargo run 이후 저장소의 모든 탭과 파일의 작업 트리·히스토리를 전환하고 현재 브랜치 강조·상태·경로·빈 메시지를 확인한다. 긴 목록을 끝까지 스크롤하고 프로젝트 전환 후 커밋 그래프·선택·가로 스크롤을 확인한다.
실제 GUI 확인을 하지 못하면 자동 테스트 결과와 구분하여 명시한다.

행 선택 확인: 세 목록에서 서로 다른 행을 클릭하여 하나의 선택만 표시되는지 확인한다. 현재 브랜치 배지가 선택과 무관하게 유지되는지, 파일 선택이 저장소 선택에 영향을 주지 않는지 확인한다. 탭·프로젝트·커밋 전환 후 패널 선택이 해제되고 커밋 상세·히스토리 파일이 갱신되는지 확인한다.

선택 우선순위 확인: 세 목록에서 왼쪽 버튼을 누른 채 유지하여 버튼을 놓기 전에 선택되는지 확인한다. 선택 행에 포인터를 올려도 선택 배경이 유지되고 다른 미선택 행에는 호버 배경이 표시되는지 확인한다. 오른쪽·가운데 버튼과 왼쪽 버튼 해제는 선택을 다시 실행하지 않아야 한다.

행 높이 확인: 세 목록의 공통 높이(모두 24픽셀)와 커밋 그래프의 행 경계 연결을 확인한다. 선택 배경과 마우스 누름 영역이 행 전체를 덮는지 확인한다.
