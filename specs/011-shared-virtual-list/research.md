# 조사 결과

## 결정

기존 GPUI uniform_list를 감싸는 작은 함수형 공통 컴포넌트를 사용한다. 저장소와 파일은 데이터 전체를 캡처·복제하지 않고 cx.processor에서 현재 데이터의 요청 범위만 읽는다.

## 근거

vendor/gpui/src/elements/uniform_list.rs는 첫 행 측정과 보이는 범위의 지연 렌더링을 제공한다. 커밋 기록은 이미 이 방식과 HistoryState 캐시를 사용하므로 별도 가상화 엔진이 필요 없다. UniformList가 Styled 및 track_scroll을 제공하여 기존 설정도 유지할 수 있다.

## 대안

전체 children 순회는 요청 목적에 맞지 않는다. 별도 엔티티와 데이터 소유 계층을 도입하면 캐시와 비즈니스 책임이 중복된다. 가변 높이 List는 기존 일정 높이 행에 필요하지 않다. 미해결 기술 질문은 없다.

## 행 선택 설계

제어형 선택 인덱스와 콜백을 받는 공통 컨테이너로 선택 상호작용을 이동한다. 도메인 후속 처리는 Workspace에 유지한다. 행별 콜백 복제 대신 Rc 공유를 사용한다. 별도 엔티티나 전역 상태는 도입하지 않는다.

## 선택 이벤트 조사

GPUI의 on_mouse_down은 MouseButton을 받아 버튼 누름 이벤트에 리스너를 등록한다. 기존 text_input도 왼쪽 버튼에 이 API를 사용한다. 선택 행에서 hover 등록을 생략하면 선택 배경이 유지되며 추가 상태가 필요 없다.

## 행 높이 조사

GPUI uniform_list는 첫 행 높이를 측정한다. 공통 외곽 행에 높이를 지정하면 측정·선택 배경·입력 영역이 일치한다. 자식은 h_full로 따르게 한다. 그래프의 기존 상수는 공통 상수를 재노출하여 값 중복과 호출자 호환성 변경을 피한다. 가변 높이 목록이나 새로운 스타일 계층은 필요 없다.

## 최신 결정: 높이 통일

개별 높이 요구가 사라졌으므로 사용하지 않는 높이 인자를 유지하지 않는다. 공통 목록이 ROW_HEIGHT=24를 직접 적용하여 모든 호출자가 같은 값을 자동으로 사용하게 한다. 앞선 36/35 유지 결정은 폐기한다.
