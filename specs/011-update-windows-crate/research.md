# 조사 결과

## 결정

직접 windows 의존성만 0.62.2로 올리고 기존 기능 플래그를 유지한다.

## 근거

Cargo.toml은 0.61을 선언하며 Cargo.lock은 직접 의존성을 0.61.3으로 해석한다. GPUI 등도 0.61 계열을 사용하므로 전이 의존성 버전을 강제 통일하지 않는다. Cargo의 해석 결과와 실제 Windows 컴파일로 호환성을 확인한다.

## 검토한 대안

전체 전이 의존성 업그레이드는 요청 범위를 넘어 제외한다. 새 테스트 코드는 추가하지 않고 기존 대상 전체 컴파일로 타입 호환성을 검증한다. 미해결 조사 항목은 없다.
