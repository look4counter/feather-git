# 기능 명세: Windows 크레이트 업데이트

**작성일**: 2026-11-05
**상태**: 검토 완료
**요청**: windows crate를 0.62.2로 변경한다.

## 사용자 시나리오 및 검증

### 사용자 스토리 1 — 의존성 업데이트 (우선순위: P1)

개발자는 지정된 Windows 의존성 버전으로 애플리케이션을 빌드할 수 있다.

**우선순위 이유**: 사용자가 지정한 버전으로 개발 환경을 일치시킨다.
**독립 검증**: 잠금 파일의 직접 의존성 버전을 확인하고 Windows 대상 컴파일 검사를 실행한다.

**인수 시나리오**:

1. 의존성을 해석하면 직접 사용하는 windows 버전은 0.62.2이다.
2. 업데이트 후 기존 Windows 기능을 포함한 컴파일 검사가 성공한다.

### 경계 조건

- 전이 의존성이 요구하는 다른 windows 버전은 공존할 수 있다.
- 호환성 문제는 기존 동작을 유지하는 최소 수정으로 해결한다.
- 환경 제약으로 검증이 실패하면 원인과 미검증 범위를 기록한다.

## 요구사항

### 기능 요구사항

- **FR-001**: 직접 windows 의존성을 0.62.2로 변경한다.
- **FR-002**: 잠금 파일에 직접 의존성의 0.62.2 해석 결과를 반영한다.
- **FR-003**: 기존 기능 플래그와 Windows 동작을 유지한다.

## 성공 기준

- **SC-001**: 직접 의존성과 잠금 파일에서 지정 버전이 일치한다.
- **SC-002**: Windows 대상 컴파일 검사에 오류가 없다.

## 가정

- 다른 패키지의 독립적인 업그레이드는 범위에 포함하지 않는다.
- 기존 사용자 수정은 보존한다.
- 명확화 검토 결과 추가 질문이 필요한 모호함은 없다.
