# 조사 결과

결정: 참조 메타데이터를 유지하고 UI에서 원격 아이콘을 표시한다.
근거: 실제 원격 분류는 Git 참조 종류에 있고 현재 문자열 결합 이후에는 분류할 수 없다. 쉼표 분리나 origin 문자열 비교는 로컬·태그·쉼표 포함 이름을 잘못 처리한다.
대안: 기존 reference 필드 교체는 불필요한 호환성 변경이다. 기존 문자열을 유지하고 메타데이터를 추가한다. 새 아이콘 패키지 대신 기존 텍스트 UI 방식에 맞춰 유니코드 구름 기호를 사용한다.
원격 별칭에 슬래시가 있을 수 있으므로 등록 이름의 가장 긴 일치 접두사를 우선한다. 등록 정보가 없는 refs/remotes 참조도 기존처럼 분류하며 관례적 첫 구성요소를 제거한다. 미해결 기술 질문은 없다.
