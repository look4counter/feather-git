# 조사 결과

결정: 기존 참조 메타데이터와 커밋 선택 함수를 재사용하고 전체 참조 경로만 추가한다. 단축 이름이나 원격 여부만으로는 로컬·태그 동명을 구별할 수 없다.
기존 스크롤 핸들의 scroll_to_item과 Center 전략을 사용한다. 새 스크롤 또는 선택 컴포넌트를 만들지 않는다.
기본 200개 기록을 유지하되 대상이 없을 때 선택한 참조를 커밋으로 해석해 대상까지 확장한다. 전체 이력을 처음부터 항상 로드하거나 없는 대상을 조용히 무시하는 방식은 요구와 성능에 맞지 않는다.
주석 태그는 peel_to_commit으로 처리하고 비커밋 태그는 오류로 보고한다. 로컬 저장소 읽기만 수행한다. 미해결 기술 질문은 없다.
