# 검증 결과: 저장소 패널과 커밋 선택 연동

검증일: 2026-11-13.

## 단계별 검증

명세 품질 점검 8/8 통과. 명확화 질문 0개. 명세·계획·작업 일관성 분석에서 요구사항 5개가 모두 7개 작업에 대응하며 누락·중복·모순은 없었다. 헌법은 미작성 템플릿이므로 선언된 원칙 검사를 생략하고 AGENTS.md의 기존 계층·호환성·최소 변경 제약을 적용했다.

## 구현 및 추적성

- FR-001, SC-001: src/ui.rs의 branches에서 탭과 목록 사이 종류 라벨을 제거했다. 목록 이름과 아이콘 본문은 커밋 메시지와 같은 TEXT 색이다. 현재 브랜치 배지·빈 상태·오류 메시지는 유지했다.
- FR-002: CommitReference.full_name으로 정확한 로컬·원격·태그 경로를 구별하고 해당 커밋 인덱스를 찾아 기존 select_history_row로 선택한다. 이 과정에서 상세 및 히스토리 파일을 갱신한다.
- FR-003: 기존 스크롤 핸들에 scroll_to_item(Center)을 요청한다. 로드 범위 밖 대상은 repository::reference_snapshot이 참조를 최종 커밋으로 해석하여 대상까지 기록을 확장한다. 기본 로드는 200개로 유지한다. 태그 전용 이력도 처리한다.
- FR-004: 선택 과정의 패널 갱신 후 저장소 선택을 복원한다. 확장 시 그래프 캐시를 재구성하되 기존 세로·가로 스크롤 핸들을 재사용하여 가로 위치를 유지한다. checkout이나 Git 쓰기 작업은 없다. 기존 아이콘·공통 목록 코드는 변경하지 않았다.
- FR-005: 프로젝트·탭·시작 화면·열린 프로젝트·인덱스를 검사한다. 스태시는 기존 행 선택만 한다. 대상 조회 실패 시 상태 표시줄에 원인을 표시하고 현재 커밋을 유지한다.

## 자동 검증

참조 조회 및 UI 선택 테스트를 먼저 추가하고 함수·메서드 부재로 실패한 것을 확인한 뒤 구현했다.

- 실제 저장소 테스트: 동명 로컬·원격·태그, 경량·주석 태그, 200개 밖 대상, 태그 전용 이력, 없는 참조·비커밋 태그 오류, HEAD 불변.
- Workspace 테스트: 참조 종류별 정확한 선택·스크롤 요청·기존 파일 갱신, 동일 행 반복 선택, 강조 복원, 시작 화면·닫힌 프로젝트·다른 탭·인덱스 가드, 스태시 제외·샘플 대상 없음.
- 실제 저장소와 Workspace 통합 테스트: 오래된 주석 태그 선택 시 200개에서 기록 확장·대상 선택·파일 갱신·강조 복원·스크롤 핸들과 가로 위치 보존. 비커밋 태그 오류 시 선택 커밋 유지. HEAD와 작업 트리 파일 불변.
- cargo test --quiet: 67개 통과, 실패 0개, 기존 수동 성능 측정용 2개 제외.
- cargo check, cargo fmt --check, cargo clippy --all-targets: 통과. 기존 vendor 실수 리터럴·테스트 초기화·proc-macro-error2 향후 호환성 경고는 남아 있고 새 코드 경고는 없다.
- cargo rustc --bin feather-git -- -o target/feather-git-repository-history-selection.exe: 컴파일·링크 성공.

## 미검증 사항

실제 GUI에서 라벨·글자색·스크롤 배치를 직접 확인하지 않았다. 소스 검토와 자동 테스트에서 스크롤 요청 및 선택 상태를 확인했다. Git 메타데이터가 없어 git diff/status는 사용하지 못한다.
