# 아이콘 표시 계약

로컬은 브랜치 기호, 원격은 구름, 태그는 태그 기호를 사용한다. 커밋 배지와 저장소 패널은 같은 매핑을 사용한다. 미상 종류는 아이콘 없이 이름을 보존한다. 스태시 표시는 기존대로 유지한다. 원격 접두사 축약·이름·본문색·현재 배지·행 높이·선택 동작은 유지한다.

로컬 브랜치는 굵은 연결선과 채워진 원형 노드의 공통 벡터 아이콘으로 표시한다. 배지의 아이콘은 고정 크기를 유지하고 이름만 말줄임한다. 원격·태그는 기존 기호를 유지한다.

로컬 아이콘의 최신 결정은 컴퓨터 화면·받침대·발판 형태이다. 기존 공통 벡터 뷰를 재사용하고 브랜치 렌더러는 사용하지 않는다. 원격·태그 기호는 유지한다.
