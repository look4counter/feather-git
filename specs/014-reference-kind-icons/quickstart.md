# 검증 안내

cargo test, cargo check, cargo fmt --check, cargo clippy --all-targets를 실행한다. 실제 저장소와 샘플에서 로컬·원격·태그의 커밋 배지와 패널 아이콘이 일치하는지 확인한다. 동명 참조와 origin 포함 로컬 이름도 확인하고 선택 연동·스크롤·현재 배지가 유지되는지 확인한다. 직접 GUI 확인 여부는 별도 기록한다.

브랜치 형태 개선 확인: 커밋 배지와 저장소 목록에서 로컬 아이콘이 굵은 연결선과 채워진 원형 노드로 같은 모양을 사용하는지 확인한다. 긴 이름에서 아이콘이 잘리거나 축소되지 않고 이름만 말줄임되는지 확인한다.

최신 로컬 표시 확인: 커밋 배지와 저장소 목록에서 기존 브랜치 모양 대신 화면·받침대가 있는 컴퓨터 아이콘을 사용하는지 확인한다. 원격 구름과 태그 아이콘은 기존대로인지 확인한다. 앞선 브랜치 형태 시각 검증 조건은 이 조건으로 대체한다.
