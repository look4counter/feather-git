# 조사 결과

전체 참조 경로는 이미 이전 작업에서 보존되어 있어 새 Git 조회 없이 종류를 구분할 수 있다. 이름의 v 접두사나 origin 포함 여부로 태그·원격을 추측하면 오인하므로 네임스페이스만 사용한다. 아이콘 매핑은 UI 한 곳에서 재사용한다. 기존 유니코드 텍스트 방식을 확장하며 새 이미지 패키지는 필요 없다. 미해결 기술 질문은 없다.

브랜치 형태 개선은 비트맵 대신 GPUI의 둥근 사각형과 원형으로 구현한다. 소형 아이콘의 선 두께와 노드 크기를 직접 통제할 수 있고 기존 글꼴이나 외부 패키지에 의존하지 않는다. 앞선 유니코드 로컬 아이콘 결정은 이 벡터 표시로 대체하며 원격·태그는 유지한다.
