# 그리드 표시 및 입력 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

순서는 그래프·메시지·작성자·날짜·해시이다. 헤더와 본문은 동일한 너비를 사용하고 그래프 셀 앞 바깥 여백은 없다. 텍스트는 셀 내부 여백과 말줄임을 사용한다.
각 헤더의 오른쪽 구분선에서 왼쪽 버튼으로 드래그하여 해당 컬럼 너비를 조절한다. 최소 너비를 지키고 그래프는 레인 전체를 유지한다. 선택·행 높이·아이콘·참조 탐색·가로 스크롤은 유지한다. 너비는 현재 작업 공간 세션에서 공유한다.

최신 너비 계약: 메시지 헤더와 본문은 flex: 1로 남는 폭을 채운다. 기존 메시지 너비 설정은 최소값이며 다른 컬럼은 고정 너비를 유지한다. 최소 너비 합을 넘는 공간은 메시지가 차지하고 부족한 경우 가로 스크롤한다.

최신 메시지 계약: flex: 1은 초기값이다. 메시지 자체를 드래그하면 현재 표시 너비에서 시작해 고정 폭으로 전환하며 헤더·본문이 일치해야 한다. 클릭만 하거나 다른 컬럼을 조절할 때는 자동 상태를 유지한다. 앞선 항상 자동 확장 계약은 폐기한다.

최신 계약: 네 내부 경계의 양쪽 컬럼 너비를 반대로 조절하고 전체 폭과 다른 컬럼은 보존한다. 메시지 고정 전환 계약은 폐기한다. 메시지는 나머지 폭을 채우며 인접 고정 컬럼을 반대로 조절하여 메시지 경계도 이동한다. 마지막 외곽 경계는 조절 핸들이 없다. 최소 너비 합보다 좁은 창을 제외하면 그리드는 항상 100% 폭이다.

그래프 초기 너비는 graph_width(5)=100픽셀이다. 실제 레인 수가 더 많으면 기존 레인 최소 너비를 적용하고, 사용자는 기존 최소값 범위 내에서 경계를 조절할 수 있다. 전체 폭 보존 방식은 유지한다.
