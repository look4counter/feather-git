# 데이터 모델

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

HistoryColumns는 다섯 컬럼의 사용자 너비를 가진다. 표시 너비는 컬럼별 최소값 및 graph_width(lanes) 이상이다. 총 너비는 같은 배열의 합계이다.
HistoryResize는 시작 프로젝트, 컬럼 인덱스, 마우스 시작 x, 시작 표시 너비를 가진다. 이동은 시작 너비+마우스 차이를 적용한다. 유효하지 않은 인덱스·비유한 수치·계산 오버플로는 무시한다. 전환·해제 시 드래그만 지우며 너비는 유지한다.

메시지에는 초기 자동/수동 고정 상태를 추가한다. 기본은 자동이며 유효한 메시지 드래그 후 고정 상태가 세션 동안 유지된다. 헤더 실제 표시 너비는 렌더별 Rc<Cell<f32>> 측정값으로 전달하여 드래그 시작 너비를 결정한다. 누름만으로는 자동 상태를 해제하지 않는다.

최신 경계 모델은 다섯 시작 표시 너비와 경계 인덱스를 사용한다. 메시지 고정 여부 필드는 제거한다. 유효 이동량은 왼쪽 최소값과 오른쪽 최소값으로 제한하며 두 컬럼에 반대로 적용한다. 최소 전체 폭은 현재 고정 컬럼 너비와 메시지 최소값 160의 합이다. 실제 전체 표시 폭은 메시지가 남는 폭을 채워 보존한다.
