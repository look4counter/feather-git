# 구현 계획: 커밋 그리드 정렬·너비 조절

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

## 기존 구조 및 기술 맥락

Rust 2024, 로컬 GPUI 0.2.2. ui.rs의 history_row와 history는 각각 컬럼 너비와 gap·px를 중복 지정한다. 행 바깥 px_5가 그래프를 20픽셀 안쪽으로 밀며 그래프 자체는 history_graph.rs의 lane_x(10+20*lane)로 이미 왼쪽에 배치된다. 그래프의 최소 여백 10은 노드·링 잘림 방지에 필요하다.
기존 HistoryState는 가시 행·그래프·프로젝트별 세로/가로 스크롤을 캐시하며 그리드는 uniform_list와 가로 스크롤을 사용한다. GPUI on_mouse_down/move/up/up_out과 ResizeLeftRight 커서를 사용할 수 있다.

## 설계 및 영향 범위

- src/history_grid.rs: HistoryColumns의 다섯 너비와 최소값, 전체 합계, 유효 입력·최소값 제한을 제공한다. 기본 너비는 그래프 45·메시지 360·작성자 110·날짜 140·해시 96픽셀이다. 그래프 최소값은 기존 graph_width(lanes)로 보정한다. 컬럼 셀은 텍스트용 좌우 여백을 포함한다.
- src/main.rs: 새 모듈 등록.
- src/ui.rs: Workspace가 너비 모델과 현재 드래그 상태(프로젝트·컬럼·시작 x·시작 너비)를 소유한다. 헤더·본문·전체 가로 스크롤 폭에 같은 너비 배열을 사용한다. 행 바깥 px_5와 gap을 제거하고 그래프는 셀 시작점 그대로 렌더링한다. 텍스트 셀 안에만 여백·말줄임을 둔다.
헤더 오른쪽 8픽셀 핸들은 1픽셀 구분선과 좌우 조절 커서를 제공한다. 왼쪽 누름으로 시작하며 루트 이동 이벤트가 너비를 갱신한다. 버튼 해제(내부·외부), 버튼이 눌리지 않은 이동, 프로젝트·시작 화면·닫기 전환은 드래그를 종료한다. 컬럼 너비는 Workspace에 있으므로 프로젝트/탭 전환·기록 확장과 무관하게 유지된다.
- src/history_graph.rs: 기존 레인 위치·간격·그리기를 변경하지 않는다. 왼쪽 정렬 회귀 테스트에서 첫 레인의 위치가 전체 레인 수에 무관함을 확인한다.

## 헌법·제약·성능

헌법은 미작성 템플릿이므로 선언된 원칙 검사를 생략하고 AGENTS.md의 계층·호환성·최소 변경 제약을 적용한다. 데이터 계층·Git·공개 형식·의존성은 바꾸지 않는다. 가상화와 그래프 캐시를 유지하고 너비 조절은 가시 행의 레이아웃만 바꾼다. 그래프를 압축하거나 잘라 최소값을 맞추지 않는다.

## 검증 및 단계

너비·모든 컬럼·다수 레인 최소값·비정상 수치·누적 드리프트 방지 테스트를 먼저 추가한다. Workspace의 드래그 시작/이동/종료·화면 전환·너비 유지·선택 불변을 검증한다. 기존 그래프·목록·참조 이동 테스트, cargo check/fmt/clippy와 별도 출력 빌드를 수행한다. 직접 GUI 드래그·시각 검증 여부는 별도 기록한다.
명세·명확화 → 계획 → 작업 → 읽기 전용 일관성 분석 → 선행 테스트·구현·검증 → 수렴 순서로 수행한다.

## 최신 계획: 메시지 컬럼 flex 자동 확장

현재 그리드 컨테이너는 w_full이지만 헤더·본문의 모든 셀이 고정 너비여서 전체 너비 합이 화면보다 작으면 오른쪽에 빈 공간이 남는다. src/ui.rs에서 메시지 본문 셀과 메시지 헤더 외곽에 flex_1·w_auto·공유 최소 너비를 적용한다. 헤더 안쪽 텍스트 셀은 외곽 전체 너비를 사용한다. 헤더 행도 w_full을 명시한다. 다른 컬럼·공유 최소 폭 합·가로 스크롤·선택·그리기·너비 모델은 유지한다.
메시지의 기존 조절 너비는 최소 너비이며 여유 공간에서는 자동으로 확장한다. 소스 변경은 src/ui.rs 한 파일이다. 스타일을 그대로 복제하는 별도 테스트는 추가하지 않고 공유 너비·드래그·회귀 테스트 및 타입·포맷·Clippy·빌드를 수행한다. 기존 아키텍처·호환성 제약과 충돌하지 않는다.

## 최신 수정 계획: 초기 flex 및 직접 조절 후 고정

이전 구현이 메시지 너비를 최소값으로만 적용하여 사용자의 수동 조절 의도를 충족하지 못했다. src/history_grid.rs에 메시지 수동 조절 여부를 보존한다. 기본은 자동이고 해당 컬럼에 유효한 이동이 발생하면 고정으로 전환한다. 이동 없는 누름/해제는 자동을 유지한다. 헤더와 본문은 같은 상태로 flex를 조건부 적용한다.
src/ui.rs의 헤더에 비표시 canvas 측정 요소를 두고 레이아웃의 실제 너비를 Rc<Cell<f32>>에 기록한다. 헤더 드래그 시작에서 측정 너비를 사용하여 넓은 화면에서도 최소 너비로 갑자기 줄지 않게 한다. 측정은 이벤트와 같은 렌더의 지역 상태를 사용하고 추가 알림·렌더 루프는 만들지 않는다. 시작 너비/좌표 이후 이동 계산은 기존 방식을 유지한다.
공유 너비·Workspace 테스트에 초기 자동·수동 전환·다른 컬럼 조절·누름만 유지·실제 표시 너비 기준 조절·기존 고정 너비 재조절을 추가하여 먼저 실패를 확인한다. 전체 테스트·타입·포맷·Clippy·빌드를 수행한다. 변경 파일은 src/history_grid.rs와 src/ui.rs이며 데이터·선택·의존성·공개 형식은 바꾸지 않는다.

## 최신 수정 계획: 전체 폭 보존 및 인접 컬럼 경계 이동

이 절은 이전의 단일 컬럼 resize와 메시지 수동 고정 상태 결정을 대체한다. 실제 렌더링된 다섯 헤더 너비를 하나의 Rc<Cell<[f32; 5]>>에 측정한다. 드래그 시작 시 이 배열을 캡처하고, HistoryColumns.resize_boundary가 경계 왼쪽에 delta를 더하고 오른쪽에서 같은 양을 뺀다. 허용 delta는 양쪽 최소 너비로 제한하며 다른 세 컬럼과 전체 합은 그대로 유지한다.
메시지는 남는 폭을 담당하는 flex를 사용하되 인접 경계를 옮길 때 상대 고정 컬럼을 반대로 조절하므로 메시지 경계도 실제로 이동한다. 메시지의 최소값은 160픽셀이며 전체 최소 폭 계산에는 현재 메시지 폭 대신 최소값을 사용한다. 이로써 드래그가 가로 스크롤을 새로 만들지 않는다. 창이 최소 너비 합보다 작은 경우에만 기존 스크롤을 유지한다.
message_fixed 상태·단일 컬럼 resize API와 전체 외곽의 마지막 핸들을 제거한다. 이전 단일 컬럼/고정 상태 테스트는 최신 수용 기준의 경계 보존 테스트로 대체하며 검증을 완화하지 않는다. 데이터·선택·그래프·프로젝트 전환은 기존대로 유지한다.
수정 파일은 src/history_grid.rs와 src/ui.rs이다. 네 경계의 양방향 이동·최소값·합 보존·타 컬럼 불변·시작 좌표 기준 반복 이동·측정 너비·클릭·전환 테스트를 먼저 추가한다. 전체 테스트와 타입·포맷·Clippy·빌드를 수행한다.

## 그래프 5레인 초기 너비 계획

실제 graph_width는 좌우 여백 10픽셀과 레인 간격 20픽셀로 5레인에서 100픽셀이다. src/history_grid.rs의 기본 그래프 너비를 crate::history_graph::graph_width(5)로 계산하여 45픽셀 대신 사용한다. 계산식을 복제하지 않고 최소 너비와 사용자 경계 조절은 유지한다. 같은 UI 계층의 기존 치수 함수 재사용이며 데이터·의존성 패키지·외부 형식 변경은 없다.
초기값이 5레인 계산과 일치하고 많은 레인 보정과 사용자 축소가 유지되는 테스트를 먼저 추가한다. 기존 테스트·타입·포맷·Clippy·빌드를 수행한다.

## 목록 바깥 좌우 여백 제거 계획

src/ui.rs의 branches/files는 행 안쪽 패딩과 별도로 목록 컨테이너에 px_3을 지정한다. 목록이 전체 패널 폭을 사용하도록 두 컨테이너의 px_3만 제거한다. 행 내부 px_3/px_2와 제목·탭·빈 상태·오류 메시지 간격은 유지한다. 소스 변경은 src/ui.rs 한 파일이며 데이터·공통 목록·선택·아키텍처·의존성을 바꾸지 않는다.
정적 검토로 두 외곽 패딩 제거와 내부 간격 유지 여부를 확인하고 기존 전체 테스트·타입·포맷·Clippy·빌드를 수행한다. 사소한 스타일 대입을 복제하는 새 테스트는 추가하지 않는다.
