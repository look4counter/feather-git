# 검증 안내

cargo test, cargo check, cargo fmt --check, cargo clippy --all-targets를 실행한다.
GUI에서 그래프가 첫 컬럼 왼쪽에 붙고 헤더 구분선과 본문 경계가 맞는지 확인한다. 다섯 컬럼 경계를 각각 드래그하고 헤더 밖·다른 패널 위에서 버튼을 놓아 조절이 끝나는지 확인한다. 최소 너비, 긴 메시지·배지, 가로 스크롤, 여러 레인 그래프를 확인한다. 프로젝트·시작 탭 전환 후 너비 유지 및 드래그 취소를 확인한다. 직접 GUI 확인 여부는 별도 기록한다.

메시지 자동 확장 확인: 창을 넓히면 마지막 해시 컬럼 뒤에 빈 공간이 남지 않고 메시지 컬럼이 나머지 폭을 채우는지 확인한다. 창을 좁히면 메시지 최소 너비와 가로 스크롤이 유지되고 헤더·본문 경계가 맞는지 확인한다. 메시지 너비 조절값은 최소 너비로 적용된다.

최신 수정 확인: 초기에는 메시지가 남는 폭을 채우고, 메시지 경계를 드래그하면 현재 너비에서 고정 폭으로 바뀌는지 확인한다. 버튼을 누르기만 하고 놓거나 다른 컬럼을 조절할 때는 자동 상태를 유지해야 한다. 직접 조절한 뒤에는 창 크기·프로젝트 변경 후에도 정한 너비를 유지한다. 앞선 항상 자동 확장·최소값만 조절 조건은 이 동작으로 대체한다.

최신 최종 동작 확인: 네 내부 경계 각각을 좌우로 옮겨 양쪽 컬럼만 반대로 바뀌고 전체 폭과 다른 컬럼은 유지되는지 확인한다. 양쪽 어느 컬럼이든 최소 너비에 닿으면 경계 이동이 멈춰야 한다. 마지막 해시 바깥에는 조절 핸들이 없고, 경계를 옮기는 것만으로 가로 스크롤이 생기지 않아야 한다. 메시지 고정 전환을 포함한 앞선 수동 확대 조건은 이 경계 이동 조건으로 대체한다.

초기 그래프 너비는 5개 레인이 들어가는 100픽셀인지 확인한다. 실제 레인이 더 많으면 자동 최소 너비 보정이 적용되고, 경계를 조절하면 기존 전체 폭 보존 방식이 유지되는지 확인한다.

저장소·변경 파일 목록의 좌우 바깥 여백이 없고 선택 배경이 패널 양끝까지 이어지는지 확인한다. 행 안쪽 아이콘·텍스트 및 제목·탭 간격은 유지되어야 한다.
