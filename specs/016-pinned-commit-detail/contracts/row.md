# 고정 행 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

변경 파일 → 히스토리 탭 아래에 커밋 아이콘과 커밋상세 행을 가로 전체 폭·24픽셀 높이로 표시한다. 하단 구분선을 두고 파일 가상 목록과 분리하여 스크롤에 따라 움직이지 않게 한다.
선택 우선 호버와 왼쪽 마우스 누름 동작은 공통 행 컴포넌트를 재사용한다. 파일 선택과 상세 행 강조는 상호 배타이며 빈 파일·오류에서도 고정 행은 유지한다. 작업 트리에는 표시하지 않는다.

커밋 기록 행의 유효한 선택은 변경 파일 패널을 히스토리로 전환하고 파일 선택을 지워 커밋상세 행을 선택한다. 동일 행 재선택도 적용한다. 무효 이벤트는 상태를 변경하지 않으며 참조 선택의 패널 모드는 보존한다.
