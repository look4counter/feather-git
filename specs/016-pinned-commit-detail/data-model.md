# 상태 모델

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

히스토리 탭이며 유효한 파일 선택이 없으면 커밋 상세 행이 선택된다. 파일 선택이 있으면 상세 행은 미선택이다. 상세 선택은 파일 선택을 해제한다. 작업 트리에서는 상세 행이 없다.
탭·커밋·프로젝트 전환은 기존 refresh_panel_data 흐름을 사용한다. 별도 상세 상태나 가상 파일 항목을 추가하지 않으므로 파일 개수·가상 인덱스는 유지된다.

커밋 기록의 유효한 행 선택 → file_history=true → 커밋 인덱스 갱신 → 기존 패널 갱신·파일 선택 해제 → 커밋상세 선택. 무효 이벤트는 전환 전에 거절한다. 참조 선택은 기존 패널 모드를 유지한다.
