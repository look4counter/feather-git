# 검증 안내

cargo test, cargo check, cargo fmt --check, cargo clippy --all-targets를 실행한다.
GUI에서 히스토리 탭 진입 시 커밋상세 행이 기본 선택되는지 확인한다. 파일 목록을 스크롤해도 행이 탭 아래에 남는지 확인한다. 파일과 상세 행을 번갈아 선택해 강조가 하나만 유지되는지, 다른 커밋을 선택하면 상세 행이 기본 선택되는지 확인한다. 작업 트리에는 행이 없어야 하며 파일 0개·오류에서도 히스토리의 고정 행은 남아야 한다.

작업 트리에서 변경 파일을 선택한 뒤 커밋 기록 행을 선택한다. 변경 파일이 히스토리 탭으로 전환되고 고정 커밋상세가 선택되며 뷰어가 해당 커밋을 표시해야 한다. 히스토리 파일 선택 후 같은 커밋과 다른 커밋을 다시 선택해도 상세로 돌아와야 한다.
