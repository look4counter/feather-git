# 조사 결과

고정 대상은 커밋 요약 텍스트가 아닌 커밋상세라는 선택 행이다. 참조 프로젝트에서 이 행은 파일 uniform_list 밖에 있으므로 스크롤에 포함되지 않는다. 파일 목록에 가상 인덱스 0번 항목으로 넣으면 함께 스크롤되어 요구와 다르다.
기존 파일 선택이 비어 있는 상태를 상세 선택으로 활용하면 별도 show_detail 플래그와 중복 동기화가 필요 없다. 기존 오른쪽 상세 뷰를 유지한다. 공통 selectable_row를 추출하여 기존 선택 우선 호버·마우스 누름 정책을 재사용한다. 미해결 질문은 없다.

- 추가 결정: select_history_row와 select_repository_row가 공유하는 커밋 선택 처리에 히스토리 전환 여부를 명시한다. 실제 상세 선택은 기존 file_selection.clear와 commit_detail_selected 상태를 재사용해 중복 플래그를 만들지 않는다.
