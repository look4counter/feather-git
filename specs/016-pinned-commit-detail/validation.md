D:/Projects/feather-git-old/src/ui.rs의 files_panel·switch_file_tab·show_detail·commit_icon을 읽어 고정 위치와 기본·상호 배타 선택 동작을 확인했다. 참조 프로젝트는 수정하지 않았다.

## 구현 및 추적성

- FR-001: src/ui.rs의 files에서 히스토리일 때 탭 아래·파일 목록 컨테이너 위에 커밋 아이콘과 커밋상세 고정 행을 배치한다. 파일 가상 목록 밖에 있으므로 목록 스크롤 대상에 포함되지 않는다.
- FR-002: src/virtual_list.rs에 기존 가상 행을 selectable_row로 추출했다. 고정 행도 동일한 공통 높이 24·축소 방지·전체 가로 폭·선택 우선 배경·미선택 호버·왼쪽 버튼 누름 이벤트를 사용한다. 고정 행에는 하단 구분선이 있다.
- FR-003: 히스토리에서 유효한 파일 선택이 없으면 상세 행이 기본 선택된다. 파일 선택은 상세 강조를 해제하고 상세 행 선택은 파일 선택을 지운다. 커밋·탭·프로젝트 갱신은 기존 선택 해제 흐름을 재사용한다.
- FR-004: 작업 트리에서는 고정 행을 렌더링하지 않는다. 빈 파일·조회 오류와 무관하게 히스토리 행은 남는다. 선택 핸들러는 프로젝트·현재 탭·시작 화면·열린 프로젝트를 검증한다.
- FR-005: 기존 오른쪽 커밋 상세 뷰를 재사용한다. 파일 개수·가상 인덱스·선택 커밋·Git 조회는 변경하지 않는다. 새 diff/viewer나 중복 상태를 도입하지 않았다.

### 빌드 및 수렴 결과

cargo build --offline는 기본 target/debug/feather-git.exe 교체 시 접근 거부로 실패했다. 기존 실행 파일을 강제로 종료하거나 변경하지 않았다. cargo rustc --offline --bin feather-git -- --emit=link=target/debug/feather-git-detail-verified.exe로 별도 실행 파일 컴파일·링크가 성공했다. 기본 실행 파일 갱신은 앱 종료 후 다시 빌드해야 한다.
요구사항 6개·성공 기준 3개와 추가 수용 시나리오 4개 및 기존 고정 행·상호 배타 선택·참조 탐색 설계를 실제 코드와 테스트에 대조했다. 누락·부분 구현·모순·요청 외 구현은 0개이며 후속 구현 작업은 없다. 미작성 헌장 템플릿의 규범 검사는 생략했다. 수렴 검사 중 tasks.md는 변경하지 않았다. 화면 수동 검증은 미실행으로 유지한다.
