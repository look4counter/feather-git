# 공통 스크롤 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

필요한 축만 12픽셀 스크롤바를 표시한다. 손잡이는 최소 20픽셀이되 트랙보다 길지 않다. 호버·활성 피드백, 휠·Shift 가로 이동, 트랙 클릭·grab 보존 드래그를 제공한다. 트랙 밖 이동과 왼쪽 버튼 해제도 처리한다.
스크롤바 입력은 행 선택·그리드 컬럼 조절로 전달하지 않는다. 커밋 헤더는 세로 고정·가로 본문 동기화하고 커밋상세 행은 전체 프레임 밖에 고정한다. 기존 행 선택·24픽셀 높이·가상화·참조 이동은 유지한다.
