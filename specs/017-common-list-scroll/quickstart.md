# 검증 안내

cargo test, cargo check, cargo fmt --check, cargo clippy --all-targets를 실행한다.
GUI에서 세 목록의 넘침 시 스크롤바 표시와 내용이 들어맞을 때 숨김을 확인한다. 휠·터치패드·Shift 가로 휠, 손잡이 호버·드래그·트랙 클릭·트랙 밖 이동/해제를 확인한다. 프로젝트/탭 전환·데이터 감소·창 크기 변경 후 위치 제한과 드래그 취소를 확인한다.
커밋 기록 헤더의 세로 고정·가로 동기화, 참조 선택 스크롤, 변경 파일 히스토리의 고정 커밋상세 행과 기존 그리드 경계 조절도 확인한다. 직접 GUI 검증 여부는 별도 기록한다.
