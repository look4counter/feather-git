# 조사 결과

참조 스크롤바는 넘침이 있을 때만 표시되고 트랙 클릭은 손잡이 중심을 누른 위치로 이동시킨다. 드래그는 손잡이를 잡은 위치를 보존한다. 교차 축이 공간을 차지할 수 있으므로 고정점 계산이 필요하다.
현재 커밋의 세로·가로 핸들을 공통 핸들에 연결하면 기존 scroll_to_item과 가로 헤더 동기화를 유지할 수 있다. 별도 스크롤 엔진이나 GPU 라이브러리는 필요 없다. GPUI의 프레임별 paint 이벤트를 사용하여 드래그가 트랙을 벗어나도 지속되게 한다. 휠을 capture에서 한 번 처리하여 native 목록과 중복 적용하지 않는다. 미해결 기술 질문은 없다.
