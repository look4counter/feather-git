# 검증 기록: 공통 목록 스크롤

## 절차 및 구현

명세·명확화·계획·작업·일관성 분석·구현 순서로 수행했다. 요구사항 품질 점검 8개를 통과했고 추가 질문은 없었다. 분석에서 누락·모순·중복은 발견되지 않았다. 참조 프로젝트는 읽기만 했다.

- FR-001: src/virtual_list.rs의 VirtualList·ListScrollHandle을 저장소·변경 파일·커밋 기록이 함께 사용한다.
- FR-002: src/scrolling.rs의 Visibility가 넘침과 두 축의 공간을 계산한다.
- FR-003: 공통 프레임의 휠 캡처·호버·트랙 클릭·손잡이 드래그와 전역 이동/해제가 입력을 담당한다. grab 위치를 보존하고 오프셋을 제한한다.
- FR-004: ui.rs가 프로젝트·패널·탭별 핸들을 보관하고 전환·닫기·교체 시 드래그를 취소한다. 사라진 축의 드래그와 호버도 해제한다.
- FR-005: history.rs의 기존 핸들은 공통 핸들과 내부 상태를 공유한다. 기록 확장도 핸들을 보존한다. 공통 가로 뷰포트가 헤더와 본문을 함께 이동시키고 고정 상세 행은 밖에 둔다. 기존 선택·열 경계·가상화 회귀 테스트가 통과했다.
- FR-006: 순수 계산 테스트가 빈 크기·짧은 트랙·교차 축·감소한 최대 오프셋·비정상 수치를 검증한다. 스크롤바 입력은 전파를 중단하여 행 선택과 분리한다.

## 자동 검증

- cargo test --quiet: 89개 중 87개 통과, 0개 실패, 기존 수동 성능 테스트 2개 무시.
- cargo check: 통과.
- cargo fmt --check: 통과.
- cargo clippy --all-targets: 통과.
- cargo rustc --bin feather-git -- -o target/feather-git-common-scroll.exe: 통과. 사용 중인 실행 파일을 교체하지 않도록 별도 출력했다.
- 기존 GPUI 부동소수점 경고, 기존 테스트 초기화 스타일 경고 및 별도 출력 관련 링커 경고는 남아 있다.

## 검증 한계

computer-use로 별도 테스트 앱 실행을 시도했으나 자동 승인 검토가 거부했다. 도구의 사유는 `Computer Use was not approved to use feather-git-common-scroll-preview`이다. 우회 실행이나 기존 사용자 앱 조작은 하지 않았다. 실제 화면에서 휠·호버·드래그·해제 및 배치를 확인하는 수동 검증은 미완료다. 계산·상태·연결은 자동 테스트와 코드 검토로 검증했다.

## 수렴 검토 범위

명세의 기능 요구사항 6개, 성공 기준 3개, 수용 시나리오 8개와 계획의 5개 소스 접점을 대조한다. 헌법은 미작성 템플릿으로 해당 검사를 생략하고 AGENTS.md의 계층·호환성·최소 변경 원칙을 적용한다. GUI 미검증 사항을 위에 명시한다.
