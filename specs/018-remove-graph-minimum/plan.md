# 구현 계획: 그래프 최소 너비 제거

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

## 기술 및 기존 분석

Rust 2024·로컬 GPUI를 유지한다. history_grid.rs의 widths·minimum_total_width·resize_boundary가 graph_minimum을 받아 레인 너비와 45픽셀을 강제한다. ui.rs의 렌더·드래그 시작·갱신이 graph_width(history.lanes)를 전달한다. 시작 검증은 0도 거부한다. 그래프 셀은 overflow 제한이 없어 좁아지면 그림이 옆으로 넘칠 수 있다.

## 설계와 영향

history_grid.rs에서 레인 수 매개변수를 제거하고 그래프 하한을 비음수 검증용 0으로 둔다. 초기 graph_width(5)는 유지한다. 메시지 등 나머지 하한은 변경하지 않는다. ui.rs의 모든 호출과 테스트를 갱신하고 드래그 시작에서 0을 허용한다. 기록 존재 검증은 유지한다. 그래프 셀에 overflow_hidden을 적용한다. 헤더의 경계 핸들은 0에서도 잡고 확장할 수 있도록 기존 8픽셀 영역을 보존한다.

## 원칙 검토

헌법은 미작성 템플릿이므로 해당 검사를 생략한다. AGENTS.md의 최소 변경·계층·호환성 원칙을 적용한다. 내부 컬럼 계산 인터페이스만 수정하며 외부 API·데이터·의존성 변경은 없다. 그래프 렌더 자체의 레인 간격과 경로 계산은 유지한다.

## 구현 및 검증

회귀 테스트로 먼저 레인 수에 의한 강제 확대를 재현한다. 그 뒤 모델·호출부·클리핑을 수정하고 0에서 재확장·음수 제한·인접 합 보존·기존 컬럼 테스트를 확인한다. cargo test/check/fmt/clippy와 별도 출력 빌드를 실행한다. GUI 수동 검증 여부는 명시한다.

현재 간격은 059에 따라 18px이므로 graph_width(5)=92px다. 과거 검증 기록의 100px는 변경 당시 값이다.
