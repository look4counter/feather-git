# 뷰어 계약

파일 선택은 비교 조회만 수행한다. 고정 커밋상세 행은 상세 조회로 전환한다. Stage·충돌 버튼과 단축키만 저장소 쓰기를 수행한다. 기록 조회에서는 Stage 컨트롤을 표시하지 않는다.

Ctrl+C는 줄 번호/기호를 제외한 선택 본문만 복사한다. 방향키/IJKL·Home/End·Shift 확장·Ctrl+A를 뷰어 포커스에서 처리한다. Space는 변경 줄 체크를 토글하고 Enter는 체크 줄을 Stage한다. 단축키 편집은 기존 키와 충돌하거나 잘못된 입력이면 적용하지 않는다.

전환 시 체크·범위·드래그를 초기화하고 오래된 조회는 버린다. 쓰기는 원본 일치 확인 후 적용하며 성공/실패를 표시하고 원래 저장소 목록을 갱신한다.

각 뷰어 명령은 기본/보조 키를 재지정할 수 있고 보조 키는 비울 수 있다. 적용 시 사용자 설정 파일에 원자 저장하여 다음 실행에 복원한다. 저장 실패는 표시하고 기존 설정을 유지한다.

충돌 선택 버튼은 위쪽(현재) 변경 사용·아래쪽(대상) 변경 사용·양쪽 모두 사용이다. 기존 위쪽·아래쪽·양쪽 범위 선택에 대응한다. 즉시 적용 안내나 체크 일괄 적용은 추가하지 않는다.

충돌 해결 후 뷰어에 해결한 파일 전체 Stage 버튼을 표시하지 않는다. 파일 목록 Stage는 유지하며 자동 Stage하지 않는다.
