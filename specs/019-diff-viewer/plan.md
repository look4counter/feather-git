# 구현 계획: Diff Viewer

## 기술과 기존 흐름

Rust 2024·GPUI 0.2.2·gix 0.90·git2 0.21·similar 3.2를 유지하며 의존성 추가는 없다. 현재 Workspace는 changed_files→file_selection만 갱신하고 detail은 항상 커밋 요약을 표시한다. repository::commit_files는 경로·상태만 주고 두 원본을 보존하지 않는다. ListScrollHandle/VirtualList가 두 축 스크롤과 24픽셀 가상 행을 제공한다. 새 뷰어도 공통 행 높이를 사용한다.

## 참조 분석 및 설계

old의 git.rs에서 Content·FileChange 기반 status/history/read_content/diff 흐름과 detail을 참고한다. src/diff_model.rs는 비교 원본·파일·행·차이·커밋 상세를 보관한다. src/diff_git.rs는 gix 조회·1 MiB·500ms·5,000줄 제한, 계층별 파일 목록·부모 비교·상세 조회를 제공한다. 필터/외부 Git 실행 없이 열린 저장소와 안전한 경로 검증을 사용한다.

old의 partial_stage.rs·conflict.rs 계산과 검증을 src/partial_stage.rs·src/conflict.rs에 재사용하며 내부 모델 이름만 연결한다. 부분 Stage의 인덱스 쓰기는 diff_git의 잠금·원본 재검증·원자 교체로 구현한다. 작업 파일 전체 Stage는 충돌 마커 없음·조회 원본 일치 확인 후 수행한다. 실제 사용자의 저장소 쓰기는 UI의 명시적 버튼/단축키로만 실행한다. 구현 검증은 임시 저장소에서 한다.

src/text_selection.rs는 old의 Unicode 문자 범위·복사·키보드 모델을 재사용한다. src/diff_viewer.rs는 독립 GPUI 엔티티로 포커스·조회 세대·비동기 작업·선택·체크·스크롤·단축키 설정을 소유한다. 비동기 응답은 대상/세대 일치 시에만 적용한다. 쓰기 중 대상 전환은 허용하되 결과는 원래 저장소의 갱신 이벤트로 전달한다. 쓰기 작업 중복은 막는다.

텍스트는 canvas의 실제 글자 위치로 선택·커서·호버 입력을 계산하고 탭은 4칸 표시한다. 프레임 밖 이동은 뷰포트에 제한하여 두 축을 자동 스크롤한다. 선택 드래그는 전역 이동·해제에서 종료한다. 컬럼 구분선과 배경은 각 행에서 같은 너비로 맞춘다. 가장 긴 본문을 한 번 측정해 가로 콘텐츠 폭을 캐시한다. 키보드 이동은 세로/가로 커서를 노출한다. 뷰어 단축키 편집 UI는 기존 TextInput으로 명령별 기본/보조 두 키를 편집하고 사용자 설정에 원자 저장하며 뷰어 키맵만 변경하고 잘못된/중복 키를 거부한다.

src/virtual_list.rs에는 뷰포트·스크롤바 hit test 및 입력 일시 중지 기능을 공개하여 스크롤 구현을 중복하지 않는다. src/ui.rs는 비교 원본 목록과 표시 목록을 같은 순서로 갱신하고 선택된 파일 또는 고정 상세 행을 뷰어 대상으로 전달한다. 프로젝트/파일/탭 전환과 닫기는 텍스트 드래그를 취소하며 오래된 로딩도 무효화한다. 갱신 이벤트는 해당 프로젝트의 파일만 새로 읽고 선택 정체성을 가능한 유지한다. main.rs에 모듈을 등록한다. 기존 detail 요약은 새 텍스트 상세로 대체한다.

## 원칙과 제약

헌법은 미작성 템플릿이므로 선언된 헌법 검사를 생략한다. UI/계산/저장소 접근을 분리하고 기존 외부 API·데이터·의존성을 유지한다. 참조 프로젝트는 수정하지 않는다. 브랜치/네트워크 작업을 이식하지 않는다. 체크된 줄은 조회 세대에 귀속한다.

## 검증 계획

파일 계층·최초/병합·줄 번호·색 분류·바이너리/인코딩/크기/5,000줄·범위·Unicode·역방향·단축키·세대 모델을 자동 검증한다. 임시 저장소에서 부분 줄/구간·CRLF·개행 없음·index.lock·필터·stale index/worktree·충돌3종/diff3/불완전 마커·전체 Stage·작업 파일 불변을 확인한다. 기존 목록·고정 상세·컬럼/그래프·선택 테스트를 회귀 실행한다. cargo test/check/fmt/clippy와 별도 출력 빌드를 수행한다. GUI 자동화 승인 제한이 있으면 우회하지 않고 미검증으로 기록한다.

## 통합 점검 보완

공통 스크롤의 전역 휠 캡처가 단축키 설정 오버레이 뒤에서 동작하지 않도록 입력 중지 상태를 공유 핸들에 둔다. 중지 시 드래그를 취소하며 기존 화면은 기본 활성 상태다. 파일 새로고침은 최신 비교 원본을 다시 읽어 실제 조회 원본으로만 쓰기를 수행한다.

## 충돌 선택 문구 변경 계획

기존 호출 분석: diff_viewer.rs의 충돌 툴바는 Choice::Current·Incoming·Both를 resolve로 전달한다. conflict.rs는 각각 첫 마커와 구분선 사이의 위쪽 내용·구분선과 끝 마커 사이의 아래쪽 내용을 선택하며 diff3의 공통 조상 구간을 제외한다. diff_git.rs가 현재/들어오는 의미를 해설하는 안내를 작성한다.
변경 범위: src/diff_viewer.rs의 버튼 문구 두 개와 src/diff_git.rs의 불필요해진 위치 해설 문장 제거다. 기존 내부 enum·콜백·파일 쓰기·Stage·양쪽 선택은 변경하지 않는다. 즉시 반영 안내와 체크 일괄 적용은 사용자 요청에 따라 제외한다. 새 의존성·아키텍처 변경 없음. 헌장은 미작성 템플릿으로 기존 계층·최소 변경 원칙과 충돌 없음.
검증: 기존 conflict 필터 회귀와 cargo check·엄격한 clippy·별도 실행 파일 빌드로 확인한다. 문구를 복제하는 새 테스트는 추가하지 않는다.

추가 범위 반영: src/diff_git.rs의 충돌 미리보기 하단 note에서 커서·상단 선택 지시 문장도 제거한다. 문구 삭제만 수행하며 FR-010과 T011에 포함한다. 명세·계획·작업 재분석 결과 누락·모순 없음.

## 해결한 파일 Stage 버튼 제거 계획

호출 분석: src/diff_viewer.rs의 resolved 지역 조건은 해당 버튼 렌더링에만 쓰이며 private stage_resolved 메서드는 그 버튼만 호출한다. 실제 Git 처리인 src/diff_git.rs의 stage_resolved는 파일 목록의 toggle_stage에서도 재사용하므로 유지한다.
수정 범위는 src/diff_viewer.rs의 렌더링 분기·전용 조건·전용 private 메서드 제거다. 공개 API·데이터 모델·백엔드·다른 Stage 기능·파일 내용은 변경하지 않는다. 헌장은 미작성 템플릿이며 기존 구조·최소 변경 원칙과 충돌 없음. 검증은 기존 충돌·해결 후 파일 목록 Stage 회귀와 컴파일·엄격한 clippy·별도 빌드로 수행한다. 단순 버튼 제거를 복제하는 새 테스트는 추가하지 않는다.

호출 경계 보완: src/backend.rs의 stage_resolved 래퍼는 버튼 제거 후 테스트에서만 호출된다. 같은 파일의 diff 래퍼처럼 cfg(test)로 제한한다. diff_git.rs의 실제 처리와 파일 목록 toggle_stage 연결은 유지한다. 작업 목록·명세 재분석 결과 FR-010과 데이터 보존 원칙을 충족하며 모순 없음.

추가 문구 변경: src/diff_viewer.rs의 충돌 선택 문구를 위쪽(현재) 변경 사용·아래쪽(대상) 변경 사용으로 바꾼다. 기존 위쪽·아래쪽 선택 범위를 유지한다. T015에 함께 반영하며 재분석 결과 누락·모순 없음.
