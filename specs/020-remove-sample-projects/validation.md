# 구현 및 검증 결과

## 변경 결과

샘플 프로젝트 4개와 커밋·파일 데이터를 담은 src/sample.rs 및 main.rs 모듈 등록을 삭제했다. ui.rs의 초기 주입, 샘플 전용 참조 선택, 데모 배지·안내와 뷰어 대체 표시를 제거했다. 최초 실행은 빈 프로젝트 목록과 활성 시작 탭 하나로 구성된다.
기존 탭·기록·파일 회귀 테스트는 명시적으로 준비한 실제 임시 저장소로 전환했다. 사용자 저장소와 과거 설계 문서는 유지했다.

## 단계별 검증

- 명세: 품질 점검 통과.
- 명확화: 범위·데이터·화면·오류·성공 기준 검토 완료, 추가 질문 없음.
- 계획·작업: 구조와 호출 관계·영향 범위·검증 순서를 반영했다.
- 구현 전 분석: 요구사항 4개 모두 작업에 연결됨. 누락·모순·중복·미해결 모호성 0개.
- 재현: new_workspace_has_only_an_active_start_tab 테스트가 변경 전 projects.is_empty 단언에서 실패하고 변경 후 통과했다.
- 전체 테스트: cargo test --offline 결과 113개 통과, 실패 0개, 기존 수동 성능 테스트 2개 제외.
- 형식: cargo fmt --check 통과.
- 정적 검사: cargo check --offline 통과.
- 일반 빌드: cargo build --offline는 실행 중인 target/debug/feather-git.exe 교체에서 접근 거부로 실패했다.
- 대체 빌드: cargo rustc --offline --bin feather-git -- --emit=link=target/debug/feather-git-verified.exe 성공. 별도 실행 파일 생성과 링크 완료를 확인했다.
- 잔존 검색: src에서 sample·demo·샘플·데모 및 기존 샘플 프로젝트 이름 검색 결과 0건. src/sample.rs 없음.

## 수렴 검사

요구사항 4개, 성공 기준 3개, 수용 시나리오 4개, 계획 변경 지점 3곳과 작업 목록을 실제 코드에 대조했다. 누락·부분 구현·모순·요청 외 구현 0개다. 헌장은 미작성 템플릿이므로 규범 검사를 생략했다. 후속 구현 작업은 없다.

## 남은 제약과 미검증

실행 중인 앱은 종료하지 않았다. 기존 기본 실행 파일은 교체되지 않았으므로 앱 종료 후 다시 빌드해야 한다. 별도 검증 실행 파일은 최신 코드로 생성됐다. 화면 수동 조작 검증은 수행하지 않았다.
기존 GPUI 실수 리터럴 경고, proc-macro-error2 향후 호환성 경고, repository::commit_files 미사용 경고가 남아 있다.
