# 화면 및 저장 계약

시작 화면의 최근 저장소 항목은 이름과 전체 경로를 표시한다. 비어 있으면 기존 안내를 표시한다. 클릭 시 실제 저장소 열기를 요청하고 진행 중에는 중복 요청을 차단한다. 성공 시 시작 탭을 프로젝트 탭으로 대체하며 같은 경로는 재사용한다. 실패 시 오류 알림을 표시하고 기존 상태는 유지한다.
작업 공간 JSON 버전은 1이며 프로젝트 메타데이터와 탭 상태만 기록한다. 설정 오류와 복원 실패는 하단에 표시한다. 설정 파일이 없으면 오류 없이 시작 화면을 표시한다.

시작 시 복원 안내를 즉시 표시한다. 복원 중 프로젝트 변경 조작은 보류하고 창 이동·크기 변경은 가능하다. 결과 반영은 설정 파일을 덮어쓰지 않으며 실패 후에도 기존 안내 정책과 재시작 동작을 유지한다.

초기 복원 중에는 전용 로딩 화면만 표시한다. 상단 중앙에서 새가 가로로 날며 깃털이 떨어지고 아래에 앱 이름과 로딩 안내를 표시한다. 프로젝트 탭·새 탭·최근 저장소·작업 상태줄은 숨기고 창 제목줄의 기본 조작은 유지한다. 완료·실패 후 기존 정상 화면으로 즉시 전환한다.
