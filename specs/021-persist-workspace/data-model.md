# 데이터 모델

RepositoryEntry: name 문자열, path 로컬 경로. 실제 저장소의 정규 경로로 식별한다.
Session: version=1, open 저장소 배열(탭 순서), active 선택 경로 또는 없음, start_tab_open/start_tab_active, recent 저장소 배열(최신순 최대 20개).
기본값: 열린 프로젝트 없음, 시작 탭 열림·활성, 최근 목록 없음.
저장 시 커밋·파일 내용·인증정보를 포함하지 않는다. 읽기 시 최근 목록 중복과 개수를 정리한다. 활성 경로가 복원되지 않으면 유효한 이웃 또는 시작 화면으로 복귀한다. 모든 프로젝트가 없으면 시작 화면을 제공한다.
탭 닫기는 open만 변경한다. 저장소 연결·선택은 recent 맨 앞으로 이동한다. 자동 복원은 recent 순서를 유지한다.

복원 진행 상태는 저장되지 않는 런타임 플래그다. 복원 결과는 저장 상태·실제 프로젝트·활성 인덱스·활성 파일 목록·오류 문자열로 구성되며 백그라운드에서 UI로 이동한다. 진행 중 → 완료 또는 오류 전이 후 일반 조작을 재개한다.

시작 애니메이션은 저장되지 않는 장면 데이터다. 주기 진행률로 새의 위치·날개 위상과 깃털별 위치·회전·투명도를 계산한다. 복원 상태만 화면 선택을 결정하며 기존 Session 형식은 변경하지 않는다.
