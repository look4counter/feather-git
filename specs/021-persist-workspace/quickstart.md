# 검증 안내

cargo fmt --check, cargo test --offline, cargo check --offline, cargo build --offline를 실행한다.
수동 검증: 저장소 둘을 열고 첫 번째를 선택한 뒤 재실행한다. 탭 순서·선택 상태를 확인한다. + 버튼으로 최근 목록을 확인하고 닫힌 저장소를 다시 연다. 같은 저장소가 중복되지 않는지 확인한다. 모든 프로젝트를 닫고 재실행해 시작 화면과 최근 목록이 남는지 확인한다.
사용자 설정은 LOCALAPPDATA/feather-git/workspace.json에 저장한다. 자동 테스트는 임시 경로만 사용한다.

느린 저장소가 열린 상태로 재시작해 복원 안내와 창 이동·크기 변경을 확인한다. 완료 후 탭 순서·선택 상태·최근 순서 및 파일 목록이 맞는지 확인한다. 복원 중 창을 닫아도 충돌하지 않아야 한다.

시작 전용 화면 확인: 복원이 진행되는 동안 새 탭·최근 목록이 보이지 않고 상단에 날아가는 새와 떨어지는 깃털이 표시되는지 확인한다. 오래 걸릴 때 반복 경계와 크기 변경을 확인하고 완료·실패 후 정상 화면으로 전환되는지 확인한다. 다른 저장소 작업의 기존 물결 진행 표시는 유지되어야 한다.
