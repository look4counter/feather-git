## 사용자 시나리오 및 검증

### 사용자 이야기 1: 작업하던 탭 복원 (우선순위: P1)

사용자는 앱을 다시 실행해 열려 있던 프로젝트에서 작업을 이어간다.
독립 검증: 실제 저장소 두 개를 열고 탭을 선택한 뒤 작업 공간을 다시 생성한다.

1. 열린 프로젝트와 순서, 선택된 프로젝트가 재실행 후 유지된다.
2. 닫은 프로젝트는 다시 나타나지 않는다. 모든 프로젝트를 닫고 재실행하면 시작 화면을 제공한다.
3. 시작 탭을 열어 둔 경우 그 열림·선택 상태도 유지된다.
4. 일부 저장소가 없어지거나 열기에 실패해도 나머지는 복원되고 실패 안내가 표시된다.

### 사용자 이야기 2: 최근 저장소로 빠르게 열기 (우선순위: P2)

사용자는 시작 화면에서 최근 사용한 저장소를 확인하고 다시 연다.
독립 검증: 생성·열기·복제 성공 후 최근 목록과 재실행 후 목록, 항목 선택을 확인한다.

1. 성공적으로 연결한 저장소의 이름과 경로가 최신 사용 순으로 표시된다.
2. 같은 저장소는 중복되지 않으며 다시 열거나 선택하면 맨 앞으로 이동한다.
3. 프로젝트를 닫아도 최근 목록에 남고 재실행 후에도 유지된다.
4. 최근 항목을 누르면 실제 저장소가 열리고 이미 열린 저장소는 기존 탭을 사용한다.
5. 열기에 실패하면 오류를 알리고 기존 탭과 최근 목록을 훼손하지 않는다.

### 경계 조건

첫 실행·비어 있는 목록·빈 저장소·한글과 공백 경로·손상된 설정·설정 읽기/쓰기 실패·없어진 저장소·중복 경로·유효하지 않은 선택 상태를 다룬다. 실패한 저장소 외의 복원은 계속한다.

### 사용자 이야기 3: 재시작 중 화면 응답 유지 (우선순위: P1)

저장소 복원이 오래 걸려도 사용자는 앱 창과 복원 진행 상태를 확인할 수 있어야 한다.
독립 검증: 복원 작업의 완료를 지연시킨 상태에서 초기 작업 공간이 즉시 반환되고 UI 이벤트를 처리하는지 확인한다.

1. 설정·저장소 읽기가 완료되지 않아도 창 생성은 반환되고 복원 안내를 표시한다.
2. 복원 중에는 탭 상태 변경과 새 저장소 연결을 보류해 저장 파일이나 선택 상태를 덮어쓰지 않는다. 창의 이동·크기 변경은 차단하지 않는다.
3. 완료하면 저장된 탭 순서·선택·최근 목록을 유지한다. 저장소와 활성 프로젝트 변경 파일 목록을 반영할 때 UI 스레드에서 디스크를 재조회하지 않는다.
4. 설정·저장소 읽기 실패나 창 종료는 충돌을 일으키지 않고 기존 실패 안내 정책을 유지한다.

### 사용자 이야기 4: 새와 깃털의 시작 전용 로딩 화면 (우선순위: P1)

앱 시작 시 사용자는 새 탭 대신 로딩만을 위한 화면을 본다. 위쪽에서는 새가 날아가고 깃털이 부드럽게 떨어진다.
독립 검증: 복원을 지연시켜 전용 화면만 표시되는지 확인하고 완료 후 정상 화면으로 전환되는지 확인한다.

1. 복원 중에는 새 탭·탭 표시줄·최근 목록·작업 패널·작업 상태줄을 표시하지 않고 전용 화면과 진행 안내를 표시한다. 기본 창 조작은 유지한다.
2. 화면 위쪽에서 날갯짓하는 새가 가로로 날고 깃털 여러 개가 회전·좌우 흔들림과 함께 천천히 떨어진다. 오래 걸리면 자연스럽게 반복한다.
3. 복원 완료·실패 후 로딩 애니메이션이 제거되고 기존 탭 또는 시작 화면·오류 안내로 전환된다. 애니메이션을 보여주기 위한 추가 대기는 넣지 않는다.

## 요구사항

- FR-001: 열린 실제 프로젝트의 순서·이름·경로·활성 프로젝트 및 시작 탭 상태를 저장하고 재실행 때 복원한다.
- FR-002: 열기·전환·닫기 후 상태를 갱신하고 모든 프로젝트를 닫은 경우 시작 화면으로 복귀한다.
- FR-003: 최근 저장소를 이름·경로와 함께 중복 없이 최신순 최대 20개까지 보관하고 시작 화면에 표시한다.
- FR-004: 최근 저장소를 선택해 다시 열 수 있고 이미 열린 프로젝트는 중복 탭을 만들지 않는다.
- FR-005: 복원·재열기 실패는 안내하고 다른 탭과 최근 목록을 보존한다. 설정 부재는 정상 첫 실행, 손상·읽기·쓰기 실패는 사용자에게 알린다.
- FR-006: 사용자별 설정을 안전하게 교체 저장하고 저장소 파일·인증정보·커밋 내용은 저장하지 않는다. 기존 실제 저장소 기능을 유지한다.

- FR-007: 시작 시 설정 읽기·저장소 복원·활성 저장소 변경 파일 목록 조회를 백그라운드에서 실행해 UI 이벤트 루프를 차단하지 않는다.
- FR-008: 복원 중 진행 안내를 표시하고 완료 전 상태 변경·설정 저장을 차단한다. 완료 또는 실패 후 일반 조작을 재개한다.
- FR-009: 복원 결과 반영 시 중복 디스크 조회와 최근 목록 변경을 하지 않고 기존 탭·선택·오류 동작을 유지한다.

- FR-010: 초기 복원 중에는 일반 작업 공간 대신 전용 로딩 화면을 표시하며 탭·최근 목록·작업 상태줄을 숨긴다.
- FR-011: 로딩 화면 위쪽에 새의 비행·날갯짓과 여러 깃털의 부드러운 낙하·회전 애니메이션을 표시한다. 기존 색상 테마를 따른다.
- FR-012: 로딩 애니메이션은 복원 중에만 반복하며 완료·실패 때 제거한다. 비동기 복원·기존 진행 표시·창 조작을 유지한다.

### 주요 개체

작업 공간 상태: 열린 저장소 목록, 활성 저장소, 시작 탭 상태, 최근 목록.
저장소 항목: 표시 이름과 정규화된 로컬 경로. 최근 목록은 탭의 열림 상태와 독립적이다.

## 성공 기준

- SC-001: 두 개 이상 실제 저장소의 순서·활성 탭·닫힘 상태가 재생성 후 정확히 일치한다.
- SC-002: 최근 목록이 재실행 후 유지되고 중복 0개·최대 20개·재열기 동작을 만족한다.
- SC-003: 설정 손상·저장 실패·저장소 누락 시 오류를 알리고 정상 탭 사용 및 복원이 가능하다.
- SC-004: 관련 자동 테스트·형식·빌드 검증이 통과한다.

- SC-005: 복원 완료를 기다리지 않고 초기 화면을 생성하며, 지연된 작업 완료 전후 시작 함수의 비차단 반환과 상태 전이가 자동 검증을 통과한다. 실제 창 이벤트 처리는 별도 수동 검증 대상으로 기록한다.

- SC-006: 복원 중에는 전용 화면 하나만 표시되고, 완료·실패 후 일반 화면으로 전환된다. 비행·낙하 애니메이션의 위치·투명도가 유효하고 반복 경계가 자연스럽다.

## 가정 및 명확화

사용자가 요구한 유지는 프로젝트 탭과 선택 상태를 의미하며 커밋·스크롤·패널 위치 복원은 범위 밖이다. 최근 사용은 성공적인 생성·열기·복제 또는 프로젝트 선택이다. 자동 복원은 최근 순서를 바꾸지 않는다. 찾을 수 없는 최근 항목은 재시도를 위해 남긴다. 한 프로세스의 단일 작업 공간을 기준으로 하며 여러 인스턴스 동시 편집 병합은 범위 밖이다.
명확화 검토: 범위·데이터·화면·오류·완료 기준을 검토했으며 위 기본값으로 구현 가능한 모호성은 해소됐다. 추가 질문 없음.

2026-11-14 추가 명확화: 이번 수정은 재시작 복원의 UI 스레드 차단 해소다. 일반 탭 전환·기타 작업의 비동기화와 복원 취소 기능은 범위 밖이다. 복원 중에는 창 조작과 진행 안내를 제공하고 프로젝트 변경 조작은 잠시 보류한다.

시작 화면 디자인 명확화: 어두운 기존 테마에 밝은 새와 민트빛 깃털 포인트를 사용한다. 화면 위쪽은 전용 화면의 상단 중앙 장면을 의미한다. 별도 이미지·동영상 자산이나 인위적인 최소 로딩 시간은 도입하지 않는다. 추가 질문 없음.
