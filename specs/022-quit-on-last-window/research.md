# 조사 결과

- 최초 가설: 앱 수준 종료 구독 누락. 그러나 Windows GPUI 자체의 마지막 창 종료 처리가 있어 이 가설만으로 원인을 확정할 수 없다.
- 실행 검증: 종료 구독이 없는 기존 코드와 구독을 추가한 코드 모두 창 제거 후 정상 프로세스 종료했다.
- 실제 원인: 이전 로딩 화면 미리 보기에서 에이전트가 숨겨 실행했던 PID 34344가 남아 기본 실행 파일을 잠갔다. 초기 정리 명령 실패를 놓친 것이 원인이다.
- 결정: 해당 테스트 인스턴스를 정리하고 근거 없는 코드 변경은 남기지 않는다. 메모리 누수를 입증하는 결과는 없다.
