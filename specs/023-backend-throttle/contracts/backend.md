# 실행 옵션 및 백엔드 계약

cargo run -- --backend-delay-ms 1500 또는 cargo run -- --backend-delay-ms=1500으로 요청마다 1.5초 추가 지연을 적용한다. 0과 옵션 생략은 비활성이다. --help는 도움말을 출력하고 종료한다. 유효 범위는 0~60000이며 잘못된 값·중복·알 수 없는 옵션은 종료 코드 2로 거절한다.
백엔드 작업은 기존 동기/비동기 경로에서 실행한다. UI 동기 호출은 UI를 멈추며 작업 이름·지연 시간·UI 스레드 진단을 stderr에 표시한다. 로그에 경로·내용·인증정보는 포함하지 않는다.
중첩 요청은 최상위 작업에만 지연하고 독립 요청은 각각 지연한다. 순수 변환·렌더링·파일 선택창은 제외한다.
