# 구현 계획: 백엔드 공통 지연 옵션

## 기술 맥락과 기존 흐름 분석

Rust 2024·GPUI, 새 외부 의존성 없이 구현한다. main.rs가 앱을 시작하고 ui.rs의 복원·저장소 연결 및 diff_viewer.rs의 조회·쓰기 작업은 GPUI 백그라운드 실행기를 사용한다. 반면 ui.rs의 패널 갱신·참조 선택·세션 저장 및 DiffViewer 생성 시 단축키 설정 읽기는 동기 호출이다. 실행기만 감싸면 동기 호출을 놓치므로 I/O 진입점에서 정책을 적용해야 한다.
저장소 I/O는 repository.rs, diff_git.rs, partial_stage.rs, conflict.rs, session.rs에 분산돼 있다. 뷰어 단축키 설정 읽기·쓰기는 diff_viewer.rs에 별도로 있으며 안전 파일 쓰기 방식이 세션과 중복된다.

## 설계 및 영향 범위

- src/backend.rs: 지연 정책·옵션 파싱·UI 스레드 식별·로그·중첩 호출 가드를 공통 구현한다. 지연은 이 파일 한 곳의 std::thread::sleep으로만 수행한다. 기본값 0은 즉시 업무 코드를 호출한다. 스레드 지역 재진입 가드와 RAII로 내부 호출 중복 지연을 막고 오류·패닉 후 상태를 복구한다. 잠금으로 요청들을 직렬화하지 않는다.
- 공통 모듈 게이트웨이 매크로가 backend.rs 한 곳에 각 I/O 서명을 선언한다. 기존 모듈 구현은 비공개 implementation 안에서 include하고 동일 이름·서명으로 전달한다. 타입과 순수 유틸리티는 명시적으로 재노출한다. 업무 구현 함수별 지연 삽입이나 호출부별 wrapper 추가를 피한다. 신규 공개 I/O는 이 게이트웨이에 등록해야 UI에서 사용할 수 있다. 기존 내부 테스트 모듈 경로는 implementation 하위로 이동하지만 테스트 내용과 동작은 유지한다.
- src/main.rs: 기존 백엔드 모듈 선언을 공통 게이트웨이 등록으로 대체하고 UI 시작 전에 옵션을 파싱·초기화한다. --help는 사용법 출력 후 0 종료, 입력 오류는 2 종료한다. --backend-delay-ms 값 또는 =값을 지원하고 0~60000 외 값·중복을 거절한다.
- src/session.rs: 기존 안전 쓰기 로직을 read_bytes/write_bytes 공통 파일 I/O로 제공한다. 기존 read/write는 동일 모델 처리와 검증을 유지한다. session::remember의 경로 정규화도 게이트웨이를 통과한다.
- src/diff_viewer.rs: 단축키 read_keys/write_keys는 공통 세션 바이트 I/O를 재사용해 지연 누락과 안전 쓰기 중복을 없앤다. 설정의 내용·검증·저장 경로는 유지한다.
- src/ui.rs 및 저장소/diff 업무 로직은 기존 공개 모듈 이름을 사용하므로 호출부와 스케줄링을 바꾸지 않는다. 도메인 API·데이터·인증은 변경하지 않는다.

## 대안 및 헌장 점검

GPUI 실행기만 감싸는 방식은 동기 I/O를 누락한다. 각 함수에 sleep 삽입은 사용자 요구에 어긋난다. 새 속성 프로시저 매크로나 설정 라이브러리는 필요 없다. 명시적 공통 게이트웨이는 현재 인터페이스를 보존하며 정책을 한 곳으로 모은다. 헌장은 미작성 템플릿이므로 규범 검사는 생략하고 기존 계층·최소 변경·호환성 규칙을 적용한다. 사용자가 요청한 공통 컴포넌트 범위 안에서 진행한다.

## 검증

옵션 파싱, 지연 기본 비활성, 중첩·패닉·오류 복구, 동시 실행, UI 스레드 판별 및 실제 게이트웨이 적용을 검증한다. 전역 설정을 바꿔 기존 병렬 테스트를 지연시키지 않도록 테스트 전용 스레드 지역 정책을 주입한다. 실제 바이트 파일 I/O·저장소 오류·순수 함수 호출의 지연 횟수를 대조한다. 기존 전체 회귀·단축키 안전 저장 검증을 유지한다.
cargo fmt --check, cargo test --offline, cargo check --offline, cargo clippy --offline --all-targets, cargo build --offline를 수행한다. 실제 실행 파일의 --help·잘못된 값 종료를 검증하되 GUI를 불필요하게 실행하거나 프로세스를 남기지 않는다. UI 수동 검증 미실행 및 동기 지연으로 예상되는 멈춤을 명시한다.
