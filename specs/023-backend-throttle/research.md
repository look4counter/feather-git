# 조사 결과

- 결정: I/O 모듈의 공통 게이트웨이에 정책을 적용한다. 이유: 실행기 경계만으로는 남아 있는 UI 동기 호출을 검증할 수 없다.
- 결정: 요청 전 고정 지연과 스레드 지역 재진입 가드를 사용한다. 내부 호출마다 지연하면 사용자가 지정한 시간보다 과도하게 느려지므로 독립 요청에만 적용한다.
- 결정: 실행 시 옵션만 사용하고 설정 파일에는 저장하지 않는다. 정상 실행과 테스트의 기본 성능을 유지한다.
- 결정: 단축키 설정도 세션 바이트 I/O를 재사용한다. 별도 파일 작업을 누락시키지 않고 기존 안전 쓰기 중복을 줄인다.
- 결정: 새로운 의존성이나 업무 함수별 지연 코드는 도입하지 않는다. 미해결 질문 없음.
