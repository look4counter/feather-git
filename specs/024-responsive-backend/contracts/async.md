# 비동기 경계 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

UI 핸들러와 렌더링은 I/O를 실행하거나 작업 완료를 기다리지 않는다. UI는 소유 요청을 생성하고 공통 백그라운드 실행기로 제출한다. 완료는 최신 요청에만 반영하고 이전 성공·오류를 버린다.
일반 조회 중 즉시 로딩 문구·오버레이·스피너를 표시하지 않는다. 추가된 히스토리 파일 목록의 150ms 지연 문구는 예외다. 대상이 바뀐 파일은 선택 불가능하게 제거하고 실제 빈 결과는 완료 후에만 표시한다. 기존 시작 전용 화면은 유지한다.
세션 저장은 직렬·최신값 우선이며 정상 종료 시 마지막 변경을 배출한다. 저장 실패와 최신 조회 오류는 기존 오류 영역으로 알린다.

추가 정책: 변경 파일의 히스토리 조회는 요청 시작부터 공통 150ms를 초과해 진행 중일 때만 목록 영역에 ‘조회 중 입니다..’를 표시한다. 작업 트리·다른 패널에는 적용하지 않는다. 응답·오류·선택 변경 후에는 표시하지 않는다. 스피너나 오버레이는 추가하지 않는다.
