# 상태 모델

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

패널 요청: 요청 번호·프로젝트·경로·히스토리 여부·커밋 ID·참조 조회 종류·선택 복원 파일 식별자·선택적 그래프 준비 입력.
패널 결과: 요청 식별자·참조 목록·변경 파일 목록·선택적 준비된 그래프·오류.
참조 요청: 선택 버전·프로젝트·탭·행·정확한 참조 이름·경로. 결과는 로드된 기록과 준비된 그래프다.
세션 작성기: 진행 중 1개·최신 대기 스냅샷 최대 1개·세대별 결과 채널. 완료 뒤 대기값을 처리하며 flush는 모두 끝날 때 반환한다.
UI의 선택·진행 버전은 저장하지 않는다. 파일과 세션 모델의 기존 형식은 유지한다.

지연 표시: 공통 LOADING_DELAY=150ms, 요청 번호·시작 Instant·표시 여부. 새 요청은 표시를 초기화하고 완료·무효화 시 제거한다. 백엔드 완료 AtomicBool은 타이머와 작업 사이에서 공유하며 저장하지 않는다.
