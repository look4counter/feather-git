# 조사 결과

- 기존 호출부 전체에 Context 인자를 추가하기보다 순수 상태 전이가 요청을 만들고 공통 디스패처가 제출하도록 분리한다. 선택 즉시 반영·재현 가능한 요청/결과 테스트가 가능하다.
- 패널·참조의 오래된 결과를 버리고 비활성 프로젝트 캐시는 재선택 시 갱신한다. 취소 불가능한 Git 작업을 강제로 중단하지 않는다.
- 세션 저장을 동시에 실행하면 오래된 상태가 마지막에 기록될 수 있으므로 직렬 작성기와 최신 대기 스냅샷 병합을 사용한다. GPUI 종료 대기는 100ms이므로 지연 옵션을 포함한 저장 배출은 이벤트 루프 반환 후 수행한다.
- 최근 목록은 이미 정규화된 경로로 메모리에서 갱신한다. 그래프 준비는 백그라운드 데이터와 UI 핸들 생성을 분리한다. 미해결 질문 없음.

- 추가 결정: 기존 panel_waiting/요청 번호를 사용하고 공통 지연 상태만 추가한다. GPUI timer로 기다려 UI를 차단하지 않는다. 백엔드 완료 플래그를 함께 검사해 UI 결과 반영 지연 때문에 로딩이 뒤늦게 나타나는 것도 막는다.
