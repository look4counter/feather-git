## 의존성과 실행 전략

T001 → T002 → 구현 전 일관성 분석 → T003/T004 → T005 → T006 → T007/T008 → T009 → T010 → T011 순서다. 동일 파일 변경은 순차 처리하며 독립 검색과 검증 결과 확인은 함께 수행할 수 있다. 공통 경계 완성 후 UI 요청을 연결하고 기존 회귀를 유지한다.
