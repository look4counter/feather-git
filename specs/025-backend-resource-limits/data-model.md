# 데이터 모델

- 실행기: FIFO 작업 큐, 조건변수, 최대 2개 작업 스레드. 작업은 실행 중 큐 잠금을 보유하지 않는다.
- 조회 슬롯: 현재 취소 토큰 0~1개. 교체와 소멸은 이전 토큰을 취소한다.
- 취소 토큰: 잠금으로 보호한 취소 상태와 지연 깨우기 조건변수.
- 완료 상태: 결과 또는 패닉 값과 대기 Future의 Waker. 완료·깨우기는 잠금 해제 후 전달한다.
- 요청 흐름: 제출 → 대기 → 실행 → 완료. 대기·지연 중 취소는 실제 작업을 생략하며, 실행 중 취소는 다음 gateway 경계에서 종료한다.
