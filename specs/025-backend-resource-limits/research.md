# 조사와 결정

- 결정: 공용 실행기의 동기 작업을 전용 2개 작업 스레드로 분리한다. 이유: 비동기 블록 안의 sleep과 recv도 스레드를 점유한다. 대안인 요청마다 새 스레드는 실행 상한이 없어 제외했다.
- 결정: 기존 동기 gateway 서명을 유지하기 위해 읽기 문맥에서만 내부 취소 unwind를 경계에서 회수한다. 이유: 모든 Result 및 공개 API를 바꾸지 않고 I/O별 지연을 유지한다. 일반 쓰기에는 취소 문맥을 설정하지 않는다.
- 결정: 동기 Git 연산은 강제 중단하지 않는다. 이유: 안전한 종료 지점은 I/O 경계이며 외부 호출 중 강제 스레드 종료는 상태를 손상시킬 수 있다.
- 결정: 로컬 GPUI Windows 작업 제출은 Normal을 사용한다. High는 작업 큐의 우선순위이며 시스템 프로세스 우선순위 설정과 다르다.
- 결정: gix의 로컬 설치 소스에서 확인한 index_worktree_options_mut으로 thread_limit을 1로 제한한다.
- 미해결 기술 항목은 없다. 기존 화면 수직동기화와 애니메이션은 이번 변경 범위 밖이다.
