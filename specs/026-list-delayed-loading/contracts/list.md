# 목록 계약

virtual_list의 기존 인수와 빌더를 유지한다. 선택적으로 .loading(ListLoading)을 연결한다. 소유자는 요청 시작 시 begin, 백엔드 완료 시 completion()으로 얻은 신호에 true 저장, 성공·실패·무효화 때 reset을 호출한다. 목록은 타이머와 정확한 ‘조회 중 입니다..’ 문구 및 지연 중 빈 영역을 처리한다.

진행 중에는 기존 행과 선택 이벤트를 제공하지 않고 헤더는 유지한다. 기능을 연결하지 않은 목록은 기존 동작을 유지한다. 150ms 상수는 src/loading.rs 한 곳에만 둔다.

변경 파일 패널은 작업 트리·히스토리 두 탭의 유효한 패널 조회를 모두 같은 핸들에 연결한다. 완료·무효화 시 초기화하고 새 요청은 별도 완료 신호를 사용한다.
