# 데이터 모델

기존 데이터 모델은 변경하지 않는다. 실제 파일 번호 0..N은 ChangedFile과 FileChange 사이에 유지한다. 히스토리 조회 성공 후에는 표시 번호 0이 상세 항목, 1..N이 실제 파일 번호 0..N-1이다. 상세 항목이 없으면 표시 번호와 실제 파일 번호는 같다. 실제 파일 개수 배지는 N이다. 이름이 같은 파일도 번호로 구분한다.

대기 → 성공이면 상세 첫 행을 포함한다. 대기 → 오류이면 오류를 표시하고 상세 행을 제공하지 않는다. 새로운 요청/탭 전환은 기존 로딩과 최신 요청 검증으로 이전 표시를 제거한다.
