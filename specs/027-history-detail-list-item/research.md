# 조사 및 결정

- 결정: 기존 실제 파일 선택 인덱스를 유지하고 UI 표시 번호만 변환한다. 이유: viewer_target과 쓰기 후 파일 식별 보존의 계약을 깨지 않는다. 가짜 ChangedFile 추가는 선택/스테이징 오동작을 유발할 수 있어 제외했다.
- 결정: 상세 행도 기존 VirtualList 안에서 렌더링한다. 별도 헤더나 고정 행을 숨겼다 보이는 대안은 함께 스크롤하는 요구를 충족하지 않는다.
- 결정: 조회 성공·유효 커밋에만 상세 행을 제공한다. 빈 변경 결과도 커밋상세를 제공하지만 오류를 성공 목록처럼 표시하지 않는다.
- 결정: 기존 커밋 선택의 상세 뷰 자동 조회는 유지한다. 사용자 요청은 목록 행의 표시 시점과 위치이며 뷰어 동작 변경은 요구하지 않았다.
- 미해결 기술 항목은 없다.
