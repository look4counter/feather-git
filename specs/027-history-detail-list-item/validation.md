# 검증 결과: 커밋상세 목록 항목

검증일: 2026-11-14

## 구현 결과

src/ui.rs의 목록 바깥 고정 커밋상세 행을 제거하고 동일 VirtualList의 첫 항목으로 옮겼다. 히스토리 조회 성공·유효 커밋·활성 프로젝트에서만 표시되며 대기·오류·작업 트리에서는 나타나지 않는다. 빈 변경 결과의 유효 커밋은 상세 행 하나를 표시한다. 실제 파일 배지는 변경 파일 개수를 유지한다.

표시 항목 수·선택 번호 변환·행 선택 검증을 공통 도우미로 처리한다. file_selection과 실제 ChangedFile/FileChange 인덱스, viewer_target 및 백엔드는 유지했다. 0번 합성 행은 기존 상세 선택으로, 이후 행은 오프셋을 제거한 실제 파일 선택으로 연결한다. 기존 커밋 아이콘과 150ms ListLoading을 재사용한다.

## 자동 검증

- 새 테스트를 먼저 연결하여 구현 전 표시/선택 도우미 부재로 실패함을 확인했다.
- 신규 3개 테스트: 대기 후 성공에만 상세 행 등장, 빈 결과/오류/커밋 없음/작업 트리의 항목 구성, 상세/첫·마지막 실제 파일/동명 파일 매핑과 범위 밖·이전 revision·다른 프로젝트/탭 이벤트 거절.
- 기존 고정 행 관련 테스트 이름을 목록 의미로 갱신하고 오류 시 존재하지 않는 상세 행 클릭은 거절하도록 검증했다. 기존 상세 뷰 자동 선택과 상세 조회 오류·쓰기 후 실제 파일 선택 보존 테스트는 유지했다.
- 관련 상세 목록 테스트 6개 통과.
- cargo test --offline: 174개 통과, 실패 0개, 기존 수동 성능 측정 무시 2개.
- cargo fmt --check, cargo check --offline, cargo clippy --offline --all-targets: 성공. 기존 미사용 함수·UI collapsible_if·GPUI 실수 리터럴 및 의존성 미래 호환성 경고만 남는다.
- cargo build --offline: 성공. 이번에는 기본 target/debug/feather-git.exe가 정상 갱신되었다.

## 미검증 범위

실제 GUI에서 행의 스크롤·아이콘 배치·로딩 안내 전환을 수동 확인하지 않았다. 자동 테스트와 소스 검토를 시각 검증으로 보고하지 않는다. 기존 무시된 수동 성능 측정 테스트 2개도 실행하지 않았다.
