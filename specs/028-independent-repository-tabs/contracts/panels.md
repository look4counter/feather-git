# 패널 갱신 계약

저장소 탭 전환은 참조 목록만 변경한다. 작업 트리/히스토리의 기존 파일 목록·선택·뷰어·스크롤과 진행 중 요청은 유지된다. 태그/스태시는 기존 gateway로 백그라운드 조회하고 로컬/원격은 Project 스냅샷을 표시한다. 이전 탭 요청의 완료/오류는 폐기한다. 참조 행 클릭으로 실제 커밋이 바뀌면 기존 파일 갱신은 허용한다.

태그·스태시 요청은 저장소 목록 전용 ListLoading으로 150ms 뒤 공통 문구를 표시한다. 실제 완료 시 표시를 억제하고 결과/무효화 때 초기화한다. 로컬·원격과 변경 파일 패널은 해당 로딩 상태를 공유하지 않는다.

파일 탭·커밋 기록 선택은 반대로 저장소 목록을 재조회하지 않는다. 파일 탭은 참조 선택도 보존하고, 커밋 선택은 이전 참조 행 선택 작업을 무효화하지만 목록 요청과 결과는 유지한다. 프로젝트 문맥 전환만 전체 갱신을 사용한다.
