# 데이터 모델

파일 요청은 파일 비교 문맥·그래프·선택 보존만 포함한다. 저장소 목록 요청은 revision, project, path, stashes를 포함하며 결과는 원 요청과 이름 목록 또는 오류다. 참조 행 선택 요청은 기존 형식을 유지한다.

저장소 탭 변경은 목록 revision과 참조 선택 revision만 변경한다. 프로젝트 전환은 전체 무효화를 유지하고 파일 모드/커밋 변경은 파일 요청만 갱신한다. 커밋 변경은 이전 참조 선택 요청도 무효화한다. 목록 완료는 자체 revision·프로젝트·경로·탭·활성 상태가 맞을 때만 적용한다. 파일 완료와 저장소 완료는 서로의 결과를 수정하지 않는다.

저장소 목록 전용 ListLoading은 repository_revision을 사용한다. 요청마다 완료 신호를 새로 만들고 이전 타이머를 취소한다. 기존 파일 목록의 panel_loading과 독립적이다.
