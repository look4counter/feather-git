# 검증 안내

1. cargo test --offline로 탭별 파일 상태 보존·I/O 분리·역순/오류·기존 회귀를 확인한다.
2. cargo fmt --check, cargo check --offline, cargo clippy --offline --all-targets, cargo build --offline를 실행한다.
3. 새 빌드를 --backend-delay-ms 1500으로 실행한다. 변경 파일을 선택한 뒤 로컬/원격/태그/스태시를 교차 선택해 파일 목록과 뷰어가 사라지거나 다시 로딩하지 않는지 확인한다.
4. 히스토리 파일 조회 도중 저장소 탭을 바꾸어도 해당 파일 결과가 반영되는지 확인한다. 태그/스태시 빠른 교체·프로젝트 전환 후 이전 목록이 나타나면 안 된다.

추가 검증: --backend-delay-ms 1500으로 태그·스태시를 선택하면 150ms 뒤 저장소 목록에 공통 안내가 보여야 한다. 빠른 응답·빈 결과·오류·로컬/원격 전환·프로젝트 이동 후 이전 안내가 남지 않고 변경 파일 영역은 유지되어야 한다.

양방향 검증: 태그·스태시 목록을 완료하거나 조회 중인 상태에서 파일 탭과 커밋 행을 교차 선택한다. 저장소 목록·오류·로딩 타이머는 재시작하지 않고 파일만 조회해야 한다. 프로젝트를 바꾸거나 시작 화면에서 복귀하면 새 프로젝트의 저장소 목록을 올바르게 조회해야 한다.
