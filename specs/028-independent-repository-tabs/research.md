# 조사 및 결정

- 결정: 탭 클릭만 분기하지 않고 참조 목록 요청/완료를 파일 요청과 분리한다. 기존 결합 요청을 유지하면 탭 전환 전에 시작한 파일 완료가 새 탭의 참조 목록을 덮을 수 있다.
- 결정: 목록 조회에는 별도 요청 번호와 ReadSlot을 사용한다. 기존 reference_revision은 참조 행 선택의 최신성이므로 재사용하면 독립 작업을 잘못 취소할 수 있다.
- 결정: 로컬/원격 스냅샷과 태그/스태시 요청 시 조회 정책은 유지한다. 네 목록의 캐시 정책 통일은 이번 요청에 없다.
- 결정: 프로젝트 문맥 변경의 전체 갱신은 유지한다. 후속 사용자 요청에 따라 실제 커밋 선택·파일 탭·파일 변경은 파일 전용 갱신을 사용하고 저장소 목록 요청을 유지한다.
- 미해결 기술 항목은 없다.
