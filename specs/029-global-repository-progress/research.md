# 조사와 결정

- 결정: 전역 작업 상태를 Workspace에 보관한다. 기존 대화상자 엔티티를 작업 소유자로 유지하면 닫힌 대화상자 확인 때문에 결과가 폐기될 수 있다.
- 결정: 최근 저장소와 대화상자 작업은 하나의 실행/완료 경로를 사용한다. 작업 종류는 기존 Operation을 재사용하고 새 실행 풀을 추가하지 않는다.
- 결정: ProgressOverlay는 앱 루트의 마지막 absolute 자식으로 배치하고 전용 포커스를 사용한다. 창 전체를 덮되 다른 앱에는 영향을 주지 않는다.
- 결정: 최근 텍스트 말줄임은 데이터가 비어 있는 문제가 아니라 폭 할당 문제로 판단한다. 사용자의 ‘둘 다 ...’ 보고와 유효한 저장 값 및 폭 없는 truncate 구성을 근거로 명시적인 가용 폭/줄 높이를 보완한다. 실제 화면 접근은 거절되어 시각적 해결은 아직 확정하지 않는다.
- 미해결 설계 항목은 없다. 화면 검증 제한은 검증 기록에 구분한다.
