# 검증 결과: 전역 저장소 진행 표시와 최근 목록

검증일: 2026-11-14

## 구현 결과

src/ui.rs의 repository_operation으로 대화상자와 최근 저장소 열기 상태를 통합했다. 제출 시 입력 대화상자/구독을 닫고 공통 start_repository_operation으로 백엔드를 실행한다. 완료는 닫힌 대화상자 엔티티를 참조하지 않으며, 진행 상태 해제·포커스 복원 후 성공 프로젝트를 활성화하거나 기존 오류 경고를 표시한다. 최근 저장소 인라인 진행 문구는 제거했다.

앱의 relative 루트 마지막 자식에 기존 ProgressOverlay를 붙였다. src/progress.rs의 선택적 전용 포커스와 입력 차단, 목록/히스토리 스크롤 중지, 뷰어 입력 비활성화 및 탐색/선택/중복 요청 가드로 작업 중 배경 조작을 차단한다. 기존 시작 복원 화면과 150ms 목록 로딩은 유지했다.

src/repository_dialog.rs는 유휴/폴더 선택만 담당하고 내부 ProgressOverlay와 Working 상태를 제거했다. 일반 Dialog::overlay 확장 메서드는 기존 공통 컴포넌트 API 보존을 위해 유지했으며 현재 호출자가 없어 미사용 경고가 남는다.

최근 목록에서 저장 이름이 비어 있지 않음을 확인했고 사용자에게 두 텍스트 모두 말줄임으로 보인다는 답을 받았다. 목록·카드·이름/경로에 w_full/min_w_0을 전달하고 스크롤 목록의 flex 공간과 두 텍스트의 줄 높이/최소 높이/축소 방지를 명시했다. 기존 이름·경로와 세션 저장 형식 및 클릭 인덱스는 변경하지 않았다. 실제로 문제가 해소된 화면은 아직 확인하지 못했다.

## 자동 검증

- 상태 전이 테스트 3개를 먼저 연결하여 구현 전 공통 상태/메서드 부재로 실패함을 확인했다.
- 신규 테스트는 Open/Create/Clone 각각의 시작·중복 요청 거절·배경 탐색/선택 차단·실패 해제/상태 보존, 대화상자 없이 결과 적용/성공 해제, 복원·경고 중 시작 거절을 검증한다. Create/Clone 성공 UI 상태 검증은 기존 실제 프로젝트 결과를 주입한 상태 테스트이며 실제 생성/복제 수동 실행으로 보고하지 않는다.
- 기존 최근 저장소 재열기/실패 보존 테스트는 공통 상태/완료 경로로 갱신해 유지했다. 제거된 대화상자 내부 Working 검증은 유휴/폴더 선택의 입력 차단 테스트와 새 전역 작업 테스트로 대체했다.
- cargo test --offline: 190개 통과, 실패 0개, 기존 수동 성능 측정 무시 2개.
- 테스트 초기화 방식의 Clippy 경고를 수정한 뒤 관련 전역 상태 테스트 3개를 다시 실행해 통과했다. 운영 코드는 전체 테스트 이후 변경하지 않았다.
- cargo fmt --check, cargo check --offline, cargo clippy --offline --all-targets: 성공. 기존 미사용 함수·UI collapsible_if·GPUI 실수 리터럴·의존성 미래 호환성 경고와 위 Dialog::overlay 미사용 경고가 남는다.
- cargo build --offline: 컴파일·링크 후 기본 target/debug/feather-git.exe 교체가 접근 거부(os error 5)로 실패했다. 실행 중 앱은 강제 종료하지 않았다.
- 최신 링크 결과를 target/feather-git-global-progress.exe로 복사하여 SHA-256 일치 및 --help 종료 코드 0을 확인했다. 기본 실행 파일은 앱 종료 후 재빌드가 필요하다.

## 승인 거절과 미검증 범위

computer-use 스킬의 sky로 실제 Feather Git 창을 식별했으나 get_window_state에서 ‘Computer Use was not approved to use feather-git’로 거절되었다. 자동 승인 검토의 구체적 사유는 제공되지 않았다. 다른 UI 자동화·화면 캡처 방식으로 우회하지 않았다.

따라서 실제 전역 오버레이의 범위·포커스 복원·배경 입력 차단, 최근 이름/경로의 말줄임 해소와 좁은 창 레이아웃을 화면에서 검증하지 못했다. 코드 변경과 자동 검증을 시각 검증으로 보고하지 않는다. 기본 실행 파일 교체도 잠금 해제 이후 적용이 남아 있다.

## 수렴 결과

요구사항 7개·성공 기준 4개·사용자 이야기 3개와 계획의 공통 작업 소유·대화상자 종료·루트 오버레이·입력/포커스·최근 목록 레이아웃·데이터 보존을 코드와 자동 테스트에 대조했다. 구현 누락·모순·범위 외 변경은 0건이며 추가 코드 작업은 없다. 실제 GUI 가독성·포커스/입력 동작 검증과 기본 exe 교체는 위 제한으로 남아 있어 시각적 해결을 확정하지 않는다. 헌법은 미작성 템플릿으로 규범 검사를 생략하고 AGENTS.md의 계층·호환성·기존 변경 보존을 확인했다. 수렴 후 작업 결과 기록에서 T007을 완료 표시했다.

## 후속 말줄임 원인 수정

사용자가 폭/높이 보완 뒤에도 두 텍스트가 ‘...’만 보인다고 보고했다. specs/030-text-truncation-cache에서 GPUI가 한 줄 텍스트의 말줄임 폭 변경을 무시하는 캐시 결함을 재현하고 수정했다. 앞선 최근 카드 레이아웃 보완만으로 문제를 해결한 것으로 간주하지 않는다. 후속 자동 검증과 GUI 미검증 범위는 해당 기능의 validation.md를 참조한다.
