# 조사와 결정

- 결정: 최근 카드 스타일을 더 바꾸지 않고 공급 GPUI 캐시 조건을 수정한다. 증상은 한 줄의 wrap_width=None에서 다른 truncate_width를 무시하는 실제 코드와 일치한다.
- 결정: 기존 캐시 필드에 말줄임 폭만 추가하고 같은 조건에서 캐시를 유지한다. 캐시를 전부 끄는 대안은 불필요한 글꼴 측정을 늘리므로 제외했다.
- 결정: 원본 runs는 불변으로 보관하고 재측정에만 복사한다. truncate_line이 스타일 구간을 변경하기 때문이다.
- 결정: 운영 순수 판정을 앱 테스트에 직접 포함해 검증한다. GPUI test-support 기능 활성화는 불필요한 개발 의존성과 플랫폼 기능을 추가하므로 제외했다.
- 미해결 설계 항목은 없다. GUI 접근 승인 거절의 제한은 유지한다.
