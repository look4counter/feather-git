# 조사와 결정

- 결정: 세션이나 canonicalize 결과를 바꾸지 않고 UI 전용 포맷터를 사용한다. 내부 경로를 바꾸면 긴 경로 I/O·저장소 동일성 비교·최근 재열기 계약에 영향을 줄 수 있다.
- 결정: 알려진 드라이브/UNC 형태만 변환한다. 무조건 앞 네 글자를 제거하면 장치·볼륨 이름 공간의 의미가 바뀔 수 있어 제외했다.
- 결정: 사용자 입력 상자의 원문과 라이브러리 오류 전체는 변경하지 않는다. 실제 I/O 입력과 표시 문구를 구분한다.
- 미해결 기술 항목은 없다. 기존 GUI 접근 승인 제한은 유지한다.
