## 의존성과 순서

T001 → T002 → T003 → T004 → T005 → T006 → T007. 실제 사용자 데이터 삭제는 수행하지 않는다.

## 검증 결과

- 삭제 구현 전 임시 저장소 전체 삭제 테스트 실패를 확인한 뒤 구현했다.
- 전체 테스트: 208개 통과, 실패 0개, 수동 성능 테스트 2개 제외.
- Windows 정션 경로 거절·외부 연결 대상 보존·잠긴 파일 오류 테스트 통과.
- 목록 전용 삭제의 파일·탭 보존과 세션 반영, 실패 상태 보존, 삭제 성공 시 탭 정리와 하위 저장소·마지막 탭 처리를 검증했다.
- cargo fmt --all -- --check, cargo check --offline, cargo clippy --offline --all-targets, cargo build --offline 통과. 기존 미사용 코드·GPUI 숫자 타입·조건문·의존성 미래 호환성 경고가 남는다.
- 실제 사용자 저장소를 삭제하지 않았다. GUI의 휴지통 표시·마우스 이벤트·팝업 배치는 실행 검증하지 못했다. quickstart.md의 수동 확인 절차를 남겼다.
- 수렴 점검: 기능 요구사항 7개, 성공 기준 4개와 두 사용자 이야기 및 계획의 계층 분리·기존 세션 호환성을 코드와 테스트로 대조했다. 미구현 차이는 없고 GUI 실행 검증 한계는 별도 기록했다.
