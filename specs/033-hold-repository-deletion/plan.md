# 구현 계획

## 실제 구조와 영향
Rust 2024·GPUI 앱에서 Workspace가 최근 삭제 팝업의 대상과 포커스를 소유한다. recent_repository_dialog::render가 세 버튼의 on_click에서 선택 콜백을 호출하며 Workspace가 비동기 백엔드 삭제를 실행한다. 기존 Dialog와 전역 ProgressOverlay는 유지한다.

## 설계
recent_repository_dialog.rs에 공유 누름 상태를 두고 Workspace가 팝업 수명 동안 소유한다. 시작 시간·세대 번호를 저장하고 매 렌더의 경과 시간으로 배경 너비를 계산한다. UI 애니메이션 프레임만 요청하며 스레드·폴링 타이머는 추가하지 않는다. 완전히 찬 프레임 다음 콜백에서 세대·활성 창·포커스를 재검증하고 한 번만 완료한다. 원래 파일 삭제 on_click은 제거하고 좌측 mouse_down에서 시작한다. mouse_up, mouse_up_out, 실제 버튼 영역 밖 이동과 창 이탈에서 초기화한다. GPUI의 hover는 누름 중에도 해제되므로 영역을 캔버스에서 얻어 마우스 이동의 캡처 단계에서 검사한다. 창 비활성화·포커스 상실 구독은 팝업 수명 동안 보관한다. 팝업 열기·선택 종료에서도 초기화한다.

## 헌법과 제약
헌법은 미작성 템플릿이므로 규범 검사를 건너뛴다. AGENTS.md의 계층 분리·최소 변경을 준수한다. 변경은 src/recent_repository_dialog.rs와 src/ui.rs에 한정하며 백엔드·세션 형식·공개 API는 변경하지 않는다. 새 의존성을 추가하지 않는다.

## 검증
누름 상태의 임계 전후·중간 진행·취소·다시 누름·이전 세대·중복 완료를 결정적 시간으로 테스트한다. 기존 영구 삭제 및 목록 유지 테스트를 포함해 전체 테스트와 fmt/check/clippy/build를 실행한다. GUI 누름과 실제 채움 배치는 미검증이면 명시한다.
