# 길게 눌러 저장소 영구 삭제

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.

## 사용자 이야기 (P1)
저장소 파일 삭제 버튼을 짧게 클릭하면 삭제하지 않는다. 왼쪽 마우스 버튼을 계속 누르면 버튼이 왼쪽에서 오른쪽으로 채워지고, 가득 찬 모습이 표시된 뒤 삭제한다. 항목만 삭제와 취소 동작은 유지한다.

## 확인 사항

2026-11-14: 삭제 범위·영구 삭제 방식은 기존 사용자 답변을 유지한다. 누름 시간은 기본 1.5초로 정하며 별도 질문이 필요한 모호성은 없다.

## 요구사항

- FR-001: 파일 삭제는 1.5초 연속 누름이 완료되어야 실행한다. 클릭·Enter·Space로 즉시 삭제하지 않는다.
- FR-002: 누르는 동안 버튼 배경이 경과 시간에 비례해 왼쪽부터 채워지며 안내에 누름 시간을 표시한다. 가득 찬 프레임 이후 삭제한다.
- FR-003: 손을 떼거나 포인터가 버튼을 벗어나거나 창·팝업 포커스가 사라지면 진행을 초기화한다. 다시 누를 때 0부터 시작한다.
- FR-004: 팝업 취소·닫기·새 대상 선택 시 이전 진행과 완료 예약을 무효화한다. 한 번의 누름으로 삭제를 한 번만 실행한다.
- FR-005: 목록 전용 삭제·취소·기존 비동기 삭제와 오류 처리·전역 진행 표시는 유지한다.

## 경계와 성공 기준

SC-001: 임계시간 직전에는 삭제 0회, 임계시간 완료 후에는 1회만 실행한다.
SC-002: 누름 취소·재시작·팝업 교체 후 이전 완료 예약은 삭제를 실행하지 않는다.
SC-003: 기존 테스트와 관련 빌드·검사를 통과하며 실제 사용자 폴더 삭제를 실행하지 않는다.
