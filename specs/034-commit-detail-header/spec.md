# 비교 뷰어 패널 헤더 정리

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.
> 후속 변경 참고: [035](../035-viewer-loading-message/spec.md) · [050](../050-panel-context-menus/spec.md).
> 현재 기준: 파일 미선택 헤더는 050의 선택된 파일 0개를 사용한다. F5는 080의 전역 로컬 새로고침이다.

## 사용자 이야기 (P1)
커밋 상세·Diff Viewer 모두 새로고침·단축키 버튼이 없는 공통 패널 헤더를 사용한다. 변경 파일을 선택하면 응답을 기다리지 않고 선택 파일명으로 제목을 즉시 바꾼다.

## 확인

2026-11-14: 후속 사용자 요청으로 모든 뷰어 대상에 동일 스타일을 적용한다. 파일명은 변경 파일 목록에 표시되는 이름을 사용한다. 기존 키보드 기능과 상세·파일 내용을 유지한다. 추가 질문은 필요하지 않다.

## 요구사항

- FR-001: 커밋 상세와 Diff Viewer 헤더의 새로고침·단축키 버튼을 제거한다.
- FR-002: 헤더 높이·좌우 여백·제목 굵기·아래 구분선을 다른 패널과 일치시킨다.
- FR-003: 파일 비교·상세 조회·텍스트 선택·기존 키보드 기능을 유지한다.
- FR-004: 변경 파일 선택 즉시 제목을 선택 파일명으로 표시한다. 로딩·오류 중에도 선택 파일명을 유지하고 빠른 선택 전환 시 최신 선택을 따른다. 커밋 상세 제목과 빈 화면 기본 제목은 유지한다.

## 성공 기준과 경계

SC-001: 상세·파일·빈 화면의 헤더 스타일이 동일하고 두 버튼이 없다.
SC-002: 관련 빌드·정적 검사·기존 테스트를 통과한다.
SC-003: 백엔드 응답 전·실패 후에도 현재 선택 파일명이 제목으로 표시되며 과거 응답으로 제목이 바뀌지 않는다.
