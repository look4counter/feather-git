## 커밋 상세 전환 검증
같은 저장소에서 커밋을 연속 선택한다. 이전 상세가 잠시 유지되다가 새 상세로 한 번에 바뀌고 새 내용은 맨 위에서 시작해야 한다. 150ms 이상 대기하여 공통 조회 안내가 나타나면 기존 본문과 스크롤바가 사라지고 본문 패널 전체 중앙에 안내만 표시되어야 한다. 최초 커밋 상세 조회도 같은 중앙 안내를 사용한다. 빠른 전환의 늦은 응답이 현재 선택을 덮어쓰면 안 된다. 다른 저장소·파일 diff·인코딩 전환은 이전 내용을 유지하지 않는다. 조회 오류는 이전 상세 대신 오류로 전환한다.
자동 검증 명령: cargo test --offline diff_viewer::tests 및 cargo test --offline virtual_list::loading_tests.
