# 작성자·커미터 사진과 두 줄 표시

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.
> 후속 변경 참고: [037](../037-github-avatar-cache/spec.md).

## 사용자 이야기 (P1)
커밋 상세에서 작성자와 커미터 각각 사진이 이름·시간 두 줄의 왼쪽에 걸쳐 보인다. 첫 줄은 이름과 기존 이메일, 둘째 줄은 작성자의 authored: 시간 또는 커미터의 committed: 시간이다. 기존 커밋·부모·전체 메시지와 선택·복사·스크롤은 유지한다.

## 확인

2026-11-14 사용자 답변: Gravatar에서 조회하고 없으면 기본 아이콘. 커미터는 committed:로 표시한다. 이름 옆 기존 이메일 정보는 유지한다.

## 요구사항

- FR-001: 작성자·커미터 각각 사진 하나가 두 줄 높이에 걸쳐 표시되고 두 텍스트 줄이 같은 왼쪽 위치에 정렬된다.
- FR-002: 이메일을 정규화한 해시로 Gravatar를 조회하고 사진 없음·빈 이메일·네트워크 오류·조회 중에는 기본 프로필 아이콘을 표시한다.
- FR-003: 사진 조회가 커밋 내용·이름·시간 표시나 Git 조회를 기다리게 해서는 안 된다. 반복 렌더에서 같은 사진을 중복 조회하지 않으며 동시 처리와 대기 수를 제한한다.
- FR-004: 전체 메시지·부모 정보·텍스트 선택·복사·가로세로 스크롤·기존 지연 로딩과 제목을 유지한다. 부모 수가 달라도 사진 위치가 정확해야 한다.

## 성공 기준과 경계

SC-001: 초기·일반·병합 커밋 모두 사진과 두 줄 텍스트의 위치가 맞는다.
SC-002: 사진 실패·오프라인·연속 커밋 전환에도 현재 텍스트가 표시되고 잘못된 사람 사진이 연결되지 않는다.
SC-003: 해시·행 매핑·시간과 기존 기능 테스트, 빌드·정적 검사를 실행하고 GUI·외부 네트워크 미검증을 보고한다.
