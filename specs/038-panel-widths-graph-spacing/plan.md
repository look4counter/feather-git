# 구현 계획

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

## 실제 구조
직전 구현은 두 행의 왼쪽 너비를 따로 저장하고6px핸들을 레이아웃에 삽입한다. 공통 높이는54%로 고정되어 십자 크기 조절 요구를 충족하지 못한다. 기존 이벤트 캡처·종료·창 활성화 구독은 재사용한다.

## 설계
src/panel_layout.rs를 공통 좌우·상하 분할 상태로 변경한다. 세로·가로·양축 드래그를 순수 계산으로 처리하고 최소 크기를 제한한다. ui.rs는 두 열을 같은 상단 높이로 나누며 핸들을 레이아웃 공간에서 제거한다. 본문 캔버스가 전체 길이의 수직·수평1px선을 마지막에 그린다. 투명6px핸들과 중앙12px핸들을 그 위에 겹치며 배경·호버 배경으로 선을 덮지 않는다. 변경 파일·뷰어의 기존 상단 경계는 제거해 캔버스가 유일한 경계를 소유한다.

드래그는 두 좌표와 시작 분할 크기를 보관한다. 기존 요청·선택·본문·스크롤은 그대로 두며 그래프19px간격도 수정하지 않는다. 새 의존성이나 저장 형식 변경은 없다. 변경 파일은 src/panel_layout.rs와 src/ui.rs다. 헌법은 미작성 템플릿으로 규범 검사를 건너뛰고 AGENTS.md의 최소 변경·계층 분리를 따른다.

## 검증
기존 독립 행 테스트를 정정된 공통 축·중앙 두 축·최소 크기·축 고정·화면 축소 테스트로 대체한다. 기존 드래그 수명·요청 비발생 테스트를 두 좌표로 갱신한다. fmt/check/test/clippy/build를 실행한다. 실제 GUI의 선 연결과 히트 영역 검증 한계는 명시한다.
