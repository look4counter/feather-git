# 십자 패널 크기 조절과 그래프 간격

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.
> 후속 변경 참고: [059](../059-footer-overlay-actions/spec.md).
> 현재 기준: 현재 그래프 레인 간격은 후속 059에 따라 18px이다. 십자 크기 조절 계약은 유지한다.

## 사용자 이야기 (P1)
네 패널은 하나의 공통 세로선과 공통 가로선으로 나뉜다. 세로선을 드래그하면 전체 좌우 너비, 가로선을 드래그하면 전체 위아래 높이를 조절한다. 중앙 교차점을 드래그하면 두 축이 동시에 움직인다. 경계선은 핸들·교차점·호버 상태에서도 끊기지 않는다. 그래프 레인 간격은 후속 059 FR-019에 따라 18px를 유지한다.

## 확인

2026-11-14 사용자 정정: 독립적인 위·아래 너비가 아니라 십자 형태로 크기를 조절해야 한다. 핸들 때문에 선이 끊겨서는 안 된다. 기존 독립 너비 설계와 테스트는 이 요구로 대체한다.

## 요구사항

- FR-001: 공통 세로·가로 경계와 중앙 교차점에서 각각 한 축·두 축 크기 조절을 제공한다.
- FR-002: 왼쪽200px·오른쪽320px·위160px·아래160px 최소를 유지하며 작은 화면에서는 비례 축소한다.
- FR-003: 해제·창 이탈·비활성화·탭 전환·모달 표시 시 드래그를 종료하고 기존 히스토리 열 조절과 충돌하지 않는다.
- FR-004: 경계선 두 개를 전체 길이로 연속 표시한다. 투명한 핸들을 선 위에 겹쳐 교차점과 호버·드래그 중에도 공백이 생기지 않게 한다.
- FR-005: 크기 조절은 추가 백엔드 조회·세션 저장을 발생시키지 않고 선택·본문·스크롤과 그래프 18px 간격을 유지한다. 크기는 앱 실행 동안 유지한다.

## 성공 기준

SC-001: 축별 드래그는 해당 축만, 중앙 드래그는 두 축을 함께 바꾸고 네 패널의 경계가 일치한다.
SC-002: 경계는 항상 수직·수평 전체 길이로 연결되며 최소 크기와 종료 조건이 지켜진다.
SC-003: 관련 자동화 검사와 빌드를 통과하고 실제 GUI 미검증은 명시한다.
