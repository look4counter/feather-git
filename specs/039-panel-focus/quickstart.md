# 검증 안내

자동 검증: cargo fmt --check, cargo test, cargo clippy --all-targets.

실제 창 검증:
1. cargo run으로 저장소를 열고 커밋 상세 또는 파일 diff 본문을 클릭한다.
2. 참조·파일·히스토리의 제목·행·빈 영역을 각각 클릭해 뷰어 커서가 사라지는지 확인한다.
3. 뷰어 빈 영역과 본문을 클릭해 포커스 및 복사가 복구되는지 확인한다.
4. 단축키 설정 입력창에 입력하고 부모가 포커스를 탈취하지 않는지 확인한다.
5. 대화상자와 작업 진행 중 배경 클릭이 모달 포커스를 변경하지 않는지 확인한다.
6. 창 비활성화 시 커서 숨김, 재활성화 시 실제 포커스에 따른 표시를 확인한다.
7. 파일 선택·텍스트 드래그·분할선 드래그가 유지되는지 확인한다.
