# 검증 안내

1. cargo test --offline로 재선택 보존·단어 선택 경계 및 기존 회귀 테스트를 실행한다.
2. cargo fmt --check와 cargo clippy --offline --all-targets 및 cargo build --offline를 실행한다.
3. 실제 창에서 커밋 선택 후 파일을 선택하고 같은 커밋 행을 눌러 파일 diff가 유지되는지 확인한다. 다른 행을 누르면 상세로 이동해야 한다.
4. 커밋 상세와 파일 diff에서 단어의 첫 글자·마지막 글자를 더블클릭하고 복사한다. 밑줄 식별자·한글·숫자·기호·탭·빈 줄을 확인한다.
5. 일반 드래그·Shift 클릭·포커스 전환이 유지되는지 확인한다. 실제 GUI 미실행 시 결과에 한계를 남긴다.
