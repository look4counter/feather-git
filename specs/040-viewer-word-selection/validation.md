# 검증 결과

## 단계별 검토

명세·명확화·계획·작업·일관성 분석·구현·수렴 단계를 수행했다. 추가 명확화 질문은 0개이며 명세 품질 점검 5/5 통과다. FR-001~002는 T003~004, FR-003~005는 T005~007, FR-006은 T007~008에 대응한다. 두 사용자 이야기와 경계 조건에 미해결 모호성·누락·모순·중복은 없다. Constitution은 미작성 템플릿이므로 규칙 검토를 생략했다. 확장 훅 파일은 없다.

## 재현 및 구현 결과

- 재선택 보존 테스트는 구현 전 !state.select_history_row(project, 1) 단언에서 실패하여 기존 조회 재시작 문제를 재현했다.
- 단어 선택 테스트는 구현 전 select_word 미구현으로 컴파일 실패를 확인했다.
- src/ui.rs: select_history_row 입구에서 같은 프로젝트·기록 모드·같은 커밋이면 false를 반환한다. 참조 이동용 select_commit은 유지했다.
- src/text_selection.rs: 문자 인덱스 기반 단어·연속 공백·단일 기호 선택을 추가했다. 한글·밑줄 식별자·숫자·빈 줄·범위 밖의 선택과 복사를 검증했다.
- src/diff_viewer.rs: 공통 본문의 더블클릭 이벤트를 단어 선택에 연결했다. 클릭 글자 경계와 원문 포함 문자 위치를 사용하여 단어 마지막 글자 및 확장된 탭을 처리한다. 더블클릭 후 드래그를 시작하지 않는다.
- 기존 테스트 중 같은 행을 새 이동으로 사용하던 준비 조건은 다른 행 이동 또는 명시적 최초 전환으로 변경했다. 같은 행의 파일 선택 보존도 명시적으로 검증한다. 기존 오류·취소·참조·스크롤 검증 단언은 유지했다.

## 자동 검증

- cargo test --offline: 227개 통과, 실패 0개, 기존 성능 측정용 2개 제외. 새 테스트 3개를 포함한다.
- cargo fmt --check: 통과.
- cargo clippy --offline --all-targets: 통과. 기존 미사용 코드·중첩 조건 및 의존성 경고는 남아 있다.
- cargo build --offline: 컴파일·링크 후 target/debug/feather-git.exe 교체 단계에서 액세스 거부로 실패했다. 실행 파일 잠금으로 보이며 기존 실행 앱을 종료하지 않았다. 테스트 실행 파일의 컴파일·링크 및 실행은 성공했다.

## 수렴 검토

FR-001~006과 SC-001~002, 두 사용자 이야기의 수용 기준 및 계획의 호출 경계·좌표 변환·선택 재사용을 코드와 테스트로 확인했다. 미구현·부분 구현·상충·범위 밖 추가 기능은 0건이다. 새 의존성·백엔드·영속 데이터·포커스 구조 변경은 없다. 추가 구현 작업은 없다.

## 미검증 범위

실제 창에서 마우스 더블클릭, Shift 조합, 드래그 및 모달 상호작용을 이번에 구동하지 않았다. quickstart.md에 수동 검증 절차를 남겼다. 일반 실행 파일 교체 완료도 미검증이며 실행 파일 잠금 해제 후 빌드 재확인이 필요하다. 이를 자동 테스트 통과 또는 코드 수렴과 구분한다.
