# 구현 계획: DiffViewer 고정 여백

## 기존 구조와 원인
Rust 2024·GPUI 앱이다. src/diff_viewer.rs는 본문을 shape_styled_line과 24px 행 높이로 직접 그리지만 줄 번호·기호는 일반 Div 텍스트를 가운데 정렬하므로 기준선이 다르다. diff_row 전체가 VirtualList의 가로 스크롤 컨테이너에 들어가 번호와 기호도 움직인다. 선택은 본문 캔버스 좌표, 드래그는 목록 뷰포트·text_left·가로 오프셋을 사용한다.
src/virtual_list.rs는 세로 가상화·휠·스크롤 핸들·스크롤바를 공유한다. 다른 목록 및 커밋 상세가 기존 모드를 사용하므로 기본 동작은 유지한다.

## 설계
VirtualList에 선택적인 fixed_left_width 설정을 추가한다. 기본값 0은 기존 전체 가로 스크롤이다. 고정 모드에서는 가상 목록 자체는 뷰포트 폭을 유지하고 가로 핸들의 범위를 본문 폭 기준의 투명한 스크롤 extent 컨테이너에서 계산한다. 가로 스크롤바 시작점만 고정 여백 뒤로 옮긴다. 세로 목록은 한 개로 유지하여 두 목록 동기화나 이중 가상화를 피한다.
DiffViewer는 diff에서만 고정 모드를 사용한다. 본문 캔버스에서 가로 오프셋을 그림·선택 배경·커서·마우스 좌표에 적용하고 본문 경계에서 클리핑한다. 고정 영역은 기존 행 레이아웃에 두어 이동하지 않는다. 키보드 커서 노출과 드래그 자동 스크롤은 본문 시작점을 기준으로 한다.
번호와 기호도 본문과 같은 shape_styled_line 및 ROW_HEIGHT로 그려 기준선을 일치시킨다. 체크박스와 구간 Stage 클릭은 그대로 유지한다.
Enter 기본 바인딩은 빈 값으로 바꾸고 저장 설정의 Enter도 사용하지 않도록 정규화한다. Enter 명령은 해석하지 않으며 설정 입력에서 Enter 재등록은 오류로 안내한다. Stage 버튼은 유지하고 미지정 단축키 괄호 표시는 생략한다.

## 영향 범위와 제약
src/diff_viewer.rs, src/virtual_list.rs 및 해당 파일의 테스트만 변경한다. 스크롤 핸들·공개 데이터 형식·백엔드·Stage 처리·부분 Stage 기능은 유지한다. 외부 의존성은 추가하지 않는다. Constitution은 미작성 템플릿이므로 적용 규칙이 없다.

## 검증
고정 여백의 가로 기하·좁은 패널·스크롤바 범위, 본문 좌표 변환과 커서 노출, Enter 기본값·저장 설정·다른 키 유지 테스트를 추가한다. cargo fmt --check, cargo test --offline, cargo clippy --offline --all-targets, cargo build --offline를 수행한다. 실제 화면의 글자 정렬과 고정 스크롤 확인은 가능한 범위와 한계를 별도 기록한다.
