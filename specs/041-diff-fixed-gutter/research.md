# 조사 결과

- 결정: 하나의 가상 목록을 유지하고 본문만 그리기 단계에서 가로 이동한다. 근거: 두 가상 목록의 세로 동기화와 중복 상태를 피하고 기존 행·선택 인덱스를 유지한다.
- 대안: 여백을 가로 오프셋 반대로 옮기면 렌더 시점과 클리핑·이벤트 경계가 서로 달라질 수 있어 제외한다. GPUI Div에는 고정 위치 스크롤 접두부 기능이 없다.
- 결정: 기존 ScrollHandle은 본문 크기의 투명 스크롤 컨테이너에서 범위를 계산한다. 기존 휠·스크롤바·범위 제한을 재사용하므로 임의 상태를 복제하지 않는다.
- 결정: 번호·기호도 본문과 같은 캔버스 글꼴·행 높이로 그린다. 임의의 위아래 픽셀 보정 대신 실제 원인을 제거한다.
- 결정: Stage 버튼은 사용자 정정에 따라 유지하고 Enter 기본값·저장값만 제거한다. 다른 키와 Stage 동작은 유지한다.
