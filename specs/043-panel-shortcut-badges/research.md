# 조사 결과

- 결정: 하단 안내는 실제 포커스를 읽고 포커스 구독과 뷰어 관찰로 갱신한다. 별도 활성 패널 상태를 복제하면 자식 입력과 모달 전환에서 어긋날 수 있어 제외한다.
- 결정: 기존 Stage 잠금과 gix 필터를 재사용한다. 외부 git 명령이나 별도 인덱스 구현을 앱 경로에 추가하지 않는다.
- 결정: 파일 Stage 토글은 비동기로 수행하고 기존 갱신 요청의 selected_file을 반대 Stage 상태로 지정한다. 인덱스 재정렬 후에도 올바른 행을 선택한다.
- 결정: 뷰어는 실제 사용자 지정 toggle 키를 표시하여 안내와 실행이 일치하게 한다.
