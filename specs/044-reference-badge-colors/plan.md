# 구현 계획

## 기존 구조와 영향 범위
Rust 2024·GPUI 앱이다. src/ui.rs의 history_row는 행 인덱스로 색을 정해 badge_base와 reference_icon_view에 같은 값을 전달한다. ReferenceKind는 이미 원격·로컬·태그·기타를 구분한다. 따라서 이 위치의 색상 분기만 종류 우선으로 변경하며 새 추상화·의존성은 도입하지 않는다.

## 설계
원격은 기존 삭제 글자와 같은 붉은색 계열 #FFA7B2, 로컬은 기존 ACCENT #64D9BF를 사용한다. 태그·기타는 첫 행 ACCENT, 나머지 #B9A2EF의 기존 분기를 유지한다. 배경·아이콘 형태·선택 및 다른 화면은 변경하지 않는다.

## 아키텍처 검토와 검증
Constitution은 미작성 템플릿이므로 적용 가능한 규칙은 없다. UI의 표시 분기만 수정해 기존 책임과 데이터 형식을 유지한다. 낮은 영향의 색상 변경이므로 새 테스트는 추가하지 않고 분기·전달 경로 검토와 cargo fmt --check, cargo check --offline로 검증한다. 실제 화면 미검증 여부를 보고한다.
