# 기능 명세: 참조 배지 종류별 색상

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.
> 후속 변경 참고: [045](../045-stage-refresh-whitespace/spec.md) · [059](../059-footer-overlay-actions/spec.md).
> 현재 기준: 로컬 텍스트는 민트색·원격은 붉은색·태그는 보라색이다. 로컬·태그 아이콘은 후속 059에 따라 흰색이다.

작성일: 2026-11-14
상태: 명확화 완료

## 사용자 시나리오 및 검증

### 사용자 이야기 1 — 원격과 로컬 구분 (우선순위 P1)
커밋 기록 메시지의 원격 배지는 붉은색 계열, 로컬 배지는 기존 민트색 계열로 표시한다.
수용 기준: 첫 행과 나머지 행 모두 원격은 붉은색, 로컬은 민트색이며 글자와 아이콘에 같은 색을 적용한다. 태그와 기타 참조의 기존 색상 기준은 유지한다.
독립 검증: 종류별 색상 분기와 아이콘·글자 전달 경로를 확인한다.

## 요구사항

- FR-001: 커밋 기록의 원격 배지 글자·아이콘은 행 위치와 무관하게 붉은색 계열이다.
- FR-002: 로컬 배지 글자·아이콘은 행 위치와 무관하게 현재 강조 민트색 계열이다.
- FR-003: 태그·기타 참조, 배경·배치·선택·아이콘 종류 및 다른 화면의 색상은 유지한다.

## 성공 기준

- SC-001: 모든 행의 원격·로컬 색상 분기가 종류에 따라 결정되고 동일 배지의 글자·아이콘 색이 일치한다.

## 가정 및 명확화

추가 질문 0개. 현재 녹색 계열은 기존 ACCENT 민트색이다. 변경 대상은 커밋 기록 메시지 배지이며 태그 색상 변경은 요청 범위 밖이다.
