# 조사 결과

- 결정: Stage 완료 갱신에 그래프 준비를 명시적으로 금지한다. 현재 파일 조회 경로는 이미 커밋·전체 저장소를 읽지 않지만 캐시 불일치 시 그래프를 재생성할 수 있다.
- 결정: 공백·탭은 기존 셰이핑 위에 장식으로 그린다. 기호로 문자열을 치환하면 UTF-8 길이와 글자 폭이 달라져 클릭·복사 위치를 다시 구현해야 하므로 제외한다.
- 결정: EOF는 실제 양쪽 파일의 마지막 줄 여부를 메타데이터로 전달한다. diff 목록 마지막 행에 무조건 붙이면 중간 구간이나 잘린 결과에서 거짓 파일 끝이 생기므로 제외한다.
- 결정: 빈 파일의 EOF는 표시 전용 행으로 처리한다. Stage와 복사의 줄 인덱스를 바꾸지 않는다.
