# 기능 명세: Stage 갱신 범위와 diff 공백 표시

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.
> 후속 변경 참고: [047](../047-status-flat-tree-sort/spec.md) · [080](../080-history-revert-reset/spec.md).
> 현재 기준: F5는 080에 따라 어느 패널에서든 전체 로컬 상태를 갱신한다. Stage 완료 후 자동 갱신은 여전히 파일·diff에 한정한다. 정렬은 047을 따른다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1 — Stage 후 파일만 갱신 (우선순위 P1)
파일 Stage/Unstage 및 부분 Stage 후 변경 파일과 해당 diff만 갱신한다.
수용 기준: 저장소 전체·참조 목록·커밋 기록 조회와 그래프 재생성을 실행하지 않는다. 기존 커밋·그래프·선택 상태를 보존하고 변경 파일의 정확한 상태와 순서를 갱신한다.
독립 검증: 쓰기 완료 이벤트가 만드는 요청과 실행 결과가 파일 조회만 수행하고 커밋 및 참조 상태를 유지하는지 확인한다.

### 사용자 이야기 2 — 태그 배지 통일 (우선순위 P1)
커밋 기록의 태그 배지는 행 위치와 무관하게 보라색이다.
수용 기준: 첫 행·다른 행 모두 태그 글자와 아이콘이 보라색이며 원격 붉은색·로컬 민트색은 유지한다.
독립 검증: 배지 종류별 색상 분기를 확인한다.

### 사용자 이야기 3 — 보이지 않는 문자 표시 (우선순위 P1)
파일 diff 본문에서 공백은 점, 탭은 화살표로 보이며 실제 파일 끝을 식별할 수 있다.
수용 기준: 일반 공백은 ·, 탭은 →로 표시하되 탭의 기존 4칸 폭을 유지한다. 파일 마지막 줄이 diff에 표시되면 그 끝에 <EOF>를 붙인다. 빈 텍스트 파일은 별도 <EOF> 표시를 제공한다. 원문·복사·선택·Stage 데이터에는 표시 문자가 포함되지 않는다.
독립 검증: 유니코드·탭·공백의 선택과 복사, 마지막 개행 유무·추가·삭제·빈 파일·파일 끝을 포함하지 않는 중간 구간을 테스트한다.

## 요구사항

- FR-001: Stage 변경 후 갱신 요청은 변경 파일·diff에 한정하고 커밋·그래프·참조·저장소 전체 갱신을 요청하지 않는다.
- FR-002: 변경 파일 정렬과 파일 상태 선택 보존 및 오류 처리를 유지한다.
- FR-003: 태그 글자·아이콘은 항상 보라색이며 원격·로컬과 기타 색상 기준을 유지한다.
- FR-004: 파일 diff 본문의 공백·탭을 원문 위의 장식으로 표시하고 탭 폭을 유지한다.
- FR-005: 실제 이전·이후 파일 마지막 줄에 <EOF>를 표시하며 중간 구간과 잘린 결과에는 거짓 파일 끝을 추가하지 않는다.
- FR-006: 표시 장식은 복사·선택·더블클릭·커서·가로 스크롤·Stage 내용에 영향을 주지 않는다.
- FR-007: 빈 텍스트 파일은 안전하게 <EOF>를 표시하고 바이너리·오류·커밋 상세에는 파일 공백·EOF 장식을 적용하지 않는다.

## 성공 기준

- SC-001: Stage 갱신 범위 및 기존 파일 선택 회귀 테스트가 통과한다.
- SC-002: EOF 식별·공백 장식 좌표·원문 복사 및 Stage 회귀 테스트가 통과한다.

## 가정과 명확화

추가 질문 0개. <EOF>는 diff 목록의 끝이 아니라 실제 파일의 끝을 뜻한다. 이전·이후 양쪽의 마지막 줄이 별도 행이면 각각 표시한다. 커밋 상세 텍스트는 변경 대상이 아니다. 새 토글 설정이나 줄바꿈 표시는 추가하지 않는다.

## 사용자 이야기 4: F5 재조회 (080에서 전역으로 확장)
현재는 수정키 없는 F5로 어느 패널에서든 로컬 저장소·기록·참조·변경 파일·뷰어를 새로 읽는다. 파일이 없거나 선택이 없어도 유효한 프로젝트에서 동작한다. 상세 수용 기준은 080 FR-010~011을 따른다.
- FR-008: F5의 파일 패널 한정 기준은 080 FR-010의 전역 로컬 새로고침으로 대체한다. 기존 비동기 조회·오래된 결과 거부·오류 표시는 유지한다.
- FR-009: 시작 화면·닫힌 저장소·경로 없음·Git 작업 중·모달 상태에서는 실행하지 않는다. 다른 패널·커밋 파일 탭도 080에 따라 허용하며 Fetch·Git 쓰기는 하지 않는다. 가능한 기존 선택을 유지한다.
- SC-003: 외부에서 추가한 변경이 재조회 결과에 반영되고 커밋·참조 조회 세대는 유지된다. 금지 상태와 수정키 조합 테스트를 통과한다.
명확화 정리: 최초 요청은 작업 트리 한정이었으나 080에서 전역 F5로 확장되었다. Stage 완료 자동 갱신의 파일·diff 한정 정책은 변경하지 않는다.
