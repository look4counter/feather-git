# 상태 조회 계약

Git 기본 설정의 줄바꿈 값 core.autocrlf·core.eol·core.safecrlf를 gix에 해당 값이 없을 때만 메모리에 보완한다. 기존 저장소·사용자 설정 우선순위와 외부 드라이버 실행 차단은 유지한다. 실제 변경·TreeIndex·충돌은 기존대로 표시한다. 작업 파일·인덱스·설정 파일에는 쓰지 않는다. summary 필터는 이번에 변경하지 않는다.

정규화가 활성화된 일반 파일의 크기 차이만으로 보고된 내용 변경은 clean 결과가 인덱스와 같을 때 제외한다. 실행 권한·타입·충돌 등 실제 상태 변경은 보존한다.
