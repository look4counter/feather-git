# 조사 결과

- 결정: 원본 FileChange 정렬에서 세 우선순위를 적용한다. 표시 목록만 바꾸는 대안은 행과 diff 원본의 연결을 깨므로 제외한다.
- 결정: 경로 컴포넌트 단위로 파일 우선 재귀 순서를 비교한다. 전체 부모 경로 문자열만 비교하면 backend/src의 파일이 backend/z.rs보다 앞에 오는 등 평면 트리 요구와 달라진다.
- 결정: 기존 대소문자 구분과 바이트 비교를 유지하고 상태·폴더 우선순위만 변경한다.

2026-11-16 결정: 기존 상태 순위에서 U만 최우선으로 옮긴다. 그룹이나 표시 모델에서 다시 정렬하는 대안은 중복 구현 및 행 연결 위험이 있어 제외했다. 미해결 기술 질문 없음.
