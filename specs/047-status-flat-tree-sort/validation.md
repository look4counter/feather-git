## 구현 및 재현

src/diff_git.rs의 status 정렬을 worktree_file_order로 변경했다. 비교는 Staged 우선 → M·D·A·U·기타 → 평면 트리 경로 순이다. flat_tree_path_order는 Git 경로 컴포넌트별로 파일 우선·이름 바이트순을 재귀 적용한다. 별도 폴더 행이나 경로 변환은 추가하지 않았다.

실제 임시 저장소 회귀는 구현 전 a-added.txt의 Staged 추가가 M보다 먼저 나오고 backend/src 파일이 루트 파일보다 먼저 나오는 실패를 확인했다. 수정 후 두 그룹의 M·D·A 순서와 index.html → backend/z.rs → backend/src/a.rs의 평면 트리 순서를 확인했다. 같은 파일의 두 상태, 표시 행과 diff 원본의 대응, 커밋 기록의 기존 경로순도 검증했다.

순수 경로 테스트는 루트·부모 폴더 파일·깊은 폴더·접두어·동일 경로·대소문자·한글·비 UTF-8 바이트를 검증한다. 충돌 U와 기타 상태의 순위도 확인했다.
