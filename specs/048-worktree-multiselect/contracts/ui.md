# UI 계약

작업 트리에서 일반 클릭은 단일 선택, Shift는 기준부터 범위 대체, Ctrl은 해당 행 토글, Ctrl+Shift는 범위 추가다. 여러 diff는 목록 순서의 파일별 영역으로 표시하고 파일 영역 경계를 유지한다. 다중 선택의 상단 헤더는 선택한 파일 N개만 표시하고 파일별 경로와 Stage 상태 헤더는 숨긴다. 단일 선택 경로 헤더는 유지한다. Space는 선택 파일 전체를 처리하며 중복 경로는 Stage 우선이다. 실패 파일과 성공 건수를 알리고 재조회 후 식별자로 선택을 복원한다. 커밋 기록 다중 선택이나 파일 간 텍스트 범위 선택은 추가하지 않는다.

다중 선택 개수 헤더의 높이·여백·세로 정렬·제목 굵기·하단 구분선은 단일 파일명 헤더와 동일하다.
