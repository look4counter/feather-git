# 검증 안내

1. cargo fmt --check, cargo test --offline, cargo clippy --offline --all-targets, cargo build --offline를 실행한다.
2. 작업 트리에서 일반·Shift·Ctrl·Ctrl+Shift 클릭 및 역방향 선택과 마지막 행 해제를 확인한다.
3. 선택한 모든 파일이 목록 순서대로 보이며 상단에 개수만 표시되고 파일별 경로·Stage 상태 헤더가 없으며 단일 선택 복귀 시 경로 헤더가 보이고 각 파일의 로딩·오류·본문 선택·부분 Stage가 분리되는지 확인한다.
4. 여러 파일에서 Space를 누르고 Stage/Unstage·중복 경로 Stage 우선·부분 실패 안내·재정렬 후 선택 복원을 확인한다.
5. 단일 선택 복귀·빈 선택·저장소 전환·커밋 기록 단일 선택·하단 포커스 안내·쓰기 완료 갱신을 확인한다.

6. 다중 선택 개수 헤더와 단일 파일명 헤더의 높이·여백·세로 중앙 정렬·글자 굵기·하단 구분선이 같은지 확인한다.
