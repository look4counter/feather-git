- 질문: 여러 파일 선택 후 Space 동작은? 답변: 선택한 모든 파일 토글.

## 사용자 시나리오 및 검증

### 사용자 이야기 1 — 행 다중 선택 (우선순위 P1)
작업 트리에서 일반 클릭은 한 행만 선택하고 Shift 클릭은 기준 행부터 연속 범위, Ctrl 클릭은 개별 행 추가·해제를 수행한다.
수용 기준: 모든 선택 행을 강조한다. 역방향 범위도 지원하며 Ctrl+Shift는 기존 선택에 범위를 추가한다. Ctrl로 마지막 행까지 해제하면 빈 선택이다. 커밋 기록 파일·참조·커밋 목록의 기존 단일 선택은 유지한다.
독립 검증: 클릭·수정키·범위·해제·잘못된 이벤트·새로고침의 선택 집합을 확인한다.

### 사용자 이야기 2 — 여러 파일 diff (우선순위 P1)
선택한 파일 모두를 목록 순서대로 DiffViewer에 세로로 표시한다. 다중 선택 패널 헤더는 선택한 파일 개수만 표시하며 파일별 경로 헤더와 Stage 상태 문구는 표시하지 않는다.
수용 기준: 단일 선택은 기존 화면을 유지한다. 다중 선택은 파일별 diff·로딩·오류·본문 선택·공백 장식·스크롤·부분 Stage를 유지한다. 한 파일의 오류나 선택을 다른 파일에 잘못 적용하지 않는다. 선택 변경 후 오래된 조회는 반영하지 않고 진행 중 쓰기는 완료 알림을 보존한다.
독립 검증: 다중 대상의 파일·상태 대응과 단일 복귀·빈 선택·조회 실패의 분리를 확인한다.

### 사용자 이야기 3 — 선택 파일 전체 Stage 토글 (우선순위 P1)
다중 선택에서 Space는 선택한 모든 파일에 적용한다. 같은 경로의 두 상태가 선택되면 전체 Stage를 한 번 실행한다.
수용 기준: 작업 파일·다른 파일을 보존한다. 비동기로 처리하고 중복 입력을 막는다. 일부 실패는 성공 건수와 실패 파일을 안내하고 실제 상태를 갱신한다. 재조회 후 경로·Stage 상태로 가능한 선택을 복원한다. 커밋·참조·그래프는 재조회하지 않는다.
독립 검증: 서로 다른 상태·같은 경로 중복·일부 실패·재정렬·선택 복원을 실제 저장소로 확인한다.

## 요구사항

- FR-001: 작업 트리 파일에서 단일·Shift 범위·Ctrl 토글·Ctrl+Shift 추가 범위를 지원한다.
- FR-002: 선택 집합 전체를 강조하고 기준 행과 현재 행을 관리하며 잘못된 입력·조회 중·모달·쓰기 중 선택을 차단한다.
- FR-003: 선택 파일은 현재 목록 순서로 파일별 diff를 표시하고 영역 경계를 유지한다. 다중 선택 헤더는 선택한 파일 N개만 표시하며 파일 경로·Staged·미스테이지 헤더를 숨긴다. 단일 선택의 기존 경로 헤더는 유지한다.
- FR-004: 기존 파일 뷰어를 재사용해 파일별 선택·구간 선택·부분 Stage·충돌·스크롤·로딩·오류를 분리하고 쓰기 완료 알림을 보존한다.
- FR-005: Space는 선택 파일 전체를 토글하고 동일 경로는 미스테이지를 우선해 한 번만 Stage한다.
- FR-006: 부분 실패를 명시하고 파일 경로·Stage 상태를 기준으로 선택을 복원하며 커밋·참조·그래프 갱신은 추가하지 않는다.
- FR-007: 커밋 기록 파일 목록과 다른 목록의 단일 선택, 기존 정렬·포커스·하단 안내·단축키 정책은 유지한다.

## 성공 기준

- SC-001: 선택 조합과 경계의 자동 테스트가 모두 통과한다.
- SC-002: 다중 대상·Stage 배치·중복 경로·실패·선택 복원과 기존 회귀 테스트가 통과한다.

## 가정 및 범위

기본 기준 행은 마지막 일반 또는 Ctrl 클릭 행이며 Shift 반복은 같은 기준을 유지한다. 여러 파일은 독립된 기존 diff 영역을 세로로 쌓고 전체 목록과 파일 본문의 스크롤을 제공한다. 파일을 가로지르는 텍스트 선택·다중 파일의 원자적 일괄 쓰기·커밋 기록 다중 선택은 범위 밖이다. 배치는 파일별 원자성을 유지하고 실패한 작업을 숨기지 않는다.

## 후속 요구사항: 헤더 디자인 통일

- FR-008: 다중 선택의 선택한 파일 N개 헤더는 단일 파일명 헤더와 같은 높이·좌우 여백·세로 중앙 정렬·글자 굵기를 사용하고 바로 아래에 같은 구분선을 표시한다.
- 수용 기준: 두 헤더의 높이·여백·굵기·구분선이 동일하며 다중 선택에서는 개수만 표시하고 파일별 경로/상태 헤더는 계속 숨긴다.
- 명확화: 비교할 기존 파일명 헤더가 있으므로 추가 질문 없이 그 스타일을 기준으로 한다.
