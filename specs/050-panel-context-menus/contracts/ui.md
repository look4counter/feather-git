# UI 계약

작업 트리 우클릭: 선택한 파일 스테이지 / Space. DiffViewer 우클릭: 선택한 줄 체크 / Space. 현재 선택은 유지한다. 작업 트리의 실행 불가는 비활성이다. DiffViewer 체크 항목은 현재 줄/범위에 체크 가능한 변경 줄이 있고 실행 가능할 때만 표시하며, 항목이 없으면 빈 메뉴도 표시하지 않는다. 외부 클릭·Escape는 실행 없이 닫고 포커스를 복원한다. 메뉴 선택은 기존 Space 동작과 같은 처리 경로를 사용한다. 하단 두 안내는 없고 구간 버튼은 구간 체크다. 빈 파일 선택 헤더는 선택된 파일 0개다.

DiffViewer의 체크된 줄 Stage 실행 버튼은 체크한 줄 스테이지로 표시하고 기존 사용자 지정 단축키의 괄호 표시는 유지한다.
