# 검증 안내

1. 빈 파일 선택 헤더와 단일/다중 선택 헤더를 확인한다.
2. 작업 트리 다중 선택 후 우클릭 메뉴와 Space 배지·비활성 상태·Stage 결과를 확인한다.
3. DiffViewer 본문 범위를 선택하고 우클릭 체크 및 구간 체크를 확인한다.
4. 외부 클릭·Escape·화면 가장자리·창 비활성화·모달·조회 중 대상 변경을 확인한다.
5. 여러 파일에서 메뉴 동작이 해당 파일에만 적용되고 기존 Space가 유지되는지 확인한다.
6. 하단 안내가 제거되고 다른 상태 표시는 유지되는지 확인한다.

7. DiffViewer의 문맥 줄만 선택한 경우·빈 선택 화면·읽기 전용·로딩/쓰기 중에는 체크 메뉴가 없고, 추가/삭제 줄을 포함한 현재 줄/범위에서만 메뉴가 열리는지 확인한다. 다중 파일 부모 메뉴도 다시 열리지 않아야 한다.
