# 기능 명세: 패널 공통 컨텍스트 메뉴

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.

상태: 명확화 완료

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 빈 선택 헤더 (우선순위 P1)
작업 트리에서 파일 선택이 없으면 DiffViewer 헤더는 선택된 파일 0개를 표시한다. 파일 선택/커밋상세의 기존 헤더는 유지한다.

### 사용자 이야기 2: 작업 트리 메뉴 (우선순위 P1)
작업 트리 패널에서 우클릭하면 선택한 파일 스테이지 메뉴와 Space 배지를 표시한다. 클릭하면 기존 Space와 같은 다중 파일 Stage 토글을 수행한다.
수용 기준: 현재 다중 선택을 보존한다. 빈 선택·조회/쓰기 중·모달에서는 실행할 수 없다. 동일 경로 Stage 우선·부분 실패·파일만 갱신하는 기존 정책을 유지한다.

### 사용자 이야기 3: DiffViewer 메뉴 (우선순위 P1)
DiffViewer에서 우클릭하면 현재 줄/선택 범위에 체크 가능한 변경 줄이 있을 때만 선택한 줄 체크 메뉴와 Space 배지를 표시한다. 클릭하면 기존 현재 줄/선택 범위 체크 토글을 수행한다. 구간 선택 버튼은 구간 체크로 표시한다.
수용 기준: 우클릭은 현재 본문 선택을 보존한다. 체크 가능한 변경 줄이 없는 범위·읽기 전용·로딩/쓰기 중에는 체크 메뉴를 표시하지 않는다. 여러 파일 중 우클릭한 파일의 범위에만 적용한다. 메뉴가 열린 후 대상이 바뀌면 오래된 동작을 실행하지 않는다.

## 명확화 및 범위

우클릭은 현재 선택 파일/텍스트 범위를 보존하며 클릭한 위치로 선택을 바꾸지 않는다. 작업 트리 메뉴 항목은 실행 불가 상태에서도 비활성으로 표시한다. DiffViewer는 체크를 실행할 수 있을 때만 항목을 표시하며, 현재 유일한 항목이 없으면 빈 메뉴도 열지 않는다. 외부 클릭·Escape는 메뉴를 닫고 실행 없이 포커스를 복원한다. 메뉴는 한 번에 하나만 표시하며 화면 가장자리에서 창 안으로 배치한다. 단축키 Space의 기존 직접 실행은 유지한다. 다른 메뉴 항목은 추가하지 않는다. 추가 질문이 필요한 모호성은 없다.

## 요구사항

- FR-001: 파일 선택 없는 DiffViewer 헤더는 선택된 파일 0개다.
- FR-002: 공통 컨텍스트 메뉴는 항목·단축키 배지·비활성·위치 보정·외부 클릭/Escape 닫기·포커스 복원을 지원한다.
- FR-003: 작업 트리 우클릭 메뉴는 선택한 파일 스테이지과 Space를 표시하고 기존 배치 토글을 재사용한다.
- FR-004: DiffViewer 우클릭 메뉴는 현재 줄/선택 범위에 체크 가능한 변경 줄이 있고 실행 가능할 때만 선택한 줄 체크와 Space를 표시하고 기존 줄/범위 체크를 재사용한다. 해당 항목이 없으면 빈 메뉴도 열지 않는다.
- FR-005: 두 패널의 기존 하단 단축키 안내를 제거하고 구간 선택 버튼을 구간 체크로 변경한다.
- FR-006: 현재 선택·쓰기 보호·다중 파일 분리·오래된 대상 방어와 기존 Space 동작을 유지한다.

## 성공 기준

- SC-001: 빈 헤더·메뉴 실행 가능 조건·대상 변경 방어·기존 Stage/체크 테스트가 통과한다.
- SC-002: 서식·정적 분석 및 전체 회귀 테스트를 통과한다. 실제 화면 미검증 범위는 별도 명시한다.

## 경계

빈 파일/변경 없는 범위·커밋상세·커밋 기록 diff·여러 파일의 자식 뷰어·조회 결과 도착·실패·중복 실행·창 비활성화를 고려한다. Stage는 메뉴를 열 때가 아니라 실행할 때만 수행한다.

## 후속 요구사항: 체크한 줄 스테이지

- FR-007: DiffViewer의 선택한 줄 Stage 버튼명을 체크한 줄 스테이지로 변경한다. 기존 사용자 지정 단축키가 있으면 괄호 표시는 유지한다.
- 수용 기준: 기본 버튼명은 체크한 줄 스테이지이며 기존 Stage 처리와 활성 조건은 유지한다.
- 명확화: 이름 변경만 요청했으므로 동작과 단축키 정책은 유지하며 추가 질문은 필요 없다.

## 후속 명확화: 체크 항목 표시 조건

체크할 항목은 기존 체크 가능 조건을 만족하는 현재 줄/선택 범위의 추가·삭제 줄을 뜻한다. 우클릭 위치로 선택을 바꾸지 않는다. 현재 메뉴 항목은 하나이므로 체크 불가이면 메뉴 전체를 열지 않는다. 작업 트리 메뉴 정책은 유지한다. 추가 질문이 필요한 모호성은 없다.

## 후속 명확화: 파일 메뉴 이름

FR-003의 표시 이름을 선택한 파일 스테이지로 변경한다. 사용자 요청은 이름 변경이므로 기존 Stage 토글 동작과 Space 배지는 유지한다. 추가 질문이 필요한 모호성은 없다. 수용 기준은 새 이름 표시와 기존 실행 동작 보존이다.
