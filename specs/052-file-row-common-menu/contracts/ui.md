# UI 계약

실제 파일 행 우클릭에서만 공통 메뉴 열기·탐색기에서 보기·경로복사 / Ctrl + Shift + C를 표시한다. 커밋상세와 빈 공간은 제외한다. 열기/위치는 클릭한 파일 하나, 복사는 현재 선택 전체다. 이미 선택된 행 우클릭은 선택을 유지하고 미선택 행이면 해당 행만 선택한다. 작업 트리 전용 스테이지/폐기는 커밋 기록에는 표시하지 않는다.

탐색기에서 보기는 클릭 파일의 기존 부모 폴더를 열며 Windows 확장 접두사는 Shell 호출 시 정리한다. 메뉴 이름과 단축키 영역은 겹치지 않고 긴 이름만 말줄임하며 단축키는 그대로 표시한다.

경로복사와 뒤따르는 작업 트리 전용 항목 사이에 구분선을 표시한다. 구분선은 메뉴 동작/탐색 대상이 아니고 마지막 항목 뒤에는 표시하지 않는다.

헤더는 전체 파일 행 개수만 기존 숫자 배지로 표시하고 커밋상세는 제외한다.

최신 원복 지시에 따라 헤더는 전체 파일 행 개수만 기존 숫자 배지로 표시하고 Staged/M/D/A 추가 배지는 제거한다. 우클릭 선택 정책은 유지한다.

상태 글자색은 S· 접두사와 무관하다. A/S·A는 기존 녹색, D/S·D는 붉은색이며 그 외 상태 색상은 유지한다.
