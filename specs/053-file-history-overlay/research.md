# 조사 결과

- 기존 메인 snapshot은 200개/전체 상태 조회를 포함하므로 파일 전용 조회에는 재사용하지 않는다. Commit 표현과 기존 그리드/DiffViewer를 재사용한다.
- 모든 브랜치의 이름 변경 전후 경로를 연결하려면 단일 브랜치의 역방향 경로 추적 대신 rename 연결을 먼저 수집해야 한다. Git 유사도 기반 경로 연결의 한계는 명세에 명시한다.
- 독립 팝업 엔티티로 메인 Workspace의 commit/file_selection을 변경하지 않는다.

- 최신 결정: 이름 변경 추적을 제거한다. 각 커밋의 요청 경로 tree 항목만 조회하여 전체 트리 diff와 유사도 분석을 생략한다. 이전 rename 설계는 대체됐다.
