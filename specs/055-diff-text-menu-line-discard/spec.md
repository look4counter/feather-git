## 사용자 시나리오 및 검증

### 사용자 이야기 1: 텍스트 우클릭 메뉴 (우선순위 P1)
DiffViewer의 본문 실제 텍스트를 우클릭할 때만 메뉴를 연다. 헤더·도구 모음·라인 번호·기호/gutter·스크롤바·본문 행이 없는 빈 공간·일반 문자열 뒤 여백에서는 열지 않는다. 최신 지시에 따라 빈/공백만 있는 본문 행의 편집 영역에서는 메뉴를 연다. 현재 텍스트 선택을 유지한다. 복사 / Ctrl + C를 공통 항목으로 제공하고 현재 선택 텍스트를 원문 그대로 복사한다. 빈 선택에서는 복사를 비활성으로 표시한다. 커밋상세·과거 diff·여러 파일의 각 뷰어에서도 동일하게 적용한다. 기존 선택한 줄 체크는 실행 가능할 때만 추가한다.

### 사용자 이야기 2: 체크한 줄 폐기 (우선순위 P1)
체크한 줄 스테이지 옆에 체크한 줄 폐기 버튼을 추가한다. 부분 체크가 가능한 미스테이지 텍스트에서 체크한 변경 줄만 인덱스 상태로 되돌린다. 나머지 작업 변경과 스테이지/다른 파일은 보존한다. 추가 줄은 제거하고 삭제 줄은 복원한다. 체크 없는/읽기 전용/충돌/작업 중 상태는 실행 불가다.

### 사용자 이야기 3: 확인과 보호 (우선순위 P1)
폐기 전에 파일명·체크 줄 수·스테이지와 나머지 변경 보존·복구 불가를 안내하는 확인 팝업을 연다. 취소/Escape/Enter는 폐기하지 않고 폐기 버튼만 실행한다. 실행 시 조회 세대·원본 인덱스/작업 파일·경로·필터를 재검증한다. 성공은 기존 파일/뷰어 갱신을 사용하고 실패를 명시한다. 여러 파일 중 요청한 뷰어 하나에만 적용한다.

## 명확화 및 범위

텍스트는 그려진 원문 폭의 본문 영역이며 공백/탭도 원문 폭 안이면 포함한다. 우클릭 위치로 선택을 바꾸지 않는다. 부분 폐기는 HEAD가 아닌 현재 인덱스 기준이므로 스테이지된 내용은 보존한다. 신규 파일의 모든 추가 줄을 폐기해 내용이 없으면 파일을 제거하고 삭제 파일의 체크 줄은 복원한다. 변환 필터/비텍스트/링크/서브모듈은 기존 부분 Stage와 동일하게 거부한다. 추가 질문이 필요한 모호성은 없다.

## 요구사항

- FR-001: 패널 전체 우클릭을 제거하고 보이는 본문 텍스트 hit 영역에서만 메뉴를 연다.
- FR-002: 복사 / Ctrl + C 공통 메뉴와 기존 키 동작이 같은 원문 복사 처리를 사용하며 선택/오래된 대상 보호를 유지한다.
- FR-003: 기존 조건부 체크 메뉴를 유지한다.
- FR-004: 체크한 줄 스테이지 옆에 체크한 줄 폐기를 추가하고 체크한 변경만 되돌린다. 인덱스·나머지 변경·다른 파일을 보존한다.
- FR-005: 명시적 확인 팝업·취소/키 보호·다중 파일 요청 전달·원본/세대/잠금/경로/필터 검증과 안전한 파일 쓰기를 제공한다.
- FR-006: 기존 부분 Stage·텍스트 선택/복사·파일만 갱신하는 흐름을 유지한다.

## 성공 기준

- SC-001: 텍스트 hit 경계·조건부 메뉴·원문 복사와 임시 저장소의 부분 폐기/보존·추가/삭제·줄바꿈·미리보기 제한 밖 변경 보존·오래된 원본/인덱스/잠금/경로 거부를 검증한다.
- SC-002: 확인/취소·다중 파일 전달 경로를 검토하고 전체 테스트·서식·Clippy를 통과한다. GUI/클립보드 통합 한계는 기록한다.
