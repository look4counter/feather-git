# 기능 명세: 줄바꿈 비교 정규화와 빈 줄 메뉴

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.

작성일: 2026-11-15
상태: 명확화 완료

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 줄바꿈 차이 제외 (우선순위 P1)
DiffViewer는 LF/CRLF 형식 차이만으로 동일 내용의 줄을 삭제/추가로 표시하지 않는다. 실제 문자 변경만 표시하고 줄 번호·공백/탭·마지막 개행 유무와 EOF 표시를 유지한다. 줄바꿈만 다른 경우 기존 내용 동일/줄바꿈 안내를 표시한다.

### 사용자 이야기 2: 안전한 부분 Stage/폐기 (우선순위 P1)
정규화된 비교의 변경 줄 체크를 부분 Stage/폐기에도 동일하게 적용한다. 비교는 정규화하되 원본 바이트 검증은 유지한다. 부분 Stage는 인덱스의 미변경 줄을, 부분 폐기는 작업 파일의 미변경 줄을 원문 그대로 보존한다. 다른 쪽에서 가져온 줄의 개행은 쓰기 대상의 주된 형식을 사용하며 대상이 비어 있으면 상대 원문의 형식을 따른다. 마지막 개행 없는 줄은 그대로 유지한다. 인덱스와 작업 파일을 일괄 정규화하지 않는다.

### 사용자 이야기 3: 빈 줄 우클릭 (우선순위 P1)
DiffViewer 본문의 빈 줄과 공백/탭만 있는 줄에서도 우클릭 메뉴를 연다. 해당 줄의 편집 영역에서 동작하고 헤더·gutter·스크롤바·본문 밖은 제외한다. 일반 텍스트 줄의 끝 여백 제한과 기존 선택 유지·복사 비활성/조건부 체크 정책은 유지한다.

## 명확화

LF와 CRLF만 비교 시 동등하게 처리한다. 공백/탭·독립 CR·마지막 개행 유무는 지우지 않는다. 신규 파일/삭제 파일과 과거 diff에도 같은 비교를 사용한다. 빈 줄은 본문 행의 원문이 없거나 공백으로만 된 경우이며 목록 아래의 행 없는 빈 공간은 제외한다. 추가 질문이 필요한 모호성은 없다.

## 요구사항

- FR-001: CRLF/LF를 비교에서만 정규화하고 실제 변경 줄과 기존 번호/EOF를 보존한다.
- FR-002: DiffViewer와 부분 Stage/폐기는 같은 정규화 비교를 사용한다.
- FR-003: 쓰기 대상의 미변경 원문/개행·나머지 변경·인덱스·다른 파일과 오래된 원본/필터/잠금 보호를 유지한다.
- FR-004: 빈/공백만 있는 본문 행의 편집 영역에서 메뉴를 열되 기존 비본문 제외·선택/복사/체크 보호는 유지한다.

## 성공 기준

- SC-001: LF/CRLF 한 줄 수정·줄바꿈만 변경·혼합 개행·EOF와 교차 개행의 부분 Stage/폐기 보존을 임시 저장소로 검증한다.
- SC-002: 빈 행 hit/비본문 경계·기존 전체 회귀·서식·Clippy를 통과하고 GUI/실행 파일 제한을 명시한다.
