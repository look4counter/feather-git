# 검증 안내

1. 파일 이력의 서로 다른 커밋 행을 우클릭해 메뉴와 선택/diff를 확인한다.
2. 열기가 해당 blob 내용이고 현재 파일은 바뀌지 않는지 확인한다.
3. 탐색기/복사가 임시 파일이 아닌 저장소 경로를 사용하는지 확인한다.
4. 삭제 커밋 비활성·조회/닫기/오래된 요청·오류를 확인한다.

## 정리 검증
파일 이력에서 과거 내용을 열고 팝업을 닫아 추출 파일이 삭제되는지 확인한다. Windows에서 파일 삭제를 막는 핸들을 유지한 상태로 닫고 핸들 해제 후 종료 재시도를 검증한다. 실제 GUI와 OS 앱은 자동 테스트만으로 검증되지 않는다.
