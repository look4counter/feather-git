# 기능 명세: 파일 이력 행 컨텍스트 메뉴

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.

작성일: 2026-11-15
상태: 명확화 완료

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 행 메뉴 (우선순위 P1)
파일 변경 이력 팝업 왼쪽 그리드의 실제 커밋 행 우클릭에 열기·탐색기에서 열기·경로 복사 메뉴를 표시한다. 우클릭 행을 선택하여 오른쪽 diff와 대상을 일치시킨다. 헤더/빈 공간/로딩/닫힌 상태에서는 메뉴를 열지 않는다.

### 사용자 이야기 2: 과거 내용 열기 (우선순위 P1)
열기는 우클릭한 커밋의 해당 파일 blob 원문을 별도의 임시 파일로 추출해 OS 기본 앱으로 연다. 확장자를 유지하고 현재 작업 파일/인덱스/커밋을 변경하지 않는다. 임시 파일은 읽기 전용이며 같은 이름의 기존 임시 파일을 덮어쓰지 않는다. 삭제 커밋처럼 그 시점 파일이 없거나 일반 파일이 아닌 경우 열기는 비활성이다.

### 사용자 이야기 3: 저장소 경로 동작 (우선순위 P1)
탐색기에서 열기와 경로 복사는 사용자 답변에 따라 저장소의 해당 파일 경로를 사용한다. 파일이 없으면 탐색기는 가장 가까운 기존 상위 폴더를 열며, 복사는 존재 여부와 무관하게 절대경로를 저장한다. 임시 추출 경로를 복사하지 않는다.

## 명확화 및 요구사항

사용자 답변: 탐색기/복사는 저장소의 해당 파일 경로. 삭제 커밋의 열기를 이전 커밋 내용으로 대체하지 않는다. 추출은 blob의 실제 바이트를 사용하며 현재 줄바꿈/편집 내용을 섞지 않는다. 추가 질문이 필요한 모호성은 없다.

- FR-001: 실제 이력 행 메뉴와 우클릭 선택·현재 요청 세대/행 검증을 제공한다.
- FR-002: 정확한 커밋/경로의 일반 파일 blob을 고유한 읽기 전용 임시 파일로 추출하고 OS 기본 앱으로 연다.
- FR-003: 탐색기/경로 복사는 저장소 절대경로와 기존 상위 폴더 준비를 재사용한다.
- FR-004: 비동기 준비·오류 표시·닫힌/오래된 요청 거부·취소·원본 보존을 유지한다. 팝업의 메뉴가 메인 모달 차단으로 즉시 닫히지 않게 한다.

## 성공 기준

- SC-001: 서로 다른 커밋의 실제 바이트·확장자·고유/읽기 전용 추출·원본 보존·삭제/잘못된 경로 거부와 행/닫기/세대·저장소 복사 대상을 검증한다.
- SC-002: 전체 회귀·서식·Clippy·빌드를 통과하고 실제 OS/GUI/클립보드 한계를 기록한다.

## 추가 요구사항: 임시파일 수명

명확화: 사용자는 팝업을 닫을 때 삭제하고 실패하면 앱 종료 시 재시도하도록 지정했다. 추가 질문은 없다. 강제 종료와 종료 시에도 사용 중인 파일의 삭제 보장은 범위 밖이다.

- FR-005: 파일 변경 이력 팝업을 닫으면 해당 팝업에서 추출한 모든 임시파일과 파일별 디렉터리를 삭제한다. 읽기 전용 속성으로 정리가 방해되지 않아야 한다.
- FR-006: 삭제 실패 항목은 앱의 정상 종료 시 재시도한다. 팝업이 열린 상태로 앱이 종료되어도 생성된 파일을 정리한다. 종료 시에도 실패하면 오류를 기록한다.
- FR-007: 팝업을 닫는 중 진행 중인 추출이 완료되어도 파일이 누락되지 않도록 정리하며, 저장소 파일 및 다른 팝업의 파일을 삭제하지 않는다.
- SC-003: 닫기·중복 닫기·닫기 이후 추출 완료·삭제 실패 후 종료 재시도·읽기 전용 파일·팝업 간 격리를 자동 검증한다.

수용 시나리오: 추출 파일은 팝업이 열린 동안 존재하고 닫으면 없어지며, Windows에서 외부 핸들로 잠긴 파일은 닫기 시 남고 핸들을 해제한 후 종료 재시도 시 삭제된다.
