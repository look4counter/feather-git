# UI 및 읽기 계약

하단 인코딩 라벨은 현재 선택을 표시한다. 클릭하면 11개 항목과 현재 선택 표시가 있는 메뉴를 열고 클릭/위아래/Enter로 선택한다. Escape와 외부 클릭은 취소한다. 파일이 없는 화면에서도 선택할 수 있다.

선택은 모든 파일 Diff의 메모리 해석에만 적용한다. 비 UTF-8 읽기는 부분 쓰기를 제공하지 않으며 전체 파일 작업 안내를 표시한다. 인코딩 오류와 바이너리는 텍스트 비교를 중단하고 안내한다. UTF-16의 정상 NUL 바이트는 허용하되 해석 후 NUL 문자는 바이너리다.

우측 제품명 라벨은 없고 좌측 기본 안내는 프로젝트명 없이 저장소 경로 또는 경로 없음 안내를 표시한다.

커밋 기록은 최초 1,500개, 하단 50행 근접 시 200개씩 이어 붙인다. 기존 행·선택·스크롤을 유지하고 끝에서는 멈춘다. 실패 시 그리드 아래 오류/재시도를 표시한다. 같은 실행 중 탐색 스냅샷을 계속 사용한다.
