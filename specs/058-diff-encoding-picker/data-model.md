# 데이터 모델

- 보기 인코딩: 11개 고정 항목과 표시 이름, 기본 UTF-8. GPUI 글로벌 상태로 실행 동안 공유한다.
- 조회 인코딩: 각 DiffViewer가 마지막 요청에 사용한 값. 대상과 함께 캐시 조건을 구성한다.
- 상태 전이: 라벨 클릭 → 목록 표시 → 선택 또는 취소 → 선택 변경 시 기존 조회 무효화/선택 범위 초기화 → 새 Diff 표시.
- 원본 바이트: 읽기 경로와 기존 전체 파일 작업에서 유지하며 디코딩 문자열로 덮어쓰지 않는다.

## 커밋 페이지 모델

프로젝트는 선택적 공유 탐색 커서를 가진다. 커서는 채널 세션 정체성으로 스냅샷을 구분한다. 페이지는 요청 오프셋·최대 200개 커밋·이후 존재 여부를 가진다. 초기 페이지는 최대 1,500개이며 이전 참조 선택 호환성 때문에 대상까지 확장될 수 있다. 그래프 상태는 현재까지 소비한 빌더와 행 배열을 유지한다. 오류는 행을 지우지 않으며 명시적 재시도까지 유지된다.
