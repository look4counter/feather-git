# 검증 안내

1. cargo test --offline로 디코더와 임시 저장소 회귀 검증을 실행한다.
2. 앱의 우측 하단 라벨을 눌러 목록 11개와 현재 선택을 확인한다. Escape/외부 클릭 및 키보드 선택을 확인한다.
3. 한국어 windows-949 파일과 UTF-16LE/BE 파일에서 선택 전후 Diff를 확인한다. 선택만으로 파일·인덱스 바이트가 변하지 않아야 한다.
4. 여러 파일·커밋 파일 비교에서 변경을 확인하고 인코딩을 연속 선택하여 오래된 결과가 표시되지 않는지 확인한다.
5. 비 UTF-8에서는 부분 쓰기/충돌 편집이 없고 UTF-8 복귀 시 기존 기능이 돌아오는지 확인한다.
6. 하단 우측 제품명과 좌측 기본 프로젝트명 접두사가 없으며 경로·오류 안내는 유지되는지 확인한다.

GUI를 직접 확인하지 못한 경우 자동화 검증과 구분하여 기록한다.

7. 1,905개 이상의 저장소를 열어 최초 1,500개와 하단 접근 시 200개 단위 추가, 마지막 나머지, 기존 스크롤/선택과 그래프 연결을 확인한다. 로딩 중 탭 전환/닫기와 오류 재시도도 확인한다.
