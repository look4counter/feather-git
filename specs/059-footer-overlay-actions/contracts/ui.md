# UI 계약

인코딩 버튼은 공용 Dialog 중앙 오버레이를 연다. 11개 항목과 현재값을 보여주며 클릭/위아래/Enter로 선택한다. Escape/취소는 값을 유지한다. 바깥 클릭은 공용 Dialog의 기본 입력 차단 정책을 따른다.

하단 좌측에는 경로/상태 안내가 있고 우측에는 Git Bash·PowerShell(Windows 전용)·탐색기·인코딩 버튼이 있다. 버튼은 브랜치 배지와 같은 8px/2px 패딩과 11px 글꼴을 쓴다. 민트 원형은 없다. 모든 동작 버튼은 동일한 배경·패딩·호버·비활성 스타일을 사용한다. 저장소가 없거나 모달/처리 중이면 폴더 버튼은 비활성이다.

터미널은 현재 저장소를 작업 폴더로 삼는다. 탐색기는 현재 저장소 폴더를 연다. 경로가 존재하지 않으면 알림을 띄운다. 비동기 완료는 다른 저장소에 적용하지 않는다.

커밋 배지는 태그 → 로컬 → 원격 → 기타 순서이며 로컬/태그 아이콘은 흰색이다. 저장소 목록은 4px 아이콘/이름 간격을 사용하고 현재 로컬 행의 아이콘·이름은 민트색이며 현재 배지는 이름 바로 뒤에 붙는다.

그래프 레인 선은 일반/현재 커밋 원의 가로 중심과 일치한다. 배율에 따른 보정은 선과 원이 공유하며 원 크기와 레인 간격은 유지한다.

그래프 분기/병합은 행 경계의 수직 4px 구간과 내부 곡선을 잇고 레인 간격은 18px다. 원은 기존 모양을 유지한다.

최신 셸 버튼은 Git Bash, Windows 전용 PowerShell, 탐색기 순서다. Git Bash 미설치 시 안내한다. 레인 간격은 18px이며 경계의 4px 수직 구간 사이를 곡선으로 잇는다. 커밋 그리드 헤더는 24px이고 하단 구분선이 있다.

바로 건너뛰기 후 추가 조회는 새 커밋 목록과 같은 세션의 커서를 사용한다. 이전 스냅샷의 늦은 결과는 새 목록에 적용하지 않는다. 끝까지 이동하면 커서를 해제하고 추가 조회를 중단한다.

우측 하단에는 셸·탐색기·인코딩 동작 버튼만 제공하고 현재 브랜치명 배지는 표시하지 않는다. 다른 패널의 참조와 현재 표시를 유지한다.
