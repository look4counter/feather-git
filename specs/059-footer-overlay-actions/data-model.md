# 데이터 모델

- 인코딩 선택 상태: 현재값과 0~10 범위의 키보드 커서. 선택은 인코딩 값, 취소는 값 없는 닫기 이벤트로 전달한다.
- 대화상자 생명주기: 닫힘 → 이전 포커스 저장/대화상자 포커스 → 선택 또는 취소 → 이전 포커스 복구.
- 폴더 작업: 프로젝트 ID·원본 경로·터미널/탐색기 종류·진행 여부. 경로 확인 결과는 표시용 경로와 실행 작업 디렉터리로 사용한다.
- 기존 글로벌 인코딩·저장소·파일 데이터 형식은 바꾸지 않는다.

표시용 참조 목록은 태그/로컬/원격/기타 순위를 갖고 같은 순위의 원래 순서를 유지한다. 저장소 행 스타일은 현재 여부에 따른 아이콘/텍스트 색이며 현재 판정 자체는 기존 로컬 브랜치 규칙을 따른다.

그래프의 노드 중심과 해당 레인 선의 중심은 같은 DPI 보정 좌표다. 원 지름/테두리는 기존 물리 픽셀 크기를 유지하고 경계는 반 픽셀 위치를 허용한다.

후속 표시 모델: 원본 레인 Segment의 시작/끝은 유지하고 렌더 시 시작·꺾임·끝의 3개 점으로 변환한다. 상단은 첫 선분, 하단은 마지막 선분이 수직이다. 버튼의 크기 기준은 별도 수치 모델이 아니라 기존 공용 배지 스타일이다.

DirectoryAction은 GitBash/PowerShell/Explorer로 구분한다. Git Bash 실행 경로는 유한 후보 중 존재하는 절대 경로 파일이다. 공용 그리드 헤더 높이는 데이터 행의 ROW_HEIGHT와 같다. 곡선 구간의 시작/끝 접선은 수직 경계 구간과 일치한다.

참조 이동 시 commits, more_commits, history_cursor는 하나의 조회 스냅샷이다. 세 필드는 같은 결과에서 갱신하며 끝에 도달한 스냅샷은 커서가 없다.
