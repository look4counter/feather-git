# 내부 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

- SettingsPanel은 저장소 경로 선택값으로 생성한다. 저장 중 can_close=false, cancel은 인증 helper 취소를 전달한다.
- 공용 Dialog가 주 창과 하위 창을 표시한다. 각 창의 확인·취소 버튼으로만 작업을 확정하거나 닫는다. 팝업 전용 단축키는 없다. 환경설정 확인은 저장 성공 이벤트에만 닫는다.
- 설정 접근은 오류를 Result로 반환한다. 쓰기는 잠금 파일을 사용하며 실패 시 기존 설정을 보존한다.
- 일반 TextInput의 기본 동작은 유지한다. 비밀번호 입력은 표시·복사·이벤트에서 원문을 노출하지 않는다.
