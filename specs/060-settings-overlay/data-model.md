# 데이터 및 상태

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

SettingsSnapshot은 전역/로컬/유효 작성자와 저장소의 원격 목록을 갖는다. SettingsPanel은 읽기/저장/오류/성공 알림과 원격 추가 창 상태를 소유한다. AuthPanel은 인증 프로필 목록과 로그인 방식·입력·취소 상태를 소유한다. 비밀 문자열은 Secret으로 이동하고 프로필에는 식별자만 기록한다. Workspace는 패널 엔티티와 이전 포커스를 소유하며 닫을 때 해제한다.
