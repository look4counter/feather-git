# 조사 결과

- 참조 창은 폭 760, 작성자/원격/인증 순서이며 원격 및 인증 추가 창을 중첩한다. 현재 공용 Dialog와 테마를 사용한다.
- 설정 접근에는 제한된 config/remote 어댑터만 필요하다. 값 없음 1, unset 없음 5, 실제 오류 128을 구별한다. 잠금·원복·다중 URL을 보존한다.
- 기존 TextInput을 확장한다. 비밀번호는 문자별 마스크와 원문/표시 바이트 좌표 변환이 필요하다. 복사와 평문 Changed 이벤트, IME 조회를 차단한다. 설정용 입력 높이는 외곽 36에 맞춘다.
- 인증 프로필 형식과 Windows 보관소 대상명을 유지한다. helper 탐지는 비대화형, 로그인은 사용자가 누른 경우에만 진행한다.
- 연구 작업 두 건은 읽기 전용으로 수행했다. 미해결 기술 쟁점 없음.
