## 사용자 시나리오 및 검증

### 사용자 이야기 1 — 설정 열기와 닫기 (우선순위 P1)
하단 환경설정 버튼으로 공용 팝업을 연다. 기존 설정창처럼 작성자, 원격 저장소, 인증을 한 창에서 본다.
수용 기준: 버튼을 누르면 배경 입력이 차단된 창이 열리고, 취소 또는 확인 저장 성공으로 닫으면 이전 포커스가 복원된다. 저장 중에는 닫기가 차단된다. 하위 창에서 취소는 하위 창만 닫는다.

### 사용자 이야기 2 — 작성자와 원격 관리 (우선순위 P1)
이름·이메일과 전역 설정 사용 여부를 저장하고 원격 주소를 조회·추가·삭제한다.
수용 기준: 재열기 시 저장값이 유지된다. 전역 사용은 저장소의 작성자 재정의만 제거한다. 원격 중복·잘못된 입력은 오류로 알리며 실패 시 기존 설정을 보존한다. 저장소가 없으면 저장소별 항목은 비활성화한다.

### 사용자 이야기 3 — 인증 관리 (우선순위 P2)
기존 창과 같은 브라우저 로그인 및 ID·비밀번호/토큰 등록과 삭제를 제공한다.
수용 기준: 비밀번호는 마스킹하고 복사·일반 입력 이벤트·설정 파일에 노출하지 않는다. 비밀값은 운영체제 보관소에 저장한다. 인증 도구가 없거나 인증 실패·취소 시 오류와 재시도를 제공한다. 등록한 인증은 저장소 접속에 사용한다.

### 경계 조건
설정 읽기/쓰기 실패, 잠금 충돌, 다중 원격 URL, 인증 도구 없음, 작은 창 스크롤, 한글/이모지 입력, 저장 중 연속 클릭, 하위 팝업 중첩을 처리한다.

## 요구사항

- FR-001: 우측 하단에 기존 하단 버튼과 같은 크기의 환경설정 버튼을 표시한다.
- FR-002: 공용 오버레이를 사용하며 기존 창과 유사한 폭·구획·입력·저장 버튼을 제공한다. 현재 앱 색상을 따른다.
- FR-003: 커밋 작성자, 원격 저장소, 인증을 기존 순서와 기능으로 구성한다.
- FR-004: 설정은 사용자의 저장/추가/삭제/로그인 동작에만 변경하며 실패를 표시한다.
- FR-005: 한글 조합, 마스킹, 읽기 전용 입력, 비활성 입력을 지원한다.
- FR-006: 기존 Git 읽기·비교, 인코딩, 기록 및 하단 기능을 유지한다.

## 주요 데이터
작성자: 전역/로컬 이름과 이메일. 원격: 이름과 가져오기/내보내기 주소. 인증 프로필: 주소·계정·방식·비밀 보관소 식별자. 창 상태: 읽기/저장/오류/하위 창/취소.

## 성공 기준
- SC-001: 버튼 한 번으로 세 영역이 모두 표시된다.
- SC-002: 격리된 저장소에서 작성자 저장 및 원격 추가/삭제가 재조회와 일치한다.
- SC-003: 비밀번호가 표시 문자열·클립보드·프로필 파일에 포함되지 않는다.
- SC-004: 관련 자동화 검사와 빌드가 통과한다.

## 가정과 명확화
기존 팝업을 기능까지 이식하며 밝은 팔레트 대신 현재 앱의 어두운 팔레트를 적용한다. 별도 일반/테마 설정을 추가하지 않는다. 기존 전역 작성자 값을 보여주되 저장소별 재정의를 편집한다. 기존 인증 메타데이터 형식과 운영체제 보관소 호환성을 유지한다. 인증 목록 조회 시 기존 창과 동일하게 운영체제의 기존 Git 인증 메타데이터를 앱 목록에 동기화할 수 있으며, 비밀값과 Git 설정은 변경하지 않는다. 추가 질문이 필요한 모호성 없음.


## 변경 요구사항: 확인 및 취소 (2026-11-15)

- FR-007: 인코딩 행 선택은 임시 선택만 변경한다. 하단 확인 버튼을 누른 경우에만 적용하고 닫는다. 취소는 기존 인코딩을 유지한다. Enter/Space는 즉시 적용하지 않는다.
- FR-008: 환경설정과 원격/인증 추가 창에서 단축키 표시와 팝업 작업 단축키를 제거한다. 입력의 기본 복사·붙여넣기와 한글 조합은 유지한다.
- FR-009: 세 창 모두 확인·취소 버튼을 제공한다. 환경설정 확인은 저장 성공 시 닫으며 오류 시 유지한다. 하위 창 확인은 기존 추가/로그인을 수행하고 성공 시 하위 창만 닫는다. 취소는 미저장 입력을 적용하지 않고 닫는다. 이미 실행된 원격/인증 관리 작업은 되돌리지 않는다.
- 수용 검증: 인코딩 선택·취소 후 기존값 유지, 확인 시 선택값 적용, 환경설정 저장 성공/실패, 하위 창 확인·취소, 단축키 미표시·미작동을 확인한다.
- 명확화: 단축키 제거는 Escape, Ctrl+Enter 및 팝업별 탐색/활성화 키 처리에 적용한다. 입력 자체의 표준 편집 동작은 유지한다. 추가 질문이 필요한 모호성 없음.


## 환경설정 세로 스크롤바

- FR-008 환경설정 본문이 화면에 다 들어오지 않으면 오른쪽에 세로 스크롤 손잡이를 표시한다. 손잡이를 드래그하거나 트랙을 클릭해 내용을 이동할 수 있다.
- SC-004 스크롤 손잡이는 휠과 항목 키보드 이동에 따른 본문 위치를 반영한다. 내용이 모두 보이면 손잡이는 숨기며 창 하단 버튼은 본문과 함께 스크롤하지 않는다.

스크롤바는 환경설정 본문 전체에 적용한다. 원격 저장소, 인증 및 업데이트 섹션은 기존 본문 스크롤 위치를 공유한다.
