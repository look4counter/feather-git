# 기능 명세: 빌드 경고 정리

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.

작성일: 2026-11-15
상태: 검증 완료

## 사용자 시나리오

### 사용자 이야기 1 (우선순위 P1)
개발자가 앱을 빌드할 때 제시된 미사용 코드·타입 추론·향후 호환성 경고가 발생하지 않는다.
수용 기준: 일반 빌드와 테스트에서 대상 경고가 사라지고 기존 동작과 테스트가 유지된다.

## 요구사항

- FR-001: commit_files, diff, remember의 실제 호출 관계에 맞춰 테스트 전용 래퍼와 일반 구현을 구분한다.
- FR-002: 실제 사용되지 않는 Diff.title과 open_keys를 정리하고 그래프 테스트 보조 함수는 테스트에서 유지한다.
- FR-003: GPUI 숫자 타입 추론을 명시하여 경고 원인을 제거한다.
- FR-004: proc-macro-error2의 비공개 proc_macro 재노출 문제를 해결하며 버전 및 동작을 유지한다.
- FR-005: 경고를 전역으로 숨기지 않고 관련 테스트·정적 분석·빌드를 통과시킨다.

## 경계 조건과 가정
테스트 전용 API는 테스트에서 유지한다. 앱 내부 구조만 변경하며 외부 공개 API나 사용자 화면은 변경하지 않는다. 의존성은 같은 버전을 로컬 패치하고 라이선스를 보존한다. 미해결 모호성 없음.

## 성공 기준
제시된 경고 7건과 GPUI 경고 2건, proc-macro-error2 향후 호환성 경고가 새 빌드에서 0건이다. 전체 회귀 테스트가 통과한다.

## 추가 명세: Windows 링커 안내 경고 정리

### 사용자 이야기 2 (우선순위 P1)

개발자는 Windows 배포 빌드에서 임포트 라이브러리 생성 안내로 인한 경고 없이 빌드 결과를 확인한다.
수용 시나리오: 릴리스 실행 파일을 새로 링크하면 해당 안내 경고는 0건이며 실행 파일과 기존 내보내기 심볼은 유지된다. 실제 링커 경고·오류는 계속 확인할 수 있다.

### 추가 요구사항

- FR-006: Windows MSVC 앱 실행 파일 링크에서 불필요한 임포트 라이브러리 생성 안내 경고를 제거한다.
- FR-007: 실행 파일의 기존 내보내기 심볼·GUI 서브시스템을 유지하고 다른 대상과 의존성의 링크 설정은 변경하지 않는다.
- FR-008: linker_messages나 다른 경고를 일괄 억제하지 않는다.
- SC-002: 새 릴리스 링크의 대상 경고가 0건이며 개발·테스트 타깃 검사가 통과한다.

### 명확화 결과

현재 요청은 빌드 경고 정리이며 앱의 UI나 콘솔 실행 정책 변경이 아니다. 생성되는 .lib·.exp는 배포 실행에 쓰지 않는 보조 산출물이다. 실행 파일이 제공하는 심볼은 유지한다. 범위·호환성·검증 기준을 검토했고 추가 질문이 필요한 모호성은 없다.

### 첫 빌드에서 확인한 보완

/NOIMPLIB 단독 적용 시 .lib 생성 안내는 사라졌지만 MSVC가 .exp 생성 안내를 출력했다. FR-001~FR-005를 유지하면서 FR-006으로 Windows 릴리스 빌드의 해당 생성 안내 경고를 제거한다. 실제 오류·다른 경고를 계속 표시해야 한다.
