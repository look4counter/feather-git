# 검증 안내

저장소·설정·인증의 입력 외곽과 체크박스 문구 왼쪽 정렬, 삭제 아이콘과 세로 정렬을 확인한다. 단어 더블클릭, 단일 클릭/드래그, 한글 IME, 비밀번호 마스킹·복사 차단을 확인한다. 자동화 검사 결과와 실제 GUI 미검증 범위를 구분한다.


## 검증 결과 (2026-11-15)

- form_controls::input/labeled_input을 저장소·작성자·원격 추가 및 주소·인증 추가 및 주소·뷰어 설정 입력에 적용했다. 외곽34, 내부32, 패딩4와 동일 테두리·둥근 모서리를 사용한다.
- 환경설정은 공통 label 포함 checkbox를 justify_start 및 text_align Left로 사용하고, Diff 줄 선택은 같은 checkbox_mark를 사용한다. 기존 클릭 가드는 유지한다.
- 두 삭제 버튼은 공통 trash_icon을 사용하고 항목 행을 items_center로 정렬했다. 원격 이름·주소 행도 가운데 정렬한다.
- 더블클릭은 ShapedLine의 글자 시작 위치에서 기존 단어 구분 규칙을 재사용한다. 비밀번호는 전체 선택하고 기존 복사·조회·평문 이벤트 차단을 유지한다.
- 새 단어 선택 테스트 3개 통과. 최초 공백 테스트에서 다른 문자열에 범위를 적용한 오류를 수정했고 동일 입력의 공백 범위를 검증하도록 재실행했다. 조건 완화나 테스트 삭제는 없다.
- 최종 cargo test --offline: 351 통과, 실패 0, 수동 성능 측정 3 무시.
- cargo fmt --all -- --check와 cargo clippy --offline --all-targets -- -D warnings: 종료코드 0.
- cargo rustc --offline --bin feather-git -- -o target/shared-controls-verified.exe: 종료코드 0. 별도 출력 경로 및 MSVC 라이브러리 생성 안내 3건은 소스 경고와 구분한다.
- 실제 GUI 배치·정렬·더블클릭·IME 및 실제 계정 로그인은 미검증이다. 실행 중인 사용자 앱과 전역 설정은 변경하지 않았다.

## 수렴 점검

FR-001은 공통 입력 외곽 및 모든 입력 표시 경로, FR-002는 공통 체크박스·Diff 표시·왼쪽 정렬, FR-003/004는 단어 선택과 Unicode·교체·비밀번호 테스트 및 기존 입력 보호, FR-005는 전체 검사, FR-006은 휴지통 아이콘과 세로 가운데 정렬에 대응한다. 명세·계획·실제 코드 대조에서 미구현이나 불일치를 발견하지 못했다. 새 의존성·저장 형식 변경은 없다.
