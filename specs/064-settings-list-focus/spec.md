# 기능 명세: 설정 목록 디자인 및 포커스 선택 해제

> 문서 정리일: 2026-11-17. 본문은 이 기능의 단계별 요구사항 이력을 포함한다. 현재 유효 기준과 검증 한계는 [전체 명세 색인](../README.md)을 함께 확인한다. 과거 검증 기록은 현재 버전의 재검증 결과가 아니다.

작성일: 2026-11-15
상태: 명확화 완료

## 사용자 시나리오

### 사용자 이야기 1 — 설정 목록 디자인 (우선순위 P1)
환경설정의 원격 저장소와 인증 목록을 최근 저장소 목록처럼 본다.
수용 기준: 행의 패딩12·간격12·둥근 모서리·세로 가운데 정렬, 제목과 보조 문구의 두 단 구성 및 30 크기 휴지통 버튼을 적용한다. 원격 이름과 계정이 제목이며 주소 및 인증 방식은 보조 문구로 표시한다. 최근 저장소의 행 배경색은 가져오지 않고 현재 팝업 배경을 유지한다. 삭제 동작과 비활성 보호·민감정보 가림은 유지한다.

### 사용자 이야기 2 — 체크박스 범위 (우선순위 P1)
체크박스의 박스와 문구 부분에서만 클릭하여 전환한다.
수용 기준: 포커스 시 배경색이 바뀌지 않는다. 행 오른쪽 빈 영역은 클릭해도 전환하지 않는다. 문구 왼쪽 정렬과 기존 전환 가드를 유지한다.

### 사용자 이야기 3 — 입력 선택 해제 (우선순위 P1)
입력창에서 다른 곳으로 포커스를 옮기면 선택 강조가 해제된다.
수용 기준: 선택 범위는 현재 커서 위치로 접히며 텍스트·저장값·비밀번호 보호는 변하지 않는다. 드래그 상태도 해제한다. 역방향 선택과 비밀번호에서도 동일하게 적용하며 더블클릭 선택 기능은 유지한다.

## 요구사항

- FR-001: 원격·인증 목록은 최근 저장소의 배치 및 버튼 모양을 공유하되 배경색을 변경하지 않는다.
- FR-002: 공통 체크박스는 내용 너비만 차지하고 포커스 배경을 제거한다.
- FR-003: 공통 TextInput은 포커스 상실 이벤트로 선택과 드래그 상태를 해제한다.
- FR-004: 기존 저장·원격·인증·삭제 가드 및 IME·비밀 보호를 유지한다.
- FR-005: 관련 자동화 테스트·포맷·정적 분석·빌드를 통과한다.

## 경계 조건과 가정
주소는 입력창 대신 최근 저장소와 같은 일반 보조 라벨로 표시하며 긴 문구는 생략한다. 다중 원격 주소는 같은 항목 아래에 모두 표시한다. 배경색 제외는 행의 기본/호버 배경을 추가하지 않는 것으로 적용하며 버튼의 기존 호버 색상은 유지한다. 포커스 해제는 입력 내용을 변경하거나 조합 문자열을 삭제하지 않는다. 미해결 모호성 없음.

## 성공 기준
두 설정 목록이 동일한 공통 행·제목·보조 문구·삭제 버튼을 사용한다. 체크박스의 클릭 범위가 내용으로 제한되고 포커스 상실의 선택 범위 테스트 및 기존 회귀 검증이 통과한다.

## 추가 요구사항: 폴더 탐색 아이콘

FR-006: 저장소 열기·생성·복제 팝업의 탐색 버튼은 글자 대신 폴더 아이콘을 표시한다. 폴더 선택 이벤트와 비활성 상태는 유지한다. 하단 탐색기 및 문맥 메뉴의 문구는 변경하지 않는다.
