# 조사 결과

현재 툴바는 샘플 notice만 갱신하고 Git 실행은 없다. 공용 문맥 메뉴는 포커스 복원·ESC와 비활성 항목을 지원한다. git2의 fetch/branch_upstream_name/merge/rebase/참조 transaction API와 callback 경로를 확인했다. 프로젝트의 기존 인프로세스 Git 및 백그라운드 요청 구조로 구현 가능하다. 미해결 기술 쟁점 없음.

옵션 제거 결정: UI 옵션만 세 개로 제한하고 기존 내부 리베이스와 키 파서는 보존한다. UI 전용 키 정규화로 저장된 rebase가 재실행되지 않게 한다. 내부 기능 전체 삭제는 기록 리베이스 요구와 무관한 범위 확대이므로 제외했다.
