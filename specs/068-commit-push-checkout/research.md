# 조사 결과

virtual_list는 선택 이벤트에서 클릭 횟수를 버리지만 multi_virtual_list는 같은 가상 목록 구현에서 MouseDownEvent를 제공한다. 이를 저장소 목록 한 곳에서만 사용한다. git2 CheckoutBuilder::safe 및 HEAD transaction 잠금은 기존 Pull의 안전한 파일 갱신 패턴과 일치한다. 원격 tip 비교는 로컬의 오래된 원격 추적 참조만 신뢰하지 않고 원격 광고를 조회한다. 객체 부족 시 download만 수행해 브랜치·FETCH_HEAD를 바꾸지 않고 ahead/behind를 판정한다.
