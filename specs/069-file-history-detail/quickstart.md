# 검증 안내

cargo fmt --check, cargo test, cargo check를 실행한다.
화면에서는 파일 이력 팝업을 열고 왼쪽 상하 반분, 첫 커밋 상세, 다른 커밋 선택 시 상세와 오른쪽 diff 동시 변경, 각 영역 스크롤, 열 너비 조절, 행 메뉴, 닫기를 확인한다.

## 실행 결과

- cargo fmt --check 통과.
- cargo check 통과.
- 전체 cargo test: 405개 통과, 실패 0개, 수동 성능 테스트 3개 제외.
- 마지막 빈 상태 제목 수정 후 파일 이력 테스트 4개 재실행 통과.
- 전체 테스트 실행 중 추가 테스트 링크가 실행 파일 잠금으로 한 차례 실패했으며, 전체 테스트 종료 후 순차 재실행으로 정상 통과했다.
- 실제 GUI의 픽셀 비율과 스크롤 조작은 미검증이다.
- 수렴 점검: 요구사항 5개, 성공 기준 3개, 사용자 시나리오 3개와 설계 결정을 코드 및 테스트에 대조했다. 코드상 누락·모순 및 추가 구현 작업 없음. 화면 검증은 위 제한으로 남는다. 헌법은 미작성 템플릿이다.
