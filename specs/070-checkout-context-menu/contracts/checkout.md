# 기록 브랜치 체크아웃 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

로컬 후보가 있으면 원격·태그는 선택에서 제외한다. 로컬이 없으면 원격 실제 브랜치를 사용하고 HEAD 별칭은 제외한다. 단일 후보는 바로 기존 흐름을 실행한다. 복수 후보는 체크아웃할 브랜치 선택 창에 표시하며 확인·취소 버튼을 제공한다. 기본 선택은 현재 로컬 브랜치가 후보면 그것, 아니면 첫 후보다.
확인 전 변경하지 않는다. 취소·Escape는 닫기만 하고 포커스를 복원한다. 위아래 키는 후보 이동, Tab은 목록·확인·취소를 순환한다. 확인은 유효 선택을 한 번만 실행한다. 기존 행 ID·프로젝트·경로·후보와 실제 로컬 참조의 커밋이 일치해야 한다.
브랜치가 없는 커밋과 태그만 있는 커밋은 기존 Detached HEAD 확인을 유지한다. 원격만 있을 때는 기존 추적 브랜치 흐름을 사용한다.

브랜치 선택 창은 인코딩 선택과 같은 체크 표시·선택/hover 배경·둥근 28픽셀 행을 사용한다. 후보 클릭은 선택만 변경하고 확인 버튼 이후 기존 검증을 거쳐 실행한다.
