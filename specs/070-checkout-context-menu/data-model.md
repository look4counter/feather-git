# 데이터 모델

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

메뉴 대상은 프로젝트 인덱스, 저장소 경로, 참조 탭 또는 커밋 구분, 행 인덱스, 정확한 참조 이름 또는 커밋 ID이다. 메뉴 열기와 실행 사이에 선택이나 대상이 달라지면 실행하지 않는다. 영속 데이터 추가 없음.

BranchCheckoutPrompt는 프로젝트·경로·커밋 ID·행·후보 Vec·선택 인덱스·공용 스크롤을 가진다. CheckoutCommitBranch 요청은 로컬 참조와 예상 커밋을 가진다. 세션 저장 형식은 변경하지 않는다.
