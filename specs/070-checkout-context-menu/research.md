# 조사 결과

결정: 기존 체크아웃 함수가 전체 커밋 ID도 처리한다. 동일한 로컬 변경 보호와 HEAD 저장 경로를 공유하므로 별도 백엔드 추가보다 중복이 적다. 임의 revparse는 범위가 넓어 제외한다.
결정: 우클릭은 기존 파일 메뉴와 같이 행 선택 후 메뉴를 연다. 선택과 프로젝트·경로·탭·대상을 실행 직전 다시 검사한다.
미해결 기술 사항 없음.

브랜치 우선 결정: 메뉴와 더블클릭의 ID 식별은 유지하고 단일 기록 체크아웃 진입점에서 후보를 해석한다. 로컬 우선은 사용자 답변이며 원격만 있으면 기존 원격 처리를 재사용한다. 다중 후보는 공용 Dialog와 가상 목록을 사용한다. 실행 직전 ref 이동은 기존 잠금 코어에 expected commit을 더해 검증한다. 미해결 질문 없음.

## 선택 스타일 통일
인코딩 선택의 행 속성을 적용한다. 공용 24픽셀 표 행의 전역 변경 대신 GPUI 기본 가상 목록에 동일 스타일을 제공하여 다른 목록의 회귀를 피한다. 기존 스크롤·선택 상태는 재사용한다.
