# 데이터 모델

목록: 현재 선택 인덱스, 항목 수, 보존 포커스와 스크롤. 빈 목록은 선택 없음, 경계에서는 이동 없음.
체크아웃 보류: 프로젝트 인덱스·저장소 경로·정확한 대상과 복원 포커스. 요청 → 보류 → 확인 후 검증·실행 또는 취소. 한 번 소비한 요청은 재사용하지 않는다.

추가 데이터: Project.branch_upstreams는 로컬 브랜치명에서 원격 추적 브랜치 표시 이름으로의 맵이다. 실제 Git upstream을 해석하며 로컬 upstream은 포함하지 않는다. 원격 생성 팝업은 프로젝트·경로·원격 참조를 보존하며 확인 시 입력 이름으로 로컬 브랜치와 추적 설정을 만든다. 성공 시 기존 snapshot 갱신으로 배지 정보도 갱신된다.
