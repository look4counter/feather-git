# 검증 안내

모든 목록에서 마우스로 포커스 후 연속 위·아래 이동과 경계·스크롤 확인. 파일 상세와 커밋 상세가 선택을 따른다. 최근 목록은 방향키로 열리지 않고 Enter로 열린다. 설정 목록 이동은 삭제를 실행하지 않는다. 입력 필드와 diff 방향키는 기존 동작 유지. 태그·커밋 메뉴와 태그 더블클릭에서 경고 확인, 취소·Escape에서 무변경, 로컬에서 경고 없음 확인. 원격 메뉴와 더블클릭은 New Branch 팝업을 열고 확인 후 로컬 브랜치·upstream·파일 갱신을 확인한다. 로컬 탭의 현재 배지가 맨 앞에 한 번만 표시되고 추적 대상 배지가 이름 뒤에 표시되는지 확인한다.

## 자동 검증 결과

- 전체 테스트: 412개 통과, 실패 0개, 수동 성능 테스트 3개 제외.
- 신규 검증: 방향키·수정키·빈 목록·경계, 경고 취소·한 번 소비·오래된 프로젝트와 경로·작업 중 거부, 실제 upstream 조회와 추적 해제, 원격 커밋 기반 로컬 브랜치 생성·upstream 설정·파일 반영·중복·누락 대상·로컬 충돌 보호.
- cargo check, cargo fmt --check, cargo clippy -- -D warnings 통과.
- 실제 GUI에서 포커스·키보드·팝업·배지 표시 조작은 미검증이다. 실제 사용자 저장소에는 Git 변경 작업을 실행하지 않았다.
- 일반 cargo build는 기존 target/debug/feather-git.exe 교체 시 접근 거부로 실패했다. 기존 앱을 중단하지 않고 cargo rustc --bin feather-git -- -o target/071-feather-git.exe로 별도 이름의 실행 파일 빌드에 성공했다. 기존 실행 파일은 교체되지 않았다.

## 수렴 점검

최종 요구사항 7개, 성공 기준 5개, 사용자 이야기 4개와 계획의 공통 선택 콜백 재사용·포커스 격리·안전한 체크아웃·실제 upstream 조회·원격 생성 흐름을 코드 및 테스트와 대조했다. 구현상 미해결 누락·모순이나 추가 작업은 없다. 현재 배지 중복을 최종 검토에서 제거했고 컴파일·형식·정적 검사를 재확인했다. 헌법은 미작성 템플릿으로 유효 규범 검사를 생략했다. GUI 미검증과 기존 실행 파일 교체 제한은 위와 같다.

## 추적 배지 표시 변경 검증

- 표시: 현재 배지 → 로컬 아이콘 → 로컬명 → 화살표 → 원격 아이콘과 붉은색 짧은 이름 배지. 추적 없음은 화살표·원격 배지 없음.
- 관련 테스트 3개 통과: 원격 이름 축약 경계, 기존 커밋 참조 분류·축약 회귀, 실제 upstream 조회·해제.
- cargo check, cargo clippy -- -D warnings, cargo fmt --check 통과.
- 별도 출력 경로 빌드: cargo rustc --bin feather-git -- -o target/071-feather-git.exe.
- 전체 테스트는 이번 표시 변경에서 재실행하지 않았다. 실제 GUI 표시와 조작은 미검증이다.
- 수렴 점검: FR-008~009, SC-006, 사용자 이야기 5와 공유 배지·실제 원격명 축약 계획을 코드 및 테스트에 대조했다. 미해결 구현 불일치나 추가 작업 없음. 기존 Git 추적 식별자와 체크아웃 경로는 유지된다.
