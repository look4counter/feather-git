# 검증 안내

네 저장소 탭의 행 우클릭 → 삭제 → 대상·영향 확인 → 취소 또는 확인을 검증한다. 원격은 서버 브랜치 삭제임을 표시하고 스태시는 내용 복구 불가 경고를 표시한다. 현재 브랜치·미병합·오래된 대상 오류를 확인한다. 실제 사용자 저장소에는 삭제를 실행하지 않고 자동 테스트는 격리 저장소와 로컬 원격을 사용한다.

## 실행 결과

- 전체 테스트: 419개 통과, 실패 0개, 수동 성능 테스트 3개 제외.
- 마지막 확인 화면의 객체 ID·스태시 설명 추가 후 삭제 backend 테스트 4개와 UI 확인·취소 상태 테스트 1개 재실행 통과.
- 로컬 현재·미병합·다른 작업 트리·잠금·변경 객체 거부, 태그 삭제, 스태시 순서 변경 거부 및 나머지 항목 보존, 로컬 bare 서버 삭제와 로컬 추적 정리 및 서버 변경 거부를 검증했다.
- 원격 체크아웃의 기존 로컬명 매칭과 기존 로컬 tip·upstream 보존·로컬 변경 보존을 관련 테스트로 검증했다.
- cargo check, cargo fmt --check, 새 파일 rustfmt --check, cargo clippy -- -D warnings 통과.
- 별도 실행 파일 빌드: cargo rustc --bin feather-git -- -o target/072-feather-git.exe.
- 실제 GUI 조작과 외부 서버 인증·정책은 미검증이다. 자동 테스트는 격리 저장소와 로컬 bare 원격만 사용했다. 실제 사용자 저장소·외부 서버에는 삭제 작업을 실행하지 않았다.

## 수렴 점검

요구사항 7개, 성공 기준 4개, 사용자 이야기 4개 및 계획의 계층·확인 게이트·객체 비교·참조 잠금·refspec 매핑·서버 변경 보호·스태시 보존·완료 갱신·기존 로컬 재사용을 코드와 테스트에 대조했다. 미해결 구현 불일치와 추가 작업 없음. 헌법은 미작성 템플릿이므로 유효 규범 검사는 생략했다. 실제 GUI와 외부 서버 인증·정책은 앞서 명시한 미검증 범위로 남는다.
