# 검증 안내

태그 삭제 팝업에서 원격 태그 삭제의 기본 해제·Tab·Space·동적 경고·취소와 확인을 검증한다. 커밋 단일클릭은 선택, 더블클릭은 detached 경고 후 체크아웃인지 확인한다. Branch 오른쪽 Stash 버튼의 이름 입력·스테이지 변경사항 유지·IME·취소·확인을 확인한다. keep-index 양쪽의 파일·인덱스·스태시 내용을 격리 저장소에서 검증한다. 실제 사용자 저장소와 외부 서버에는 변경하지 않는다.

## 실행 결과

- 전체 테스트: 430개 통과, 실패 0개, 수동 성능 테스트 3개 제외.
- 원격 태그 옵션: 기본 해제·확인 전달·취소/완료 초기화 및 격리 bare 서버에서 삭제 성공·미존재·변경 객체 거부를 검증했다.
- 커밋 더블클릭: 정확히 두 번 클릭·올바른 프로젝트/행·비로딩/비작업 상태를 검사하며 기존 체크아웃·detached 확인 경로를 공유한다. 단일클릭과 방향키는 기존 선택 경로다.
- Stash: keep-index 양쪽에서 저장 메시지·작업 트리 내용·스테이지 스냅샷·현재 인덱스·HEAD·미추적 파일을 검증했다. 빈 이름·변경 없음·초기 커밋 없음·병합 진행·잠금 오류 시 보존을 확인했다.
- cargo check, cargo clippy -- -D warnings, cargo fmt --check 및 포함 소스 rustfmt --check 통과.
- cargo rustc --bin feather-git -- -o target/074-feather-git.exe 별도 실행 파일 빌드 성공. 기존 실행 파일은 교체하지 않았다.
- 실제 GUI의 더블클릭·포커스·팝업·IME와 외부 서버 인증·정책은 미검증이다. 자동 테스트는 격리 저장소와 로컬 bare 원격을 사용했으며 실제 사용자 저장소·외부 서버에는 변경을 실행하지 않았다.

## 최종 코드 대조

요구사항 6개, 성공 기준 3개, 사용자 이야기 3개와 계획의 공통 원격 정책·확인 옵션·객체 보호·더블클릭 확인 경로·keep-index·팝업 소유자·비동기 완료 갱신을 코드 및 테스트에 대조했다. 구현상 미해결 누락·모순과 추가 작업 없음. 헌법은 미작성 템플릿으로 유효 규범 검사는 생략했다. GUI와 외부 인증의 검증 제한은 위와 같다.
