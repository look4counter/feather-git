# 조사 결과

기존 원격 삭제 negotiation과 삭제 후 로컬 정리를 태그에도 재사용한다. 태그 생성 원격 선택 함수를 추출해 정책 중복을 피한다. 서버 태그가 다른 객체라면 기존 ID 보호를 유지한다.
기존 multi_virtual_list는 클릭 횟수를 제공하며 공용 방향키는 click_count=1로 선택 콜백을 실행한다. 따라서 더블클릭만 체크아웃으로 구분할 수 있다.
KEEP_INDEX는 스태지된 변경을 포함해 스태시에 저장하되 인덱스와 해당 작업 내용을 유지하는 표준 의미다. INCLUDE_UNTRACKED는 사용하지 않는다. 기존 이름 팝업을 재사용한다. 미해결 기술 질문 없음.
