# 검증 안내

스태시 행 우클릭에서 스태시 적용과 삭제를 확인한다. 적용 후 저장된 파일 내용과 목록의 스태시 보존, HEAD 유지, 파일 패널 갱신을 확인한다. 다른 행·탭·프로젝트 이동 뒤 오래된 메뉴는 실행되지 않아야 한다. dirty 충돌·잠금·진행 상태 오류는 강제 덮어쓰기 없이 표시한다. 실제 사용자 저장소 대신 격리 자동 테스트로 검증한다.

## 관련 검증 결과

- 선택 스태시 적용·목록 보존·HEAD 유지·미추적 파일 보존 테스트 통과.
- 스태시 순번 변경·로컬 변경 충돌·잘못된 참조·index.lock·refs/stash.lock 거부 테스트 통과.
- UI의 스태시 전용 대상·선택·프로젝트·행·변경 설명·작업 중 차단 테스트 통과.
- cargo check, cargo clippy -- -D warnings, cargo fmt --check, stash_actions.rs rustfmt --check 통과.
- cargo rustc --bin feather-git -- -o target/075-feather-git.exe 별도 실행 파일 빌드 성공. 기존 실행 파일은 교체하지 않았다.
- 실제 GUI 조작은 미검증이며 실제 사용자 저장소에 적용하지 않았다. 자동 테스트는 격리 저장소만 사용했다.
- 전체 회귀 테스트: 434개 통과, 실패 0개, 수동 성능 테스트 3개 제외.

## 최종 코드 대조

요구사항 4개, 성공 기준 3개, 사용자 이야기 2개와 계획의 기존 스냅샷 재사용·스태시 참조 잠금·안전한 적용·메뉴 상태 검사·비동기 진행 및 완료 갱신을 코드와 테스트에 대조했다. 구현상 미해결 누락·모순 및 추가 작업 없음. 헌법은 미작성 템플릿으로 유효 규범 검사 생략. 실제 GUI 검증의 제한은 위와 같다.
