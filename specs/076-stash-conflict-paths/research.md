# 조사 결과

checkout notify는 인덱스에 충돌이 남기 전에 로컬 변경 덮어쓰기 충돌 경로를 제공한다. callback과 적용 전후 인덱스 충돌을 함께 사용한다. 원본 PathBuf를 backend에 보존하고 UI에서 기존 display_path로 변환한다. 타입 오류를 downcast하므로 사용자에게 보여줄 메시지와 경로를 분리할 수 있다.
스태시 표시 이름은 순번·설명으로 만들되 실제 참조와 객체 검증을 유지한다. 표시 함수와 locator 검증을 함께 갱신해야 적용과 삭제 회귀를 피할 수 있다. 미해결 기술 질문 없음.
