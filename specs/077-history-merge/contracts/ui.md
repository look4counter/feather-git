# 화면 및 내부 계약

기록 커밋 메뉴에 병합을 표시한다. 참조 목록 메뉴에는 추가하지 않는다.
실행 직전 프로젝트·경로·선택 커밋·작업 상태를 다시 검사한다.
오류 제목은 병합 실패이며 상세 오류는 공통 알림에 전달한다.
merge_commit(path, id)는 현재 로컬 브랜치에만 반영하며 충돌 시 해결 가능한 상태를 남긴다.

병합 실패 알림은 로컬 변경 차단이면 커밋·스태시를 안내하고 실제 영향 파일 목록을 표시한다. 실제 잠금은 별도 원인으로 안내한다. 병합 후 충돌은 해결·병합 완료를 안내한다. 경로는 추측하지 않고 현재 프로젝트·경로·revision일 때만 표시한다. 같은 도우미를 쓰는 Pull에도 적용한다.
