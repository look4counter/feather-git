# 데이터 모델

ToolbarAction::MergeCommit { id: String }은 선택 커밋 전체 식별자를 가진다.
정상 상태와 로컬 HEAD 및 유효 커밋을 검사한다. 정상 상태에서 빠른 전진 또는 병합 커밋으로 전이하며 충돌은 병합 중 상태를 유지한다. 이미 포함되면 정상 유지한다.
기존 ToolbarResult의 결과·프로젝트·기록을 재사용하며 영속 형식 변경은 없다.

MergeFailure는 종류(로컬 변경 차단·실제 잠금·병합 충돌·기타), 정렬·중복 제거 경로 목록, 사용자 문구를 가진다. 원래 오류를 오류 체인에 보존한다. ToolbarResult의 기존 경로와 SyncResult의 새 경로로 전달한다.
