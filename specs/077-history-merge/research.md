# 조사 결과

- 결정: 기존 Pull의 잠금·빠른 전진·병합 도우미를 재사용한다. 데이터 보호와 충돌 상태 보존이 이미 구현되어 있다. 별도 Git 명령이나 중복 모듈은 불필요하다.
- 결정: 정확한 커밋 식별자로 네트워크 조회 없이 실행한다.
- 결정: 기존 ToolbarRequest를 사용해 진행 표시·동시 작업 차단·실패 후 갱신을 공유한다.
- 미확정 기술 선택과 외부 조사가 필요한 질문은 없다.

진단 결정: 기존 스태시의 Git checkout 알림과 공통 오류창을 재사용한다. 모든 dirty 파일을 오류 후보로 표시하는 대안은 무관한 파일을 원인으로 오인하므로 제외한다. 공용 충돌 인덱스 수집기는 repository 내부로 이동한다. 오류 코드로 원인을 구분하며 확인 불가 경로는 추측하지 않는다. 미해결 기술 질문 없음.

추가 결정: libgit2의 merge.c 사전 검사에서 경로 알림 없이 Conflict가 발생하는 것을 재현했다. 해당 실패에 한해 인메모리 병합 결과와 실제 index·workdir를 같은 기준으로 비교한다. 무관한 dirty 경로와 병합 결과에 일치하는 staged 경로는 제외한다. 진단 자체의 오류도 숨기지 않는다.
