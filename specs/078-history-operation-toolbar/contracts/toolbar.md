# 상태 툴바 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

위치: 커밋 기록 제목 아래·목록 위. 상태가 있으면 표시하고 정상은 숨긴다.
우선순위: 실행 중 커밋 → 실행 중 Git 명령 → 조회 오류 → 미완료 작업과 충돌 여부 → 작업 없는 충돌 → 숨김.
예시: 병합 실행 중…, 병합 진행 중 · 충돌 해결 필요, 병합 진행 중 · 완료 대기, Git 작업 상태 확인 실패.
기존 주제 색상과 한 줄 줄임 표시를 사용하며 병합 상태에는 병합 커밋·병합 취소 버튼을 제공한다.
상태는 백그라운드에서 읽고 현재 프로젝트·경로·revision 검증 후 반영한다. 기존 모달과 진행 표시는 유지한다.

병합 상태에서만 병합 커밋·병합 취소를 표시한다. 충돌이면 커밋 비활성화, 실행·갱신·모달 중에는 둘 다 비활성화한다. 취소 확인창은 취소에 기본 포커스를 두고 Enter는 선택 버튼, Escape는 취소, Tab은 버튼 이동으로 동작한다.

확인창 버튼은 확인·취소이며 기본 포커스는 취소다. 툴바 두 버튼은 높이 24px·좌우 패딩 8px·글자 12px의 공용 status_button으로 표시한다. 활성 버튼 hover는 SELECTED 배경이며 비활성은 hover와 실행을 막는다.
