1. cargo test --offline로 상태 전이·충돌·프로젝트·오류·기존 회귀를 검증한다.
2. cargo check --offline 및 cargo clippy --offline --all-targets -- -D warnings를 실행한다.
3. 실행 중 앱을 보존하도록 별도 경로에 cargo rustc로 빌드한다.
4. 앱에서 병합 충돌을 만든 뒤 기록 상단 상태를 확인하고 해결·커밋 후 숨김을 확인한다.
