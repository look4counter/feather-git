# 조사 결과

- 결정: libgit2 RepositoryState와 index.has_conflicts를 기존 백그라운드 읽기에서 수집한다. 파일 이름만 추측하거나 렌더링에서 저장소를 여는 대안을 제외했다.
- 결정: Project와 PanelResult로 전달한다. 초기 열기·작업 후 새로 읽기·파일 목록 갱신을 함께 지원한다.
- 결정: 기존 실행 플래그에 표시 이름만 추가한다. 실행 관리 체계를 새로 만들지 않는다.
- 미해결 기술 질문 없음. 외부 조사나 별도 조사 에이전트가 필요한 미확정 기술 선택 없음.

병합 버튼 결정: 커밋은 기존 창을 재사용한다. 취소는 로컬 git merge -h에서 확인한 --abort를 사용하며 강제 reset 대안은 제외한다. 실행은 기존 백엔드 툴바, 확인은 공용 Dialog를 사용한다. 미해결 기술 질문 없음.

표시 개선 결정: 공용 status_button의 SELECTED hover와 작은 패딩을 재사용한다. dialog::button의 전역 hover를 바꾸는 대안은 다른 모달에 영향을 주므로 제외했다. 크기는 24px·글자 12px로 정했으며 미해결 질문 없음.
