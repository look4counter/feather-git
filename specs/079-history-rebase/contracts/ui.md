# 메뉴·실행 계약

기록 우클릭 → 리베이스 → 정방향 (현재를 대상 브랜치로), 역방향 (대상을 현재 브랜치로).
정방향은 선택 커밋을 기준으로 현재 브랜치를 재배치한다. 역방향은 선택 커밋의 다른 로컬 브랜치를 재배치하고 완료 후 처음 체크아웃된 브랜치로 돌아온다. 여러 후보면 역방향의 자식에 브랜치별 항목을 표시하며 후보 없음은 비활성이다.
하위 메뉴는 hover·클릭·오른쪽·Enter로 열고 왼쪽으로 돌아가며 Escape·외부 클릭·창 비활성화로 안전하게 닫는다. leaf 선택은 한 번만 실행하고 포커스를 복원한다.
리베이스 계속·리베이스 취소는 24px 공용 버튼이다. 충돌·작업·모달·갱신 중에는 적절히 비활성화한다. 취소 창은 확인·취소이며 기본 포커스는 취소다.
오류는 실제 원인 경로를 공통 알림에 표시하고 성공·실패 모두 같은 저장소 결과만 갱신한다. 새 명령은 원격 조회를 하지 않는다. Pull은 기존 세 옵션만 유지한다.
