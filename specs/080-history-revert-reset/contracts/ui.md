# UI 계약

> 정리 안내: 단계별 설계·작업 기록이며 후속 변경은 [현재 명세 색인](../../README.md)과 해당 기능의 spec.md를 따른다. 기존 체크 상태와 과거 검증 이력은 현재 재검증 완료를 의미하지 않는다.

기록 행 컨텍스트 메뉴에 Revert·Reset을 추가한다. Reset은 인코딩 선택창과 같은 3개 행에서 하나를 고른다. 옵션 클릭은 즉시 저장소를 변경하지 않으며 확인 버튼/확인 포커스 Enter만 실행한다. 취소/Escape는 실행하지 않는다. Tab은 옵션 영역·확인·취소 사이를 이동하며 확인창의 배경 작업은 차단된다.

Revert 체크박스 표기는 no-commit이며 병합 커밋은 첫 부모 기준을 설명한다. Reset Hard 선택 시 미커밋 변경과 방해 경로 제거 영향을 설명한다. 병합·리베이스·Push와 Pull 병합도 대상 정보와 확인·취소를 표시한다. 네트워크 Push는 확인 뒤에만 시작한다.

전역 F5는 네트워크 없이 현재 프로젝트를 다시 읽는다. 찾기는 공통 탭·입력·검색 버튼·가상 목록·중앙 안내를 사용하며 커밋 결과 선택은 기록으로 즉시 이동하며 커밋 우클릭 메뉴와 복사는 제공하지 않는다. 파일 결과 우클릭은 파일 이력 보기만 제공한다. 입력 Enter는 포커스·IME·수정키를 검증한 뒤 검색한다. 브랜치 선택에는 후보가 하나여도 Detached HEAD 행을 함께 표시한다.

Revert 진행 상태에서는 계속·취소를 제공하고 취소는 기존 확인창을 사용한다. no-commit 충돌 해결 후 계속해도 자동 커밋하지 않는다. 공통 입력창은 Shift+Home/End로 현재 줄의 처음·끝까지 선택한다. 기록 메뉴 표기는 Merge·Rebase를 사용한다.

그래프의 추가 부모 연결은 해당 부모를 기다리는 가장 왼쪽 기존 레인을 재사용하며 기존 레인이 없을 때만 새 레인을 추가한다.
