# 수동 검증

1. 임시 저장소에서 기록의 Revert를 열어 no-commit 해제/체크·취소·Escape와 실제 커밋/인덱스 결과를 확인한다.
2. Reset에서 Mixed 기본값·방향키·클릭·확인·취소를 확인한다. 임시 변경으로 Soft/Mixed/Hard 차이와 Hard 경고를 확인한다.
3. 기록의 병합·정방향/역방향 리베이스와 툴바 Push·Pull 병합이 확인창부터 열고 취소하면 작업을 시작하지 않는지 확인한다.
4. 팝업 중 배경 메뉴·프로젝트 전환이 차단되고 닫으면 이전 포커스가 복원되는지 확인한다.
5. Git 충돌과 오류에서 현재 저장소 상태와 목록이 갱신되며 실제 경로·원인이 표시되는지 확인한다. 충돌한 Revert는 Stage 후 Revert 계속으로 처리하거나 Revert 취소 확인창으로 취소한다. no-commit 충돌은 앱 재시작 후 계속해도 HEAD를 유지하고 변경을 Stage에 남겨야 한다.

자동 검증은 cargo test --offline, cargo check --offline, cargo clippy --offline --all-targets -- -D warnings와 별도 출력 빌드로 수행한다.

## 추가 수동 검증

6. 브랜치가 하나 또는 여러 개인 커밋을 체크아웃하면 Detached HEAD 행이 함께 나오는지 확인한다. 선택·확인 후 기존 detached 경고가 표시되고 취소하면 상태가 바뀌지 않아야 한다.
7. 저장소·기록·파일·DiffViewer·찾기 입력 중 어느 곳에서 F5를 눌러도 Fetch 없이 로컬의 외부 커밋·브랜치·파일이 반영되는지 확인한다. 파일 경로/Stage와 커밋 선택을 가능한 범위에서 유지하고 뷰어는 동일 대상도 다시 읽어야 한다. 수정키+F5와 팝업 중 F5는 실행하지 않는다.
8. 찾기 탭에서 커밋 메시지 본문·파일 경로·과거 파일 내용·작업트리 추적 및 미추적 내용을 검색한다. 커밋 결과 선택으로 기록으로 이동하고 커밋 우클릭 메뉴가 없는지 확인한다. 파일 결과 우클릭에는 파일 이력 보기만 있어야 한다. old의 Space/O 단축키는 추가하지 않았다.
9. 처음 로딩된 기록에 없는 커밋 결과도 이동하는지 확인하고 쿼리·프로젝트 전환 뒤 오래된 결과가 반영되지 않는지 확인한다. 찾기 중 F5는 현재 쿼리도 다시 실행한다.
10. 옵션 선택창의 기본값·체크 표시·선택 배경·Hard 설명·확인/취소·Escape·Tab·방향키와 포커스 복원을 확인한다.

## 검증 중 확인한 사항

- 표준 Git CLI를 실행한 뒤 libgit2의 기존 index 핸들은 캐시가 남을 수 있으므로 검사와 테스트는 index.read(true)로 디스크 상태를 다시 읽는다. 표준 Git의 실제 HEAD·인덱스·작업트리 변경을 확인했다.
- 검색의 tree 탐색은 명시적 스택을 사용한다. 취소 checkpoint가 C 콜백 안에서 unwind하지 않게 하면서 파일마다 취소를 확인한다.
- 검색 결과 이동은 쿼리 세대·엔티티·프로젝트·경로·현재 탭을 검증한다. 오래된 이동 응답도 자신의 진행 표시를 정리하고 새 화면을 변경하지 않는다.
- 기존 F5 회귀는 파일 패널 한정 요구사항을 전역 요구사항으로 갱신했다. 외부 로컬 커밋·브랜치·미추적 파일 갱신과 선택 복원, 히스토리 모드·차단·수정키를 검증한다.
- 그래프 부모 연결은 아래 추가 검증대로 수정했다. 대용량 DiffViewer는 이번 범위에 없으며 old 디렉터리는 읽기 전용으로 참고했다.

## 추가 수동 검증

11. 모든 공통 입력창에서 Shift+Home/End의 줄 단위 선택과 한글·이모지·기존 선택의 방향 전환을 확인한다. 찾기 입력 Enter는 검색하고 IME 확정 Enter는 검색하지 않아야 한다.
12. 같은 부모를 기다리는 레인이 여러 개인 그래프에서 추가 부모가 가장 왼쪽 기존 레인으로 연결되고 불필요한 새 레인이 생기지 않는지 확인한다.

- 추가 검증은 Revert 계속·취소·no-commit 재시작·외부 Git 진행·HEAD/잠금, UI 활성 조건·취소 확인, Shift 줄 선택, Enter 포커스/IME/수정키, 찾기 결과 선택과 부모 레인 회귀를 포함한다. 기존 Revert/Reset·확인창·F5·검색 테스트도 통과했다.
