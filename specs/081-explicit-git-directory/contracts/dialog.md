# 대화상자 경로 계약

| 작업 | 선택 후 경로 | 이름 기본값 | 최종 경로 의미 |
| --- | --- | --- | --- |
| Create | 선택 폴더/.git | 부모 이름 | 생성할 Git 디렉터리 |
| Clone | 선택 폴더/.git | 부모 이름 | 복제할 Git 디렉터리 |
| Open | 선택 경로 그대로 | .git 및 .git숫자는 부모 이름 | 기존 Git 디렉터리 |

수동 입력은 추가 변환하지 않는다. 이름 수정은 확인 시 보존한다. 취소는 입력을 변경하지 않는다. 최근 목록에는 실제 Git 디렉터리 경로를 표시한다.
