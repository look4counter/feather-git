# 데이터 모델

## 프로젝트

- path: 정규화한 Git 디렉터리. 탭·요청·최근 목록·세션의 식별 경로이다.
- workdir: 선택적인 실제 작업 폴더. 베어 저장소에는 없다.
- name: 사용자가 수정 가능한 표시 이름이다.

## 요청과 세션

Create·Clone의 path는 최종 Git 디렉터리이며 부모가 작업 폴더이다. Open은 선택 Git 디렉터리와 이전 작업 폴더 경로를 지원한다. source/name 검증은 유지한다.

세션 version=1과 기존 필드를 유지한다. 유효한 경로를 Git 디렉터리로 변환하고 open/recent 중복을 제거하며 active도 변환한다. 존재하지 않는 경로는 보존한다.
