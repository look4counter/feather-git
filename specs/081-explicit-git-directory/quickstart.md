# 검증 안내

프로젝트 루트에서 cargo test, cargo check, cargo clippy --all-targets를 실행한다. 테스트는 로컬 저장소를 사용한다.

1. Create에서 폴더 선택 후 .git 기본 경로와 부모 이름을 확인한다.
2. .git2로 바꿔 생성하고 기존 .git 보존·작업 파일 조회·스테이지를 확인한다.
3. Clone에서 .git과 .git2를 사용하여 복제하고 파일이 부모에 나타나는지 확인한다.
4. Open에서 두 저장소를 열고 최근 목록과 재시작 후 구분을 확인한다.
5. 파일 열기·경로 복사·작업 폴더 열기가 부모를 사용하고 삭제 보호가 유지되는지 확인한다.
6. 이전 작업 폴더 경로가 담긴 세션을 읽어 Git 디렉터리로 변환되는지 확인한다.

## 실행 결과 — 2026-11-17

- 최초 회귀 테스트에서 기존 구현의 직접 경로 생성·복제·대상 재사용 오류 3건을 재현한 후 수정했다.
- 전체 회귀 실행: 511개 통과, 실패 0개, 수동 성능 측정 3개 무시. 로그는 target/081-test-results.log에 있다.
- 마지막 Clone 경계 조건 수정 후 Clone 관련 6개를 다시 실행하여 모두 통과했다. 빈 소스·다중 브랜치·분리된 HEAD·사용자 지정 경로·공유 부모·기존 파일 보존을 포함한다.
- 최종 cargo check --all-targets 및 cargo clippy --all-targets가 종료 코드 0으로 통과했다. Clippy 경고는 없었다. 테스트 링크 시 기존 MSVC 라이브러리 생성 안내가 경고로 출력되었다.
- git diff --check가 통과했다.
- 테스트 임시 경로는 쓰기 권한이 있는 프로젝트 target/test-tmp로 TEMP와 TMP를 지정했다. 사용자 전역 환경설정은 변경하지 않았다.
- UI 폴더 선택창을 실제로 조작하는 수동 검증과 원격 서비스 인증을 통한 실제 네트워크 Clone은 수행하지 않았다. UI 기본값 계산 및 로컬 저장소 기반 통합 테스트로 검증했다.
