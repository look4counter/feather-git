# 조사 결과

## 저장소 식별

결정: Project.path를 repo.path로 통일하고 workdir을 별도 보관한다. 기존 snapshot이 workdir을 저장하면 .git2로 열어도 후속 작업이 .git으로 전환되기 때문이다. 모든 요청에 별도 필드를 추가하는 대안보다 변경이 작다.

## 초기화와 복제

결정: 직접 지정한 경로에 bare 생성·복제 후 작업 트리를 연결한다. 설치된 git2 소스에서 workdir_path가 .git 연결 파일을 만들 수 있고 RepoBuilder에 생성 콜백이 없음을 확인했다. 부모에서 일반 복제 후 .git 이동은 기존 저장소와 충돌하므로 채택하지 않는다. 로컬 저장소로 gix 재열기·원격 추적·체크아웃을 검증한다.

## 호환성과 보호

결정: 기존 JSON 구조를 유지하고 읽을 때 경로를 정규화한다. 파일 작업에는 실제 workdir을 사용한다. 별도 식별자와 세션 버전 도입은 불필요하다.

## Windows 숨김 속성

설치된 libgit2의 repository.c는 GIT_REPOSITORY_INIT__HAS_DOTGIT일 때만 숨김을 적용한다. .git2를 일반화하려면 앱에서 명시적으로 속성을 추가해야 한다. 기존 windows 의존성이 파일 속성 API를 제공하므로 외부 명령이나 신규 라이브러리는 필요하지 않다.
