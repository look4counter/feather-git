# 기능 명세: Git 디렉터리 직접 지정

**작성일**: 2026-11-17  
**상태**: 명세 및 명확화 검증 완료

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 생성 경로 지정 (우선순위: P1)

사용자는 작업 폴더를 선택하고 기본 입력된 `.git`을 그대로 쓰거나 `.git2` 등으로 수정하여 생성한다.

**우선순위 이유**: 요청의 기본 생성 흐름이다.  
**독립 검증**: 기본·사용자 지정 경로에 생성하고 기존 파일 보존과 부모 작업 트리 연결을 검사한다.

1. 폴더 선택 시 경로는 `선택 폴더/.git`, 이름은 선택 폴더 이름이다.
2. `.git2`로 수정하면 해당 위치에 생성되고 부모가 작업 폴더가 된다.
3. 기존 대상은 빈 폴더도 덮어쓰지 않는다. 다른 저장소와 작업 파일은 보존한다.

### 사용자 이야기 2 — 복제 경로 지정 (우선순위: P1)

사용자는 Clone에서도 같은 경로·이름 규칙으로 복제한다.

**우선순위 이유**: 사용자가 생성과 같은 처리를 요청했다.  
**독립 검증**: 로컬 소스를 기본·사용자 지정 경로로 복제하고 이력·체크아웃·원격 추적 설정을 확인한다.

1. 폴더 선택과 이름 기본값은 생성과 같다.
2. 메타데이터는 지정 경로에, 작업 파일은 부모 폴더에 생긴다.
3. 기존 작업 파일이 있으면 복제를 거절한다. 기존 Git 메타데이터만 있는 부모에는 허용한다.
4. 잘못된 소스는 인증정보를 노출하지 않고 대상 생성 전에 거절한다.

### 사용자 이야기 3 — 열기와 최근 저장소 (우선순위: P1)

사용자는 Git 디렉터리를 직접 열고 최근 목록에서 같은 저장소를 다시 연다.

**우선순위 이유**: 같은 작업 폴더의 여러 저장소가 혼동되지 않아야 한다.  
**독립 검증**: 같은 부모의 두 저장소를 별도 항목으로 저장·복원한다.

1. Open은 선택 경로를 그대로 쓰고 `.git`을 추가하지 않는다.
2. 최근 목록·열린 탭·활성 저장소를 Git 디렉터리로 구분한다.
3. 이전 작업 폴더 경로를 실제 Git 디렉터리로 변환하고 중복을 제거한다. 누락 항목은 보존한다.
4. 파일 조회·스테이지·열기·경로 복사·디렉터리 열기는 실제 작업 폴더를 사용하고 삭제 보호를 유지한다.

### 경계 조건

- 수동 입력은 최종 Git 디렉터리이며 확인 시 추가 변환하지 않는다.
- 폴더 선택 취소는 입력을 보존하고 재선택 시 기본값을 새로 채운다.
- Create·Clone의 이름은 최종 경로의 부모 이름이며 직접 수정할 수 있다.
- Open은 `.git`과 `.git` 뒤 숫자 형태이면 부모 이름을 기본값으로 사용한다. 베어 및 다른 이름의 저장소는 기존 이름 규칙을 유지한다.
- 부모를 정할 수 없는 생성 경로, 기존 파일·폴더·링크 대상은 거절한다.
- 외부 분리 저장소와 worktree의 작업 트리 연결을 임의로 변경하지 않는다.

## 요구사항

### 기능 요구사항

- **FR-001**: Create·Clone의 폴더 선택 직후에만 `.git`을 추가하고 최종 입력은 보존한다.
- **FR-002**: 생성·복제의 이름은 부모 작업 폴더에서 계산하며 직접 수정 가능하다.
- **FR-003**: 지정된 Git 디렉터리를 부모 작업 트리와 연결하여 생성하고 기존 대상을 보존한다.
- **FR-004**: 지정된 Git 디렉터리에 복제하고 부모에 체크아웃하며 원격 추적 설정과 기존 파일 보존을 보장한다.
- **FR-005**: Open은 Git 디렉터리 직접 선택과 이전 작업 폴더·베어 저장소 호환성을 지원한다.
- **FR-006**: 최근 목록·탭·세션을 Git 디렉터리로 식별하고 이전 항목을 호환 변환한다.
- **FR-007**: 작업 파일 기능은 실제 작업 트리를 사용하고 메타데이터 삭제 보호를 유지한다.
- **FR-009**: Windows에서 Create·Clone으로 새로 만든 Git 디렉터리는 이름에 관계없이 숨김 속성을 명시적으로 적용한다. 기존 파일 속성은 보존하고 부모 작업 폴더와 작업 파일은 숨기지 않는다. Open으로 연 기존 저장소 속성은 변경하지 않는다. 속성 적용 실패는 생성된 디렉터리가 남아 있음을 알리는 오류로 반환한다. 다른 운영체제의 동작은 유지한다.
- **FR-008**: 정상·실패·경계 조건 자동화 테스트, 빌드·정적 분석·회귀 검증을 실행한다.

### 주요 개체

- 저장소 경로: 메타데이터의 실제 위치이며 저장소 식별자이다.
- 작업 폴더: 실제 파일 위치이며 신규 생성·복제에서는 저장소 경로의 부모이다.
- 저장소 이름: 수정 가능한 표시 이름이며 이름이 같아도 경로가 다르면 별개이다.

## 성공 기준

- **SC-001**: 기본 및 `.git2` 생성·복제에서 지정한 메타데이터·작업 파일 위치가 일치한다.
- **SC-002**: 같은 부모의 두 저장소가 저장·복원 후에도 별개이다.
- **SC-003**: 충돌과 오류 시 기존 대상·작업 파일 내용이 보존된다.
- **SC-004**: 관련 자동화 검증이 통과하고 미검증 범위는 명시한다.

## 가정과 명확화

대화에서 생성·복제·Open·이름·최근 목록 요구가 확정되었다. 기능·데이터·상호작용·오류·범위·완료 조건에 중대한 모호성이 없어 질문은 0개이다. 기존 라이브러리와 세션 형식을 유지한다.

## 추가 명확화 — 2026-11-17

사용자가 .git2에도 숨김 속성을 명시적으로 적용하도록 요청했다. 범위는 현재 기능의 신규 Create·Clone이며 기존 저장소를 여는 동작은 읽기 동작으로 유지한다. 실패는 무시하지 않고 부분 성공을 알린다. 추가 질문이 필요한 모호성은 없다.
