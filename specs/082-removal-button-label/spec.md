# 기능 명세: 최근 저장소 삭제 버튼 문구 중복 수정

**작성일**: 2026-11-17  
**상태**: 명세·명확화 검증 완료

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 삭제 선택지를 한 번씩 표시 (우선순위: P1)

최근 저장소 삭제 팝업의 세 버튼에서 각 이름이 한 번만 표시되어야 한다.

**우선순위 이유**: 사용자가 보고한 화면 오류이다.  
**독립 검증**: 팝업의 항목만 삭제·저장소 파일 삭제·취소 문구가 각각 한 번 표시되는지 확인한다.

1. 팝업을 열면 세 버튼의 이름이 각각 한 번 표시된다.
2. 저장소 파일 삭제 버튼을 누르는 동안 진행 표시 위에서도 문구가 한 번 표시된다.
3. 길게 누르기·중간 취소·Escape 취소 동작은 유지된다.

### 경계 조건

진행 표시가 비어 있거나 가득 찬 경우 모두 문구 중복이 없어야 한다. 다른 팝업의 공통 버튼 표시와 기존 저장소 삭제 동작은 변경하지 않는다.

## 요구사항

- **FR-001**: 세 삭제 선택 버튼의 문구를 각각 한 번만 렌더링한다.
- **FR-002**: 문구는 진행 표시 위에 유지하고 기존 누름·취소 동작을 보존한다.
- **FR-003**: 변경은 해당 팝업에 한정하고 관련 테스트와 컴파일·정적 분석을 실행한다.

## 성공 기준

- **SC-001**: 각 버튼의 표시 문구 추가 지점이 하나이며 진행 표시 위에 위치한다.
- **SC-002**: 기존 길게 누르기 및 취소 회귀 테스트가 통과한다.

## 가정과 명확화

사용자는 앞서 확인된 동일 문구의 이중 추가를 수정하도록 요청했다. 문구·동작·범위의 모호성이 없어 추가 질문은 0개이다.
