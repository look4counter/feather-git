# 재현 안내

전체 테스트는 target/qa-full-tests.log를 확인한다. 임시 재현 코드는 target/qa-run 아래에서 원본 소스를 include하여 실행한다. 테스트 저장소 경로가 target/qa-run/fixtures 아래인지 확인하고 GIT_CEILING_DIRECTORIES로 주 프로젝트 탐색을 막는다. 결과 보고서는 docs/qa-2026-11-17.md이다.

## 점검 결과

- 전체 자동화 515개 통과·3개 성능 측정 제외, cargo check와 clippy 통과.
- 원본 함수 호출로 잘못된 저장소 Reset/Revert, .git2 단독 실패, 상위 저장소 Reset, 검색 메타데이터 노출을 재현했다.
- 터미널 컨텍스트와 숨김 디렉터리 선택에 추가 위험이 있다. 실행 재현과 코드상 위험을 보고서에서 구분했다.
- 실제 UI는 자동 승인 검토 거부로 미검증이다. QA 테스트 프로세스만 종료했고 기존 사용자 앱과 설정은 보존했다.
- 앱 결함은 발견·기록만 했으며 수정하지 않았다. 점검 명세와 보고서 사이의 미해결 누락은 없다.
