# 조사 결과

## Git 명령

선택 repo 검증과 Git 명령의 탐색 대상이 다르다. -C만으로는 .git2를 지정할 수 없으므로 실제 repo.path와 workdir을 인수로 전달해야 한다. 모든 관련 작업을 같은 내부 생성 함수로 통일한다.

## 검색

기존 변경 파일 목록의 실제 메타데이터 탐지 규칙을 공유한다. 이름이 .git2로 시작한다는 이유만으로 일반 폴더를 숨기는 대안은 채택하지 않는다.

## 터미널과 선택창

터미널은 기존 안전한 인수와 작업 폴더 구성을 유지하면서 환경을 지정한다. 폴더 선택은 기존 Windows FOS_FORCESHOWHIDDEN 플래그로 해결하며 공개 필드 추가와 OS 설정 변경은 필요하지 않다.
