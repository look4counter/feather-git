# 기능 명세: 저장소 컨텍스트 및 선택·검색 결함 수정

**작성일**: 2026-11-17  
**상태**: 명세·명확화 검증 완료  
**입력**: 사용 흐름 점검에서 발견한 네 가지 문제를 모두 수정한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 선택한 저장소에만 Git 작업 적용 (우선순위: P1)

사용자는 .git2를 열고 이력 변경과 진행 중 작업의 계속·중단을 수행할 때 해당 저장소만 변경되기를 기대한다.

**독립 검증**: 단독 .git2, 동위 .git/.git2, 상위 저장소가 있는 하위 .git2에서 대상과 비대상 HEAD·인덱스·작업 상태를 비교한다.

1. Reset은 선택 저장소의 HEAD 및 선택한 모드에 해당하는 층만 변경한다.
2. Revert와 계속·중단, Merge/Rebase 중단은 선택 저장소에 적용된다.
3. 외부 Git 경로 환경변수에 의해 다른 저장소로 전환되지 않는다.
4. 기존 잠금·변경된 HEAD·충돌 검사와 오류 전달은 유지한다.

### 사용자 이야기 2 — 작업 파일만 검색 (우선순위: P2)

Git 디렉터리의 내부 파일이 파일 검색 결과에 섞이지 않아야 한다.

**독립 검증**: 실제 메타데이터와 비슷한 이름의 일반 폴더·작업 파일을 함께 만들고 검색한다.

1. 현재 작업 폴더 안의 실제 Git 메타데이터는 추적·미추적 파일 검색에서 제외한다.
2. .git 구성 요소는 제외하며 .gitignore나 .git2-notes 같은 일반 파일·폴더는 유지한다.
3. 커밋 메시지 및 정상 파일의 경로·내용 검색은 유지한다.

### 사용자 이야기 3 — 터미널에서 같은 저장소 사용 (우선순위: P2)

앱에서 연 Git Bash·PowerShell은 선택한 저장소를 대상으로 Git 명령을 실행한다.

**독립 검증**: 터미널에 설정하는 실제 환경을 적용한 자식 Git 명령에서 Git 디렉터리·작업 폴더·인덱스를 확인한다.

1. GIT_DIR과 GIT_WORK_TREE는 선택 저장소를 가리킨다.
2. 외부 인덱스·공통 디렉터리 환경은 제거하고 경로는 명령 문자열로 실행하지 않는다.
3. 베어 저장소와 기존 디렉터리 열기·오류 흐름을 유지하며 Explorer에는 터미널 환경을 적용하지 않는다.

### 사용자 이야기 4 — 숨김 Git 디렉터리 선택 (우선순위: P2)

Windows의 Open 폴더 선택창은 숨김 Git 디렉터리를 표시할 수 있어야 한다.

**독립 검증**: 네이티브 폴더 선택 옵션에 숨김 표시가 포함되고 기존 파일·다중 선택 옵션이 보존됨을 확인한다.

1. 폴더 선택에 숨김 항목 강제 표시를 적용한다.
2. 파일 전용 선택의 기존 옵션과 공개 API 형식은 유지한다.

## 요구사항

- **FR-001**: 이력 변경·계속·중단의 Git CLI는 실제 Git 디렉터리와 작업 폴더를 명시한다.
- **FR-002**: 비대상 저장소의 HEAD·인덱스·진행 상태를 보존하고 기존 검증을 유지한다.
- **FR-003**: 실제 Git 메타데이터를 파일 검색에서 제외하되 정상 파일과 커밋 검색은 보존한다.
- **FR-004**: Git Bash·PowerShell의 Git 환경을 선택 저장소로 설정하고 오염된 경로 환경을 제거한다.
- **FR-005**: Windows 폴더 선택창에 숨김 표시를 적용하고 공개 API·파일 선택 계약을 보존한다.
- **FR-006**: 재현 테스트·전체 회귀·빌드·정적 분석을 수행하고 실제 화면 미검증은 별도로 명시한다.

## 성공 기준

- **SC-001**: 앞서 재현한 잘못된 저장소 Reset/Revert와 .git2 단독 실패가 해소된다.
- **SC-002**: .git2 내부 파일 검색 결과는 0개이며 일반 파일 검색은 유지된다.
- **SC-003**: 터미널 자식 명령은 선택한 Git 디렉터리를 반환한다.
- **SC-004**: 관련 검증이 통과하며 미검증과 남은 제품 문제가 구분된다.

## 경계 조건과 가정

한글·공백·특수문자 경로, 저장소 없는 폴더, 베어 저장소, 단독 및 중첩 저장소, 기존 환경변수를 고려한다. 동위 저장소가 공유하는 작업 파일은 선택한 Git 명령의 의미에 따라 변경될 수 있지만 비대상 메타데이터는 변경하지 않는다.

## 명확화

사용자는 네 가지 수정에 동의했다. 터미널은 선택 저장소의 컨텍스트를 전달하고 Windows 폴더 선택은 숨김 표시를 강제한다. 추가 질문이 필요한 모호성은 없다. 실제 화면 접근은 앞선 자동 승인 거부 때문에 검증 제약으로 기록한다.
