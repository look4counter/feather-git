# 조사 및 설계 결정

src/main.rs의 main → backend 초기화 → GPUI Application 실행 흐름을 확인했다. 실행 서브시스템 속성만 추가하고 함수 호출·데이터 흐름은 유지한다. 기존 Git 실행 숨김과 사용자 터미널 열기는 별도 책임으로 유지한다.

Windows이며 debug_assertions가 꺼진 빌드에 windows_subsystem = "windows"를 적용한다. 런타임에 콘솔 창을 숨기는 방식은 깜박임과 추가 API 의존성이 있어 채택하지 않는다. 디버그 빌드는 콘솔을 유지한다.

데이터 모델·외부 계약은 변경하지 않으므로 contracts는 생성하지 않는다. 헌장은 미작성 템플릿이므로 규범 검사를 생략하고 AGENTS.md의 기존 책임·호환성 유지 원칙을 준수한다.

일관성 분석: 요구사항 3개 모두 T003·T004에 대응하며 모순·중복·모호성·누락 0건이다. 설계 전후 아키텍처 변경과 새 의존성이 없다. 확장 훅 파일은 없다.
