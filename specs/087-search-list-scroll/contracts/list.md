# 목록 동작 계약

공통 가상 목록의 휠·스크롤바·방향키 구현을 그대로 사용한다. 같은 검색 결과의 재렌더링은 동일한 핸들을 공유한다. 새 검색 시 위치는 초기화한다. 조회 중에는 기존 가림 처리가 선택을 차단하며 비활성화 시 핸들을 중지한다. 커밋 선택과 파일 우클릭 메뉴 이벤트 형식은 바꾸지 않는다.

추가 크기 계약: 검색 버튼과 입력 외곽은 모두 30px다. 버튼은 탭과 같은 글자 12px, 좌우 여백 12px를 사용한다. 기본 입력과 다른 다이얼로그 버튼은 기존 크기를 유지한다.

결과 표식 계약: F만 민트 `#64d9bf`, C만 노랑 `#e6bc73`이며 제목·경로·내용 일치 안내에는 이 색상을 적용하지 않는다. 행 선택과 메뉴 이벤트는 기존과 같다.
