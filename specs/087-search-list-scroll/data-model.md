# 데이터 모델

`SearchPanel`에 `scroll: ListScrollHandle`을 보관한다. 생성 시 기본값을 만들고 렌더 시 공유 복제한다. 일반 렌더는 상태를 유지하고 새 검색은 콘텐츠 상태를 초기화한다. 비활성화 시 입력과 진행 중 드래그를 중단한다. 검색 결과와 선택의 기존 데이터 구조는 유지한다.

## 작은 검색 입력

검색 편집기는 `TextInput::compact`로 생성한다. 작은 입력은 12px 글자·20px 줄 높이·28px 내부 높이를 사용한다. 기본 입력은 기존 13px·24px·32px를 유지한다. 입력 외곽은 검색 패널에서 30px로 지정한다. 저장 데이터와 편집 상태 전이는 바뀌지 않는다.

결과 종류 표식은 기존 Match 변형으로 결정한다. 저장 데이터나 새 상태는 추가하지 않는다.
