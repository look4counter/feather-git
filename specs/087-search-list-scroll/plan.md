# 구현 계획: 찾기 목록 공통 스크롤

## 개요와 기술 환경

Rust 2024, GPUI 0.2.2 기반 Windows 데스크톱 앱이다. 새 의존성이나 저장 형식 변경은 없다. 검색 결과 수와 관계없이 기존 가상 목록 렌더링 방식을 유지한다.

## 기존 구조 및 영향 분석

`ui.rs::search_tab`이 저장소별 `SearchPanel`을 보유하고, 패널이 검색 백엔드 결과와 선택을 관리한다. `SearchPanel::render`는 `virtual_list`를 사용하지만 스크롤 핸들을 전달하지 않는다. `VirtualList::render`는 핸들이 없으면 매번 기본 핸들과 포커스를 새로 만든다. 프레임 측정값도 유지되지 않아 스크롤바 표시와 포커스 지속을 방해한다. 다른 저장소 목록은 `panel_scrolls`에서 핸들을 보관해 전달한다.

## 설계 결정

- `src/search_panel.rs`에 `ListScrollHandle` 필드를 추가하고 생성 시 기본값으로 초기화한다.
- 렌더 시 같은 핸들을 복제하여 `.scroll_handle(...)`로 전달한다. 공통 컴포넌트는 수정하지 않는다.
- 새 검색 시작 시 `reset_for_content`로 위치를 초기화한다. 일반 재렌더링에서는 초기화하지 않는다.
- 패널 활성화 변경 및 해제 시 `set_suspended`로 휠과 드래그를 차단한다.
- 검색 백엔드, 선택 이벤트, 파일 메뉴, 조회 중 가림 처리와 공개 인터페이스는 유지한다.

## 헌법 및 규칙 점검

헌법은 미작성 템플릿이므로 구체 원칙 검사는 생략한다. AGENTS.md의 기존 구조 준수, 최소 변경, 공통 기능 재사용, 계층 분리, 호환성을 설계 전후 확인했다. 충돌은 없다.

## 구현 순서와 검증

명세와 명확화 완료 → 작업 생성 → 일관성 분석 → 핸들 보관 및 수명 연결 → 기존 검색·가상 목록 테스트와 빌드·정적 분석 → 수렴 점검 순서로 진행한다. 소스 변경은 `src/search_panel.rs`에 한정한다. 문서는 현재 기능 폴더에 작성한다.

자동 검증은 기존 선택, 방향키 경계, 휠, 스크롤 상태 초기화 테스트를 재사용한다. 단순 필드 배선을 복제하는 테스트는 추가하지 않는다. 실제 창에서 휠·드래그·연속 방향키 검증이 불가능하면 미검증으로 보고한다.

## 검색 컨트롤 크기 추가 계획

`ui.rs::panel_tabs`는 30px 높이, 12px 글자, 좌우 12px 여백을 사용한다. `dialog::button`은 32px·13px·좌우 16px이고 `form_controls::input`은 34px다. `TextInput` 내부도 32px 높이와 24px 줄 높이를 고정하므로 외곽만 줄이면 내부가 잘릴 수 있다.

검색 패널에서 기존 버튼의 높이·글자·좌우 여백을 덮어쓰고 입력 외곽 높이 및 최소 높이를 30px로 덮어쓴다. `TextInput::compact` 생성자를 추가해 검색 입력에만 12px 글자, 20px 줄 높이, 28px 내부 높이를 적용한다. 내부 4px 여백과 테두리 2px를 합하면 외곽 30px에 맞는다. 기본 생성자와 다중행 입력은 기존 크기를 유지한다. 수정 범위는 `src/search_panel.rs`와 `src/text_input.rs`다. 새 의존성이나 이벤트 변경은 없다.

검증은 기존 검색 테스트와 입력·IME 관련 테스트, cargo check 및 Clippy를 사용한다. 단순 크기 상수 복제 테스트는 추가하지 않는다. 실제 GUI에서 한글 조합·커서·높이 비교는 직접 확인하지 못할 경우 미검증으로 기록한다. 헌법은 미작성 템플릿이고 기존 구조·호환성 규칙 위반은 없다.

## 검색 결과 표식 색상 추가 계획

현재 `src/search_panel.rs`는 C 또는 F와 본문을 한 문자열로 만든다. 종류와 본문은 `repository_search::Match`에서 얻고 공통 가상 목록이 선택·스크롤을 처리한다. 테마의 `ACCENT`는 민트색 `#64d9bf`이고 기존 파일 상태 표시에 따뜻한 노랑 `#e6bc73`을 사용한다.

표식과 본문을 별도 자식 요소로 나누고 표식에만 색을 적용한다. 파일은 ACCENT를 재사용하고 커밋은 기존 노랑 계열 값 `0xe6bc73`을 사용한다. 표식은 축소되지 않게 하고 본문은 최소 너비 0과 기존 생략을 유지한다. 변경은 `src/search_panel.rs` 렌더링에 한정한다. 검색 백엔드, 이벤트, 데이터 모델, 공통 테마와 목록에는 변경이 없다. 관련 검색 테스트와 cargo check·Clippy 및 diff 검사를 실행한다. 단순 색상 배선을 복제하는 테스트는 추가하지 않는다. 실제 시각 확인을 못하면 기록한다. 헌법은 미작성 템플릿이고 기존 계층·호환성 규칙 위반은 없다.
