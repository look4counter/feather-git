# 검증 안내

자동 검증: `cargo test --offline`, `cargo check --offline`, `cargo clippy --offline -- -D warnings`를 실행한다. 기존 경고가 있으면 원인을 분리해 기록한다.

수동 검증: `cargo run --offline`으로 앱을 열고 저장소 찾기 탭에서 결과가 많이 나오는 검색어를 입력한다. 세로 스크롤바와 휠로 마지막 결과에 접근한다. 결과 클릭 후 방향키를 3회 연속 입력하고 선택과 화면 이동을 확인한다. 다시 검색해 위치 초기화, 빈 결과와 오류 안내, 조회 중 차단을 확인한다. 검색어 입력란에서는 기존 Enter 검색이 유지되어야 한다.

크기 변경 검증: 저장소 패널 탭과 검색 버튼·입력창 높이를 비교해 모두 30px인지 확인한다. 한글 조합, 커서, 선택 표시, Enter 검색이 정상인지 확인한다. 다른 다이얼로그 입력창 크기가 그대로인지 확인한다. 관련 자동 테스트는 `cargo test --offline search_panel::`, `cargo test --offline text_input::`, `cargo test --offline ime_tests::`로 실행한다.

색상 검증: 파일과 커밋이 모두 나오는 검색 결과에서 F가 민트, C가 노랑인지 확인한다. 본문 색과 긴 경로 생략, 행 선택 및 파일 우클릭 메뉴가 유지되는지 확인한다.
