# 조사 결과

결정: 기존 `ListScrollHandle`을 검색 패널 수명 동안 보유한다.
근거: 공통 목록은 핸들 안에 스크롤 위치, 측정된 화면 크기, 포커스와 드래그를 저장한다. 호출자가 핸들을 전달해야 재렌더링 간 상태가 유지된다.
대안: 별도 스크롤이나 키보드 처리는 중복이므로 제외한다. 공통 목록 기본 상태 보관 변경은 영향 범위가 넓어 제외한다.
미해결 기술 질문은 없다.

추가 결정: 탭 크기를 검색 패널에만 적용하며 공통 입력에 선택적 작은 생성자를 제공한다. 기본 입력 전체를 줄이는 대안은 다른 화면에 영향을 주므로 제외했다. 입력 외곽만 줄이는 대안은 내부 32px 콘텐츠가 잘릴 수 있어 제외했다.

추가 조사: 표식과 본문이 한 문자열이라 행 전체 색상 대신 두 요소를 나누는 방식을 택했다. 파일은 기존 테마 ACCENT, 커밋은 기존 파일 상태의 노랑 값을 재사용한다. 백엔드 데이터와 이벤트 변경은 필요하지 않다.
