# 기능 명세: 작업 트리 파일 전체 선택

작성일: 2026-11-18
상태: 명세·명확화 검증 완료
입력: 변경 파일의 작업 트리에서 Ctrl+A로 전체 선택한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 변경 파일 전체 선택 (우선순위: P1)

사용자는 변경 파일 패널의 작업 트리에서 Ctrl+A를 눌러 화면 밖 항목을 포함한 모든 파일을 선택한다. 기존 다중 선택에 연결해 선택된 파일의 차이 표시와 후속 작업을 사용한다.
우선순위 근거: 많은 파일의 반복 선택을 줄인다.
독립 검증: 변경 파일이 여러 개 있는 목록을 클릭하고 Ctrl+A를 눌러 모든 파일의 선택 및 차이 표시를 확인한다.

1. 일부 파일을 선택한 상태에서 Ctrl+A를 누르면 전체가 선택된다.
2. 화면에 보이지 않는 파일도 선택되며 반복 입력해도 선택이 유지된다.
3. 히스토리 탭이나 다른 패널에서는 파일 전체 선택이 발생하지 않는다.

### 경계 조건

빈 목록은 안전하게 처리한다. 목록 조회 중, 저장소 작업 중, 모달 표시 중, 비활성 창에서는 실행하지 않는다. 텍스트 입력란의 Ctrl+A는 기존 텍스트 선택 동작을 보존한다.

## 요구사항

- FR-001: 변경 파일 패널에 포커스가 있고 작업 트리 탭일 때 Ctrl+A로 전체 파일을 선택한다.
- FR-002: 기존 다중 선택 상태와 뷰어를 재사용하고 검색·히스토리·다른 패널·텍스트 입력에 영향을 주지 않는다.
- FR-003: 빈 목록, 반복 입력, 조회 중, 모달 및 작업 중 상태를 안전하게 처리한다.
- FR-004: Ctrl+Shift+A 등 추가 수정키 조합을 전체 선택으로 처리하지 않는다.

### 주요 개체

파일 다중 선택: 기존 변경 파일의 인덱스 집합, 기준 행, 활성 행이다. 저장 데이터는 추가하지 않는다.

## 성공 기준

- SC-001: 변경 파일 N개가 있으면 Ctrl+A 한 번에 N개를 선택한다.
- SC-002: 히스토리·입력란·다른 패널 및 차단 상태에서 작업 트리 선택이 변경되지 않는다.

## 가정 및 명확화

전체 선택 범위는 작업 트리에 표시되는 모든 변경 파일이며 staged 여부를 구분하지 않는다. 기존 Ctrl·Shift 선택과 동일한 후속 동작을 사용한다. 추가 질문이 필요한 모호성은 없다.
