# 구현 계획 — Windows 앱 아이콘

## 기술 맥락과 영향 범위

Rust 2024와 GPUI를 사용한다. Windows에서는 메인 창의 시스템 제목표시줄을 숨기고 `src/ui.rs`의 `Workspace::titlebar`가 제목과 제어 버튼을 그린다. GPUI는 실행 모듈에서 아이콘 리소스 ID 1을 읽고 Win32 창 클래스에 등록한다. `build.rs`가 실행 파일 링크 인수를 구성하지만 현재 아이콘은 등록하지 않는다.

## 설계와 헌장 점검

- 제목표시줄은 기존 GPUI 이미지 경로에 컴파일 시 포함한 PNG를 전달한다. 이미지 객체는 한 번 초기화하고 제목과 드래그 영역 및 제어 버튼은 기존 구성에 둔다.
- Windows 대상 빌드에서 `embed-resource`를 사용해 ICO를 리소스 ID 1로 링크한다. 빌드 도구는 RC 파일을 재사용하고 누락 또는 컴파일 실패 시 빌드 오류를 낸다. 기존 MSVC 링크 옵션은 유지한다.
- 사용자 데이터 모델과 공개 인터페이스 변경은 없다. 헌장은 빈 양식이며 저장소의 계층 책임과 호환성 지침을 적용한다.

## 검증

개발·배포 빌드 및 회귀 테스트를 실행한다. Windows API로 실행 파일의 아이콘과 실행 중인 창 클래스의 아이콘을 확인한다. 실제 화면과 제어 버튼 확인을 시도하고 환경 제약이 있으면 결과를 기록한다.

## 제목표시줄 여백 조정 설계
`src/ui.rs`의 왼쪽 패딩을 16px에서 8px로 줄인다. 오른쪽 패딩과 아이콘 간격, 창 조작 구조를 유지한다. 전체 대상 컴파일과 릴리스 빌드로 검증한다.
