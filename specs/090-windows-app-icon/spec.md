# 기능 명세 — Windows 앱 아이콘

## 사용자 시나리오 및 검증

### 사용자 이야기 1 — 깃털 아이콘으로 앱 식별 (우선순위 P1)

Windows 사용자는 기존 로딩 화면에서 보던 깃털 모양으로 Feather Git 창과 실행 파일을 식별할 수 있다.

- Windows에서 새로 빌드한 앱을 실행하면 기본 창 제목 왼쪽과 실행 중인 작업표시줄 버튼에 같은 깃털이 표시된다.
- 실행 파일의 아이콘을 Windows에서 추출하면 같은 깃털이 표시된다. 일반 빌드와 릴리스 빌드에 적용된다.
- 실행 파일만 다른 폴더로 옮겨 실행해도 앱 아이콘이 표시된다.

## 요구사항

- FR-001 기존 로딩 깃털을 본뜬 투명 PNG를 기본 창의 제목 왼쪽에 표시한다.
- FR-002 같은 그림의 다중 크기 ICO를 Windows 실행 파일에 포함하고 실행 중인 작업표시줄에서 사용한다.
- FR-003 제목표시줄의 창 이동 및 제어 버튼 동작을 보존한다.
- FR-004 이미지 파일을 실행 파일 옆에 별도로 배포할 필요가 없다.

## 성공 기준

- SC-001 실제 Windows 실행 파일에서 깃털 아이콘을 추출할 수 있다.
- SC-002 기본 창 제목과 작업표시줄의 실행 중인 앱 버튼에 깃털이 표시된다.
- SC-003 제목표시줄의 창 이동과 최소화, 최대화, 닫기가 계속 동작한다.

## 명확화

대화에서 만든 두 깃털 이미지가 적용 대상이다. 제목표시줄은 Windows 기본 앱 창의 사용자 지정 제목표시줄을 가리킨다. 기존 고정 바로 가기의 아이콘 갱신은 범위 밖이다.

## 제목표시줄 왼쪽 여백 조정
- FR-005 창 왼쪽과 아이콘 사이의 여백을 줄인다.
- SC-004 아이콘과 제목이 함께 왼쪽으로 이동하고, 간격과 창 조작 동작을 유지한다.
- 명확화에서 기존 여백의 절반을 적용하기로 했다.
