# 기능 명세 — 스테이징·폐기·찾기 전역 진행 표시

## 사용자 이야기 1 — 변경 적용의 진행 상태 확인

파일 목록에서 하나 이상의 파일을 스테이징하거나 스테이징 해제할 때, 그리고 차이 보기에서 체크한 줄에 같은 작업을 할 때 기존 전역 진행 창을 표시한다. 파일 및 줄 폐기는 확인 전에 진행 창으로 확인 버튼을 가리지 않는다. 파일 폐기 준비와 확인 후 실제 적용 작업 동안에는 진행 창을 표시한다. 취소와 오래된 미리보기 거절은 새 적용 진행 창을 시작하지 않는다.

## 사용자 이야기 2 — 저장소 찾기의 진행 상태 확인

현재 저장소의 찾기 탭에서 비어 있지 않은 검색을 실행하면 결과가 돌아올 때까지 기존 전역 진행 창을 표시한다. 검색 버튼과 Enter 및 기존 찾기 새로고침 경로에 같은 규칙을 적용한다. 빈 입력은 진행 창을 띄우지 않는다.

## 요구사항과 수용 기준

- FR-001 파일 단위 Stage·Unstage 및 폐기와 체크한 줄의 Stage·Unstage 및 폐기에 창 전체의 기존 진행 표시를 사용한다.
- FR-002 저장소 찾기 요청이 진행 중일 때 같은 표시를 사용한다.
- FR-003 성공·실패·취소 시 완료된 작업의 진행 표시를 해제한다. 더 이상 현재 저장소나 탭에 속하지 않는 찾기 요청이 진행 표시를 유지하지 않는다.
- FR-004 진행 중 관련 화면 입력을 차단하고 기존 확인·오류·결과 처리를 보존한다. 기존의 다른 작업 진행 창을 보존한다. 충돌 해결 및 차이 보기 내부의 텍스트 찾기는 범위에 포함하지 않는다.
- SC-001 작업이 지연되면 창 중앙의 전역 진행 카드가 보이고, 완료 후 결과 또는 오류 및 다음 입력을 사용할 수 있다.
- SC-002 폐기 확인을 취소하거나 빈 검색어를 제출하면 해당 적용 또는 검색 진행 카드는 나타나지 않는다.

## 명확화

찾기는 앱의 저장소 찾기 탭을 뜻한다. 폐기는 파일 전체와 부분 선택에 모두 적용한다. 창 제목표시줄과 기존 진행 카드 형태는 보존한다.

## 전역 진행 창 표시 지연

- FR-005 스테이징·폐기·찾기 전역 진행 창은 기존 공통 지연인 150ms가 지난 후에도 대상 작업이 진행 중일 때 표시한다. 기존 전역 진행 창을 쓰던 다른 작업의 표시 시점은 유지한다.
- SC-003 150ms 전에 끝난 작업은 카드를 표시하지 않는다. 150ms 이상 지속된 작업은 카드를 표시하고 완료 즉시 해제한다.
- SC-004 도중에 끝난 작업의 타이머는 나중에 시작한 작업의 카드를 앞당겨 표시하지 않는다. 작업 중 입력 차단은 지연 중에도 적용한다.
- 명확화 범위는 직전에 추가한 파일 및 부분 스테이징·폐기와 저장소 찾기다.

## 스테이징 화면 깜빡임 방지

- FR-006 스테이징·스테이징 해제 시 상단 툴바, 저장소 패널, 하단 상태표시줄을 불필요하게 흐리거나 초기화하지 않는다. 진행 카드, 카드가 표시되는 동안의 기존 배경 암전, 입력 차단은 유지한다.
- FR-007 파일 목록과 차이 보기는 스테이징 직후 새 작업 트리 결과가 도착할 때까지 현재 내용과 선택을 유지한다. 그 결과에 맞춰 선택과 차이 보기를 갱신하며 실패 또는 없어진 파일은 실제 결과를 표시한다.
- FR-008 부분 스테이징을 완료할 때 차이 보기에 빈 화면이나 중복 조회를 만들지 않는다. 같은 작업 파일의 비교가 바뀔 때 가능한 기존 스크롤과 다중 파일 보기를 유지한다.
- SC-005 지연된 조회에서도 선택된 파일이 중간 프레임에서 빈 선택으로 바뀌지 않는다. 새 목록이 도착하면 새 스테이징 상태로 바뀐다.
- SC-006 쓰기 중 입력 보호와 150ms 진행 카드가 유지된다. 다른 기존 작업의 상태 표현, 저장소 요청 세대와 목록을 보존한다.

### 명확화

상단 툴바, 저장소 영역, 차이 보기와 하단 상태표시줄을 포함한다. 파일 전체 및 부분 Stage·Unstage 경로를 함께 다루며, 같은 작업 트리 갱신을 공유하는 폐기에는 동일한 화면 보존을 적용한다.
