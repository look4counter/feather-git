# 검증 및 수렴 기록

- 전체 대상 컴파일 검사와 Windows 릴리스 빌드에 성공했다. 실행 파일은 `target/worktree-search-progress/release/feather-git.exe`에 생성했다.
- 작업 진행 플래그, 폐기 확인과 취소, 차이 보기, 찾기 및 일괄 스테이징 관련 테스트 27개가 통과했다.
- 워크스페이스에 임시 폴더를 두고 전체 테스트를 재실행했다. 487개 통과, 42개 실패, 3개 건너뜀이었다. 실패에는 읽기 전용 Git 설정 파일 접근 오류가 포함된다. 파일 선택 조건의 어설션 실패는 변경 전 테스트 실행 파일에서도 동일하게 재현했다.
- 수렴 점검에서 파일 작업, 부분 작업 및 현재 저장소 검색의 시작과 성공·오류·취소 시 해제 경로가 기존 런타임 상태와 연결됨을 확인했다. 변경 코드와 명세 사이의 미해결 불일치는 발견하지 않았다.
- 실제 Windows 화면에서 전역 카드의 표시와 입력 차단은 직접 확인하지 않았다.

## 표시 지연 검증

- 기존 공통 150ms를 재사용한다. 입력 차단 레이어는 작업 시작과 함께 활성화하고, 카드와 배경은 150ms 이후에도 작업이 진행 중인 경우 그린다. 이전부터 전역 진행 창을 쓰던 작업은 기존 표시 시점을 유지한다.
- 149ms에는 감춤, 150ms에는 표시, 빠른 완료와 재시작 시 이전 시간 초기화를 자동 테스트로 확인했다. 관련 테스트 33개와 전체 대상 컴파일 검사, Windows 릴리스 빌드가 통과했다.
- 수렴 점검에서 명세와 구현 사이의 불일치를 발견하지 않았다. 전체 테스트 재실행과 실제 Windows 화면 검증은 수행하지 않았다.
