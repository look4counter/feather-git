# 구현 계획 — 커밋 그래프 행 경계 연속성

## 현행 동작과 영향 범위

공통 가상 리스트는 24px 논리 높이의 행을 개별 배치한다. `RowGraph`는 각 행의 입출력 경로를 물리 픽셀에 맞춘 다음 별도로 그린다. 홀수 물리 픽셀 굵기에서는 현재 정렬 방식이 행 끝점까지 반 픽셀 정렬을 적용한다. 행별 잘림 및 경로 안티앨리어싱이 결합하면 인접 행 경계의 픽셀에 배경이 비칠 수 있다.

## 설계

- `src/history_graph.rs`에서 정렬을 마친 경로의 행 경계 쪽 끝점만 물리 1픽셀만큼 연장한다. 곡선 제어점, 노드, 색과 경로 캐시는 기존 방식을 유지한다.
- `src/ui.rs`의 그래프 열 셀에 있던 고정 행 마스크를 제거하고 캔버스에서 열의 가로 너비와 위아래 물리 1픽셀을 허용하는 마스크를 적용한다. 상위 목록 뷰포트의 마스크와 교차하므로 열과 목록 경계는 유지된다.
- 헌장은 미작성 양식이다. 기존 커밋 그래프 계산과 GUI 경로의 책임을 유지하며 공개 데이터나 의존성을 변경하지 않는다.

## 검증

렌더에 쓰는 경로 함수로 분수 배율·스크롤 위치에서 수직선과 곡선에 겹침이 있는지 검증한다. 기존 그래프·레이아웃 테스트, 전체 대상 컴파일 검사 및 릴리스 빌드를 실행한다.
