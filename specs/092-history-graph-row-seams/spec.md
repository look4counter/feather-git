# 기능 명세 — 커밋 그래프 행 경계 연속성

## 사용자 이야기

사용자는 커밋 기록을 스크롤할 때 서로 연결된 그래프 선이 행 경계에서 미세하게 끊겨 보이는 현상 없이 기록을 읽을 수 있다.

## 요구사항과 수용 기준

- FR-001 같은 레인에서 이어지는 수직선과 레인을 바꾸는 곡선이 행 경계에서 연속되어 보인다.
- FR-002 그래프 표시 배율과 분수 스크롤 위치에도 연결성을 유지한다.
- FR-003 그래프 열 및 목록 영역의 바깥은 가리고, 그래프 레인·색상·노드 위치와 행 높이를 유지한다.
- SC-001 100%, 125%, 150%, 175%, 200% 배율의 분수 행 위치에서 연결 경로가 행의 경계를 덮는다.
- SC-002 기존 노드 위치, 그래프 열 너비 및 경계에 수직으로 진입하는 곡선 기준을 유지한다.

## 명확화

보고된 위치를 인접 커밋 행의 연결선 경계로 해석한다. 서로 연결되지 않은 기록에는 선을 추가하지 않는다.
