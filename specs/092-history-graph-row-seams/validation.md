# 검증 및 수렴 기록

- 경계 겹침 회귀 테스트가 수정 전 실패했고 수정 후 통과했다. 100%, 125%, 150%, 175%, 200% 배율에서 65개 분수 위치의 수직·곡선 조합을 검증했다.
- 그래프와 열 배치 관련 테스트 22개, 전체 대상 컴파일 검사, Windows 릴리스 빌드가 통과했다.
- 수렴 점검에서 그래프 열의 기존 가로 너비 및 목록 마스크와의 교차, 기존 노드와 경계 곡선 테스트를 확인했다. 명세와 구현의 미해결 불일치를 발견하지 않았다.
- 실제 Windows 화면에서의 간헐적 틈과 전체 회귀 테스트는 이번에 직접 확인하지 않았다.
