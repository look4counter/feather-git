# 빠른 검증

Windows 앱의 오른쪽 하단에서 환경설정을 열고 업데이트 섹션의 업데이트 확인을 누른다. 저장소를 열지 않은 상태에서도 같은 경로를 확인한다. 업데이트 창을 닫으면 환경설정으로 돌아오고 업데이트 확인 버튼으로 포커스가 복귀하는지 확인한다. 현재 버전과 같은 응답에는 최신 버전이 표시되고, 상위 버전에는 업데이트 및 재시작 버튼이 표시된다. 임시 복사본에 대해 앱 종료, 새 버전 재시작, 네트워크 오류 및 복구를 확인한다.

환경설정의 업데이트 섹션에서 인증서 추가를 눌러 사내 CA 파일을 선택한다. 목록에서 등록된 파일을 확인하고 필요 없어진 파일은 해당 행에서 삭제한다. 종료 후 다시 열어 목록 유지 여부와 업데이트 확인 및 다운로드를 검증한다.
