# 기능 명세 — Windows 단일 실행 파일 업데이트

## 사용자 이야기

Windows 사용자는 환경설정의 업데이트 섹션에서 현재 버전과 서버의 최신 버전을 확인한다. 새 버전이 있으면 창에서 업데이트를 승인할 수 있다. 작업이 끝나면 새 실행 파일로 앱이 다시 열린다.

## 요구사항과 수용 기준

- FR-001 현재 버전은 빌드에 포함된 Cargo 패키지 버전으로 표시한다. 제공된 XML의 `version` 요소 중 ID가 `com.look4counter.feather-git`인 항목에서 버전과 다운로드 주소를 읽는다.
- FR-002 현재 또는 상위 로컬 버전, 다운로드할 새 버전, 조회 오류를 창에서 구분한다. 네트워크 중에는 UI 스레드를 블로킹하지 않는다.
- FR-003 새 버전만 명시적인 버튼 조작으로 공식 배포 주소에서 다운로드한다. 받는 중이나 다운로드 실패 시 기존 실행 파일은 그대로 실행된다.
- FR-004 정상 종료 뒤 기존 파일을 교체하고 새 실행 파일을 실행한다. 사용자가 단일 EXE만 받아서 사용할 수 있고 실패 시 기존 파일이 실행 가능한 상태를 유지한다.
- SC-001 사용자 XML 예시와 더 큰 버전을 정확히 비교하며 누락, 잘못된 XML, 중복 항목과 오류를 처리한다.
- SC-002 다운로드, 교체, 새 버전 시작 실패에 대비하여 교체 전 파일을 유지하거나 복원한다.

- FR-005 Windows 환경설정의 업데이트 섹션에 업데이트 확인 버튼을 표시하고 상태표시줄의 버튼을 제거한다. 저장소를 열지 않은 상태에서도 사용할 수 있다.
- SC-003 기존 업데이트 창이 열리고 닫으면 편집 상태와 포커스가 유지된 환경설정으로 돌아간다.

## 명확화

업데이트 목록에는 `id`, `version`, `url` 속성이 있다. 버튼 이동에도 기존 Windows 전용 범위를 적용하고 새 버전이 감지되면 사용자가 업데이트 및 재시작을 선택한다.
