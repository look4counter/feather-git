# 검증 및 수렴 기록

- 사용자 예시와 로컬 사이트 XML에서 실제 속성 이름 및 공식 다운로드 주소를 확인했다.
- 버튼 이동 후 전체 대상 컴파일과 업데이트 테스트 4개가 통과했다. 코드에서 환경설정 이벤트, 상태표시줄 버튼 제거와 기존 업데이트 창의 포커스 복귀를 확인했다. Windows 화면에서 직접 조작하는 검증은 남아 있다.
- 버전 비교, URL 제한, 잘못된 XML, 불완전한 실행 파일, 교체와 복원 및 상태표시줄 관련 테스트 6개가 통과했다.
- 임시 Windows 실행 파일을 실행한 채 실제 릴리스의 도우미 모드를 기동했다. 원본 실행 중에는 파일이 유지됐고 원본 종료 및 종료 신호 이후에만 파일이 교체되어 새 테스트 실행 파일이 시작됐다.
- 전체 대상 컴파일 검사와 릴리스 빌드가 통과했다. 수렴 점검에서 명세와 코드 사이의 미해결 차이를 발견하지 않았다.
- 환경에서 원격 XML과 릴리스 자산에 연결할 수 없어 실서버 조회·다운로드 및 앱 창에서의 조작은 확인하지 않았다. 전체 테스트도 재실행하지 않았다.

## 업데이트 인증서 검증

- 업데이트 테스트 4개와 인증서 저장소 테스트 1개가 통과했다. 등록, 중복 제거, 재조회, 잘못된 입력으로 인한 저장 취소, 삭제를 확인했다.
- 전체 대상 컴파일과 디버그 빌드가 통과했다. 광범위한 이름 필터에 함께 잡힌 작업 트리 테스트는 Git 경로 환경 변수를 제거한 뒤 통과했다.
- 수렴 점검에서 목록 관리, 사용자 설정 저장, 기본 신뢰 유지와 확인·다운로드 양쪽의 공용 클라이언트 연결을 명세와 대조했다. 실제 사내 서버와 Windows 파일 선택 화면은 검증하지 않았다.

## Windows TLS 검증 결과

- 전체 대상 컴파일과 업데이트·인증서·아바타 테스트 16개가 통과했다.
- 기본 디버그 실행 파일 교체 중 액세스 거부 오류가 발생했다. 새로 링크한 실행 파일을 별도 경로로 복사하고 해시 일치와 도움말 실행을 확인했다.
- 수렴 점검에서 업데이트 확인·다운로드가 동일한 Windows TLS 클라이언트를 사용하며 등록 CA, 호스트 검증 및 공식 배포 주소 제한을 적용하는 것을 확인했다. 실제 사내망의 오류 재현 및 해결 여부는 확인하지 못했다.
