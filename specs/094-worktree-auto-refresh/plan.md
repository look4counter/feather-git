# 변경 파일 자동 갱신 구현 계획

## 구조와 데이터 흐름

저장소 스냅샷의 실제 작업 폴더를 사용해 Windows 디렉터리 변경 신호를 구독한다. 새 의존성 없이 기존 Windows 바인딩을 사용한다. 활성 저장소와 화면을 기준으로 GPUI 감시 작업을 교체하며, 1초 타이머는 운영체제 신호만 확인한다. 변경을 감지하면 다음 조회가 가능한 시점까지 표시를 유지한다.

기존 변경 파일 요청은 백엔드에서 상태와 Diff를 읽고 요청 번호와 저장소 정보를 확인한 뒤 결과를 적용한다. 자동 갱신은 내부 파일 편집 뒤에 이미 쓰는 선택 복원 경로를 재사용한다. 저장소 작업 및 기존 패널 조회와 겹치지 않도록 한다.

## 제약과 검증

공개 API와 저장 데이터 형식의 변경이 없다. 운영체제 감시 등록 실패 시 기존 수동 갱신을 사용할 수 있다. 저장소별 감시는 활성 변경 파일 화면의 수명과 일치한다. 작업트리 내부의 Git 메타데이터나 무시 파일에 대한 알림도 재조회 계기가 될 수 있다.

Windows 임시 디렉터리에서 변경 신호와 재등록을 검증하고, 기존 패널 및 선택 복원 테스트와 잠금 파일 기준 빌드를 실행한다. 프로젝트 헌법 파일은 초기 템플릿 상태이므로 프로젝트 규칙의 기존 구조와 호환성 요건을 확인한다.
