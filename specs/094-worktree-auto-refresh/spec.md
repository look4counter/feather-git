# 변경 파일 자동 갱신

## 사용자 이야기 1 — 외부 변경 확인 (P1)

활성 저장소의 변경 파일 화면에서 외부 편집기로 파일을 저장하면 작업트리 목록과 선택한 파일의 Diff가 자동으로 갱신된다.

## 요구사항과 수용 기준

- **FR-001** Windows의 활성 변경 파일 화면에서 하위 파일의 추가, 수정, 삭제, 이동을 감지한다.
- **FR-002** 자동 재조회 시작 간격은 최소 1초다. 변경 없는 구간의 자동 Git 조회는 0회이며, 조회 중 변경은 다음 조회에 반영한다.
- **FR-003** 유효한 파일 선택을 유지하고, 저장소나 화면을 전환하면 이전 감시를 종료한다. 수동 갱신과 내부 작업의 기존 동작을 보존한다.

## 명확화

“반경파일”은 변경 파일 화면이다. 1초는 자동 작업트리 재조회 사이의 최소 간격이다. 운영체제가 알린 변경 여부를 매초 확인하며 Git 조회 완료 시간은 저장소에 따라 달라진다.

## 성공 기준

- **SC-001** 유휴, 연속 저장, 조회 중 저장 조건에서 FR-002의 조회 횟수와 간격을 확인한다.
- **SC-002** 추가, 수정, 삭제, 이동과 탭 전환에서 FR-001 및 FR-003을 확인한다.
